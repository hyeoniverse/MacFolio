z-index에 이름을 붙인 다음 차례는 모서리 둥글기(`border-radius`)다. 새 카드나 단추를 만들 때마다 "다른 카드는 몇 px였지?"를 찾아야 했다.

## border-radius가 무엇인가

상자의 모서리를 얼마나 둥글게 깎을지 정하는 CSS 속성이다. 값이 클수록 더 둥글다. 높이의 절반보다 크게 주면 양 끝이 반원인 알약 모양이 되고, `50%`를 주면 정사각형이 원이 된다.

## 세어 보기

`src` 아래 CSS에서 `border-radius`는 576곳이었다. 값은 마흔 가지가 넘었다.

| 값                         | 곳           | 무엇                     |
| -------------------------- | ------------ | ------------------------ |
| 50%                        | 84           | 원 (아바타, 동그란 단추) |
| 999px                      | 73           | 알약 (검색 칸, 배지)     |
| 6px                        | 46           | 작은 단추, 입력 칸       |
| 8px                        | 42           | 단추, 메뉴               |
| 14px                       | 34           | 카드                     |
| 10px                       | 29           | 목록 상자                |
| 4px                        | 15           | 작은 표시, 코드 조각     |
| 12 · 22 · 18 · 20 · 16px … | 각 20곳 아래 | 앱마다 다른 모양         |

원(50%)을 뺀 위의 여섯 값만으로 239곳, 전체의 40%가 넘는다.

## 이름 붙이기

`styles/theme.css`에 여섯 이름을 두었다.

```css
:root {
	--radius-xs: 4px;
	--radius-sm: 6px;
	--radius-md: 8px;
	--radius-lg: 10px;
	--radius-xl: 14px;
	--radius-full: 999px; /* 알약 */
}
```

그리고 34개 CSS 파일에서 `border-radius: 8px;`처럼 이 값 하나만 적힌 239곳을 `border-radius: var(--radius-md);`로 바꿨다. 값이 같으니 화면은 1px도 달라지지 않는다.

## 바꾸지 않은 것

- **원(50%)**: 크기와 상관없이 원이라는 뜻이라 이미 이름이나 다름없다.
- **모서리마다 다른 값**(`14px 14px 0 0` 같은 위쪽만 둥근 시트): 한 값이 아니라 그대로 두었다.
- **나머지 값(12·22·18px 등)**: 앱마다 iOS·macOS 모양을 따라 고른 값이 많다. 여섯 이름 중 가까운 것으로 합치면 모양이 바뀌므로, 디자인을 맞출 때 하나씩 정한다.

이제 새 카드는 `var(--radius-xl)`, 새 알약은 `var(--radius-full)`로 시작하면 다른 곳과 같은 둥글기가 된다.
