## 들어가기 전에

분류 모델은 고양이 사진을 받아 "고양이"라는 답 하나를 낸다. 반대 방향으로 "1960년대 사진 속, 스노우 글로브 안의 바나나"라는 문장을 받아 그 장면을 그리는 일은 훨씬 어렵다. 이런 사진은 학습 데이터에 없으므로 검색해 찾아올 수 없고, 512×512 컬러 이미지 한 장은 786,432개의 픽셀 값으로 이루어져 있어 그럴듯한 조합을 무작위로 맞힐 가능성도 없다. 모델은 이 거대한 공간에서 자연스러운 이미지가 어디에 몰려 있는지를 학습 데이터에서 배워야 한다.

==생성 모델(generative model)은 학습 데이터의 분포를 근사하고, 그 분포에서 학습 데이터에 없던 새 표본을 뽑는 모델이다.== 분포를 배우는 방법은 모델마다 다르다. GAN은 생성자와 판별자의 적대적 게임으로, VAE는 잠재 변수의 분포를 규제한 오토인코더로, 디퓨전 모델은 잡음을 단계적으로 제거하는 과정으로 분포를 학습한다. 2022년 8월 공개된 스테이블 디퓨전(Stable Diffusion)은 디퓨전을 픽셀 대신 작은 잠재 공간에서 수행해, 소비자용 GPU에서도 프롬프트만으로 이미지를 생성할 수 있게 했다.

이 글이 답하려는 질문은 두 가지다. 세 생성 모델은 각각 어떤 목적 함수로 학습하고, 그 결과 어떤 장단점을 가지는가. 그리고 스테이블 디퓨전은 텍스트 프롬프트를 어떻게 잠재 공간의 한 지점으로 바꾸고, 그 지점에서 잡음을 제거해 이미지를 만드는가. 원 논문의 수식으로 학습 목표를 확인하고, 마지막에는 저작권과 사회적 편향 같은 한계를 다룬다.

| 순서 | 내용                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 1    | 생성형 AI의 범위, 캡션 생성에서 이미지 생성으로 온 흐름, DALL·E에서 스테이블 디퓨전까지의 연표 |
| 2    | 생성 모델의 목표와 생성 학습의 삼중고(품질, 다양성, 속도)                                      |
| 3    | GAN의 생성자·판별자, 최소최대 목적 함수와 최적 판별자, 학습 절차와 모드 붕괴                   |
| 4    | VAE의 잠재 변수, 증거 하한(ELBO)의 유도, 흐릿한 출력의 원인                                    |
| 5    | 디퓨전 모델의 확산 과정, ELBO에서 잡음 예측 손실까지의 유도, DDIM 표본 추출                    |

| 7    | 생성 과정과 샘플러, 이미지 변환·인페인팅·미세 조정, 버전별 차이                                |
| 8    | 한계와 전망: 저작권과 학습 데이터 암기, 사회적 편향, 분야별 발전 예측                          |

디퓨전 모델이 잡음 예측에 쓰는 U-Net은 [의미 분할의 성능 평가와 FCN·DeconvNet·U-Net](/memo/dl-segmentation)에서, 스테이블 디퓨전이 텍스트 조건을 넣는 교차 어텐션의 바탕인 스케일드 내적 어텐션은 [트랜스포머의 셀프 어텐션과 멀티 헤드 어텐션](/memo/dl-transformer)에서 다룬다. 확률 분포, 기댓값, KL 발산을 알고 있으면 수식 절을 따라가기 쉽다.

## 생성형 AI와 이미지 생성

### 생성형 AI의 범위

생성형 AI(generative AI)는 텍스트, 이미지, 음성 같은 비정형 데이터를 다루는 딥러닝 모델로 사용자의 입력(프롬프트)에 따라 콘텐츠를 새로 만드는 인공지능을 통칭한다. 정해진 범주 중 하나를 고르는 분류 모델과 달리, 사용자의 요구에 맞춰 결과물 자체를 능동적으로 생성한다. 2022년 11월 공개된 ChatGPT가 텍스트 분야의 대표 사례이고, 이미지 분야에는 DALL·E, Midjourney, 스테이블 디퓨전이 있다.

생성형 AI의 혁신이 빨라지면서 시장과 대중의 관심이 이 분야에 집중되었다. 발전 영역도 텍스트에 그치지 않고 코드, 이미지, 음성, 비디오, 3D로 넓어졌다. 아래 지형도는 분야마다 모델 계층 위에 응용 서비스 계층이 쌓이는 구조를 보여 준다. 모델 계층은 사전 학습한 기반 모델이고, 응용 계층은 그 모델을 특정 업무에 맞춰 감싼 서비스다. 이미지 분야의 모델 계층에는 OpenAI의 DALL·E 2, Stability AI의 Stable Diffusion, 공개 모델 DALL·E mini에서 출발한 Craiyon이 있고, 응용 계층에는 이미지 생성, 소비자·소셜, 미디어·광고, 디자인이 놓인다. 이 글은 그중 이미지 생성을 다룬다.

### 캡션 생성에서 이미지 생성으로

2015년 무렵 인공지능 분야의 큰 발전 중 하나는 이미지 캡셔닝(image captioning), 즉 이미지의 자동 설명이었다. 이미지 속 물체에 "사람", "공", "해변" 같은 라벨을 붙이는 객체 인식은 이미 가능한 상태였고, 캡셔닝은 여기서 한 단계 나아가 CNN으로 이미지 특징을 뽑고 RNN으로 문장을 생성해 "해변에서 공놀이를 하는 사람들" 같은 자연스러운 문장을 만들었다. 라벨 목록은 물체의 존재만 알려 주지만, 문장은 물체 사이의 관계(공을 가지고 논다)와 장소(해변에서)를 함께 담는다.

연구자들은 이 방향을 뒤집어 문장에서 이미지를 만드는 문제에 도전했다. 검색처럼 기존 이미지를 찾아오는 것이 아니라 학습 데이터에 없는 장면을 새로 그려야 하므로 캡셔닝보다 훨씬 어려운 문제다. 캡셔닝은 출력 공간이 단어 수만 개의 시퀀스이고 정답 문장과 비교하기 쉽지만, 이미지 생성은 출력이 수천에서 수십만 차원의 연속 값이고 같은 문장에 맞는 정답 이미지가 무수히 많다.

Mansimov 등의 alignDRAW(2015년 arXiv 공개, ICLR 2016)는 이 문제를 처음 본격적으로 다룬 모델이다. 순환 VAE인 DRAW가 캔버스에 조금씩 덧그리는 구조에, 그리는 단계마다 문장의 어느 단어에 주목할지 정하는 어텐션을 더했다. 저자들은 "주차장에 서 있는 초록색 스쿨버스"처럼 현실에서 보기 드물어 학습 데이터에도 거의 없는 조합을 입력해 32×32 픽셀 이미지를 생성했다. 학습 데이터의 스쿨버스는 대부분 노란색이므로, 모델이 데이터를 외운 것이 아니라 "초록색"과 "스쿨버스"라는 개념을 조합했는지 확인할 수 있는 시험이다.

![이미지 캡셔닝은 이미지에서 CNN과 RNN을 거쳐 문장을 만들고, 텍스트-이미지 생성은 문장에서 생성 모델을 거쳐 새 이미지를 만드는 도식](./images/dl-image-generation-02.svg '캡셔닝(이미지 → 문장)의 방향을 뒤집은 텍스트-이미지 생성')

![초록색 스쿨버스 프롬프트로 생성한 32픽셀 크기의 작은 이미지](./images/dl-image-generation-03.jpg '2015년 모델이 생성한 32×32 픽셀 결과. 왼쪽 프롬프트(PROMPT)는 "주차장에 서 있는 초록색 스쿨버스"이다. 형태는 흐릿하지만 초록색 물체를 만들었다')

결과물은 형태를 알아보기 어려운 수준이었지만 초록색 물체를 만들어 냈고, 텍스트 조건으로 학습 데이터에 없는 이미지를 만들 수 있다는 가능성을 보였다. 같은 프롬프트를 2022년의 DALL·E 2에 입력하면 창틀, 문, 바퀴, 주차선까지 갖춘 사진 수준의 이미지가 나온다. 해상도는 32×32에서 1024×1024로 가로세로 32배, 픽셀 수로는 1,024배가 되었다.

![A green school bus parked in a parking lot 프롬프트로 DALL·E 2가 생성한 초록색 스쿨버스 측면 사진](./images/dl-image-generation-19.jpg '같은 프롬프트에 대한 2022년 DALL·E 2의 결과. 학습 데이터에 드문 초록색 스쿨버스를 사진 수준으로 그린다')

7년 사이의 변화는 미술계에서도 드러났다. 2022년 8월 Jason M. Allen이 Midjourney로 만든 작품 「Théâtre D'opéra Spatial」(스페이스 오페라 극장)이 미국 콜로라도 주 박람회 미술전의 디지털 아트·디지털 보정 사진 부문에서 1위를 차지했다. 사람 고유의 영역으로 여겨지던 예술에 AI가 들어왔다는 논쟁이 일었고, 이 사건은 대중에게 AI 그림의 수준을 알린 계기가 되었다.

### 스테이블 디퓨전 이전의 흐름

이미지 생성 모델 자체는 새로운 기술이 아니다. GAN 계열 모델이 등장하면서 이미지 생성 연구가 본격화되었지만, 초기 모델은 성능이 낮고 일반 사용자가 다루기 어려워 연구자 밖에서는 큰 주목을 받지 못했다. 2018년 10월 크리스티 경매에서 43만 2,500달러에 낙찰된 GAN 초상화 「Edmond de Belamy」는 생성 모델이 대중의 주목을 받은 계기였다. 작품 오른쪽 아래의 서명 자리에는 화가 이름 대신 GAN의 최소최대 목적 함수가 적혀 있다. 그러나 이런 모델은 원하는 결과물에 맞춘 특정 데이터셋으로 직접 학습해야 했고, 학습한 모델은 유연성이 낮았다. 이 초상화는 14~20세기 초상화 약 1만 5천 점으로 학습한 모델의 출력이고, 초상화 데이터셋으로 학습한 모델은 초상화만 생성하고 풍경은 생성하지 못한다.

2021년 1월 5일 OpenAI는 텍스트 프롬프트 하나로 다양한 장면을 생성하는 DALL·E를 공개했다. 120억 매개변수의 트랜스포머가 텍스트 토큰 256개 뒤에 이미지 토큰 1,024개(32×32)를 이어 쓰는 방식으로, 공개 자료의 대표 예시는 "아보카도 모양의 안락의자"였다. 두 개념을 합친 의자는 학습 데이터에 거의 없지만, 모델은 아보카도의 반쪽 단면을 등받이로, 씨를 쿠션으로 옮겨 그렸다. DALL·E는 한 프롬프트에 512장을 생성한 뒤 CLIP으로 프롬프트와의 유사도를 측정해 상위 표본만 고르는 재순위화(reranking)를 사용했다.

![OpenAI의 DALL·E 공개 화면. 아보카도 모양 안락의자 생성 예시와 JAN. 2021 표기](./images/dl-image-generation-20.jpg '2021년 1월 OpenAI의 DALL·E 공개(OpenAI announces DALL·E). 프롬프트는 "아보카도 모양의 안락의자"로, 두 개념을 조합한 생성 예시이다')

2022년 4월 6일 공개된 후속 모델 DALL·E 2는 구조를 완전히 바꿨다. CLIP 텍스트 임베딩을 받아 CLIP 이미지 임베딩을 생성하는 사전(prior) 모델과, 그 이미지 임베딩을 조건으로 64×64 이미지를 만드는 디퓨전 디코더, 이를 256×256과 1024×1024로 키우는 두 단계의 디퓨전 업샘플러로 이루어진다. 논문은 CLIP 이미지 임베딩을 역으로 이미지로 바꾼다는 의미로 이 구조를 unCLIP이라 불렀다. DALL·E 2는 DALL·E의 256×256보다 가로세로 4배 큰 1024×1024 해상도를 제공하고 묘사도 훨씬 정교해졌다. 다만 대기자 명단에 오른 제한된 사용자에게 먼저 공개되었고, 2022년 7월부터는 유료 크레딧 방식으로 서비스되어 누구나 자유롭게 쓸 수는 없었다.

![같은 아보카도 안락의자 프롬프트로 DALL·E와 DALL·E 2가 각각 생성한 3×3 이미지 격자 비교](./images/dl-image-generation-21.jpg 'DALL·E(왼쪽)와 DALL·E 2(오른쪽, 2022년 4월). 같은 개념을 더 높은 해상도와 사실적인 재질로 그린다. 오른쪽 아래는 출처 표기(Lia Coleman 제공)이다')

같은 시기 다른 디퓨전 기반 텍스트-이미지 모델도 연이어 등장했다. 2021년 12월 OpenAI의 GLIDE는 텍스트 조건 디퓨전 모델에 분류기 없는 가이던스를 적용해 CLIP 가이던스보다 사람이 선호하는 결과를 얻었고, 2022년 5월 Google의 Imagen은 텍스트 전용으로 사전 학습한 대형 언어 모델 T5-XXL을 고정한 채 텍스트 인코더로 써서, 텍스트 인코더의 크기를 키우는 효과가 이미지 디퓨전 모델의 크기를 키우는 효과보다 크다는 결과를 보였다. Imagen의 가중치는 공개되지 않았고, GLIDE는 사람 이미지를 걸러 낸 데이터로 학습한 작은 모델만 공개되었다.

OpenAI 모델의 접근이 제한된 동안 오픈 소스 개발자 커뮤니티는 공개된 사전 학습 모델을 조합해 텍스트-이미지 생성기를 직접 만들었다. 이미지와 문장의 유사도를 측정하는 CLIP을 안내 신호로 삼아 VQGAN이나 디퓨전 모델의 출력을 프롬프트 쪽으로 이끄는 VQGAN+CLIP, CLIP 안내 디퓨전(CLIP guided diffusion)이 대표적이다. 생성 중인 이미지를 CLIP에 넣어 프롬프트와의 코사인 유사도를 계산하고, 그 유사도가 커지는 방향의 기울기로 이미지나 잠재 코드를 매 단계 수정하는 방식이다. 이 코드는 Google Colab 노트북으로 공유되어 GPU가 없는 사용자도 브라우저에서 실행할 수 있었고, 이 커뮤니티에서 활동한 개발자 일부는 이후 이미지 생성 회사에 합류했다.

Midjourney는 이 시기인 2022년 7월 12일 디스코드 서버의 봇으로 명령을 입력하는 방식의 공개 베타를 시작했다. 사용자가 채팅창에 `/imagine` 명령과 프롬프트를 입력하면 봇이 2×2 격자로 네 장의 후보를 생성하고, 진행률을 표시하며 중간 결과를 갱신한다. 사용자는 그중 하나를 골라 고해상도로 키우거나 변형을 요청한다. 내부 모델 구조는 공개하지 않았다.

![디스코드 채팅창에서 MidJourney Bot이 film strip from a cat party 프롬프트로 네 장의 고양이 필름 이미지를 생성하는 화면](./images/dl-image-generation-22.jpg 'Midjourney의 디스코드 봇. 프롬프트 "고양이 파티를 담은 필름 스트립" 하나에 네 장의 후보를 2×2 격자로 만들고 진행률(65%)을 표시한다')

비슷한 시기인 2022년 8월 22일 Stability AI가 스테이블 디퓨전을 공개하면서 이미지 생성은 새로운 국면을 맞았다. 이미지 생성 기술의 민주화를 목표로 모델 가중치를 CreativeML OpenRAIL-M 라이선스로 공개했고, 잠재 공간에서 연산하는 구조 덕분에 기존 모델보다 효율이 높아 일반 소비자용 GPU에서도 프롬프트만으로 이미지를 생성할 수 있었다. 사실상 그림 인공지능의 대중화를 연 모델이고, 가중치가 공개된 덕분에 이를 기반으로 한 이미지 생성 서비스와 미세 조정 모델이 대량으로 등장했다.

파생 서비스 중 가장 널리 알려진 것은 2022년 10월 공개된 NovelAI Diffusion이다. 스테이블 디퓨전을 애니메이션풍 일러스트로 미세 조정해 AI 그림을 대중에게 널리 알렸지만, 작가의 동의 없이 일러스트 사이트에서 수집한 그림으로 학습했다는 점이 알려지면서 AI 그림 저작권 논란에 불을 붙였다. 이 논란은 AI 그림에 대한 창작자와 대중의 반감을 키운 원인이기도 하다.

## 생성 모델의 목표

판별 모델은 조건부 확률 `p(y \mid x){:math}`를 학습하고, 생성 모델은 데이터 자체의 분포 `p_{\text{data}}(x){:math}`를 근사하는 모델 분포 `p_\theta(x){:math}`를 학습한다. 학습을 마친 뒤 `p_\theta{:math}`에서 표본을 뽑으면 학습 데이터에 없던 새 이미지가 나온다. 텍스트-이미지 모델은 여기에 조건이 붙은 `p_\theta(x \mid y){:math}`, 즉 프롬프트 y를 조건으로 한 이미지 분포를 학습한다. 이미지 한 장은 수십만 차원의 벡터이므로 분포를 직접 표현하기 어렵고, 세 모델은 표준 정규분포처럼 표본을 뽑기 쉬운 분포의 잠재 변수(latent variable) `z{:math}`를 이미지로 바꾸는 방식을 서로 다르게 학습한다. GAN과 VAE의 `z{:math}`는 이미지보다 차원이 낮고, 디퓨전 모델의 시작 잡음 `x_T{:math}`는 이미지와 차원이 같다.

| 모델   | 학습 신호                       | 생성 방법                                         | 장점                        | 단점                    |
| ------ | ------------------------------- | ------------------------------------------------- | --------------------------- | ----------------------- |
| GAN    | 판별자와의 적대적 게임          | `G(z){:math}` 한 번의 순전파                      | 선명한 이미지, 빠른 생성    | 학습 불안정, 모드 붕괴  |
| VAE    | 증거 하한(ELBO) 최대화          | `z \sim \mathcal{N}(0, I){:math}`를 디코더에 입력 | 안정된 학습, 잠재 공간 구조 | 흐릿한 이미지           |
| 디퓨전 | 단계별 잡음 예측(ELBO의 단순화) | 잡음에서 T단계 반복 제거                          | 높은 품질과 다양성          | 반복 횟수만큼 느린 생성 |

Xiao 등(ICLR 2022)은 생성 모델이 동시에 갖춰야 할 세 성질을 표본 품질, 모드 포괄(다양성), 빠른 표본 추출로 정리하고, 세 성질을 모두 만족하는 모델이 없다는 점을 생성 학습의 삼중고(generative learning trilemma)라 불렀다. 위 표의 단점 열은 이 삼중고에서 각 모델이 포기한 성질과 대응한다. GAN은 다양성을, VAE는 품질을, 디퓨전은 속도를 포기한다. 스테이블 디퓨전은 디퓨전의 품질과 다양성을 유지하면서, 연산 공간을 줄이고 단계 수가 적은 샘플러를 써서 속도 문제를 완화한 사례다.

## GAN

### 생성자와 판별자

이 절부터는 스테이블 디퓨전을 이해하는 배경지식으로 대표 생성 모델 세 가지를 살핀다.

GAN(Generative Adversarial Network, 적대적 생성 신경망)은 Goodfellow 등이 2014년 NeurIPS에 게재한 모델이다. ==생성자 G는 잡음 z에서 가짜 데이터를 만들고, 판별자 D는 입력이 진짜일 확률을 출력하며, 두 네트워크는 서로를 이기도록 번갈아 학습한다.== 흔히 위조지폐범(G)과 경찰(D)에 비유한다. 위조지폐범은 경찰에게 들키지 않도록 위조 기술을 높이고, 경찰은 위조지폐를 찾아내도록 감별 능력을 높인다. 이 경쟁이 반복될수록 위조지폐는 진짜와 구별하기 어려워진다. 생성자는 판별자를 속이기 위해, 판별자는 생성자를 잡아내기 위해 성능이 오르는 상호 적대적 관계가 이름의 유래다.

![잡음 z가 생성자 G를 거쳐 가짜 이미지가 되고, 가짜와 진짜 이미지가 판별자 D로 들어가 진짜 확률을 출력하는 구조도](./images/dl-image-generation-16.svg 'GAN 구조. 판별자의 기울기가 생성자로 역전파된다')

생성자는 진짜 데이터를 직접 보지 않는다. 생성자가 받는 학습 신호는 판별자의 출력에서 역전파된 기울기뿐이고, 이 기울기는 "판별자가 더 진짜라고 믿게 하려면 출력 픽셀을 어느 방향으로 바꿔야 하는가"를 알려 준다. 판별자는 사실상 진짜 분포와 가짜 분포의 차이를 측정하는 학습 가능한 손실 함수 역할을 한다.

### 최소최대 목적 함수

원 논문의 목적 함수는 D는 최대화하고 G는 최소화하는 2인 게임이다.

```math
\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
```

첫째 항은 진짜 데이터에 1을, 둘째 항은 가짜 데이터에 0을 출력하도록 판별자를 이끈다. 이 식은 진짜를 정답 1, 가짜를 정답 0으로 둔 이진 교차 엔트로피의 부호를 바꾼 것과 같다. G를 고정하면 최적 판별자는 `D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}{:math}`이고, 이를 대입하면 목적 함수는 두 분포의 젠슨-섀넌 발산(JSD)으로 바뀐다.

```math
V(D^*, G) = -\log 4 + 2 \cdot \mathrm{JSD}(p_{\text{data}} \,\|\, p_g)
```

<details>
<summary>최적 판별자와 JSD 유도</summary>

기댓값을 적분으로 쓰고 생성자의 분포를 `p_g{:math}`로 두면, 각 x에서 다음 식을 D(x)에 대해 최대화하는 문제가 된다.

```math
V(D, G) = \int_x \Big( p_{\text{data}}(x) \log D(x) + p_g(x) \log\big(1 - D(x)\big) \Big)\, dx
```

`a \log y + b \log(1 - y){:math}`는 `y = a/(a + b){:math}`에서 최댓값을 가지므로 `D^*(x){:math}`가 위 식이 된다. 이를 대입하고 두 분포의 평균 `m = (p_{\text{data}} + p_g)/2{:math}`를 쓰면 다음과 같다.

```math
V(D^*, G) = \mathbb{E}_{p_{\text{data}}}\!\left[\log \frac{p_{\text{data}}}{2m}\right] + \mathbb{E}_{p_g}\!\left[\log \frac{p_g}{2m}\right] = -\log 4 + D_{\mathrm{KL}}(p_{\text{data}} \,\|\, m) + D_{\mathrm{KL}}(p_g \,\|\, m)
```

두 KL 항의 합이 `2 \cdot \mathrm{JSD}(p_{\text{data}} \,\|\, p_g){:math}`이다. JSD는 0 이상이고 두 분포가 같은 경우에만 0이므로, 생성자의 최적점은 `p_g = p_{\text{data}}{:math}`이다.

</details>

따라서 전역 최적점은 `p_g = p_{\text{data}}{:math}`이고, 이 시각에 판별자는 모든 입력에 `D^*(x) = 1/2{:math}`을 출력한다.

> [!TIP] 비포화 손실
> 학습 초기에는 D가 가짜를 쉽게 구별해 `\log(1 - D(G(z))){:math}`의 기울기가 거의 0이 된다. 원 논문은 G가 `\log(1 - D(G(z))){:math}`를 최소화하는 대신 `\log D(G(z)){:math}`를 최대화하도록 바꿔 초기 기울기를 키웠고, 실제 구현은 대부분 이 비포화(non-saturating) 손실을 사용한다.

### 학습 절차

원 논문의 학습 알고리즘은 판별자를 k번 갱신한 뒤 생성자를 한 번 갱신하는 과정을 반복한다. 논문의 실험은 k = 1을 사용했다.

| 단계 | 처리                                                                                                     |
| ---- | -------------------------------------------------------------------------------------------------------- |
| 1    | 잡음 분포에서 m개의 `z{:math}`, 데이터에서 m개의 `x{:math}`를 뽑는다                                     |
| 2    | `\frac{1}{m}\sum_i [\log D(x_i) + \log(1 - D(G(z_i)))]{:math}`의 기울기로 판별자를 상승시킨다 (k번 반복) |
| 3    | 새로 m개의 `z{:math}`를 뽑는다                                                                           |
| 4    | 생성자의 손실 기울기로 생성자를 하강시킨다. 판별자의 가중치는 이 단계에서 고정한다                       |

두 네트워크가 서로의 목표를 움직이므로 손실 값이 꾸준히 줄어들지 않는다. 판별자가 너무 강하면 생성자의 기울기가 사라지고, 너무 약하면 생성자가 엉뚱한 방향으로 이끌린다.

### GAN의 발전과 한계

GAN은 한 번의 순전파로 선명한 이미지를 만들어 수년간 이미지 생성의 최고 성능(SOTA) 자리를 지켰고, 얼굴 합성 같은 딥페이크에도 GAN 계열 기술이 쓰인다. 그러나 두 네트워크의 균형이 깨지면 학습이 발산하고, 생성자가 판별자를 속이는 몇 가지 표본만 반복 생성하는 모드 붕괴(mode collapse)가 발생한다. 판별자는 개별 표본의 진위만 판정하므로, 생성자가 데이터 분포의 일부 영역만 그럴듯하게 덮어도 손실이 낮아지기 때문이다. Dhariwal과 Nichol(2021)은 분류기 가이던스를 적용한 개선 디퓨전 모델(ADM-G)이 ImageNet 256×256에서 FID 4.59를 기록해 BigGAN-deep의 6.95보다 낮다는 결과를 보였고, 텍스트 조건 생성의 품질과 다양성에서 디퓨전 모델이 앞서면서 GAN은 상대적으로 주목을 덜 받게 되었다.

## VAE

### 오토인코더와 잠재 변수

VAE(Variational Autoencoder, 변분 오토인코더)는 Kingma와 Welling이 2013년 arXiv에 공개하고 ICLR 2014에 게재한 모델이다. 인코더가 입력 x를 저차원 잠재 변수 z로 압축하고 디코더가 z에서 x를 복원하는 오토인코더 구조를 따른다. 잠재 변수는 고양이 사진 한 장에 담긴 수많은 특징(털 색, 자세, 얼굴 방향 등)을 몇 개의 숫자로 압축한 표현이다.

일반 오토인코더는 입력마다 z를 한 점으로 대응시키므로 잠재 공간의 빈 곳에서 뽑은 z는 의미 있는 이미지로 복원되지 않는다. ==VAE는 인코더가 z의 분포 `q_\phi(z \mid x) = \mathcal{N}(\mu, \sigma^2 I){:math}`를 출력하고 그 분포를 표준 정규분포에 가깝게 규제해, 학습 후 `\mathcal{N}(0, I){:math}`에서 뽑은 z를 디코더에 넣어 새 데이터를 생성한다.== 이렇게 만든 고양이는 원본을 복사한 것이 아니라 비슷하게 생긴 새 고양이다.

![입력 x가 인코더를 거쳐 평균과 표준편차를 출력하고, 잡음 ε과 결합해 z를 만든 뒤 디코더가 복원하는 구조도](./images/dl-image-generation-17.svg 'VAE 구조와 재매개변수화 z = μ + σ ⊙ ε')

| 구분         | 오토인코더                 | VAE                                               |
| ------------ | -------------------------- | ------------------------------------------------- |
| 인코더 출력  | 잠재 벡터 한 점 z          | 분포의 매개변수 μ, σ                              |
| 손실         | 복원 오차                  | 복원 오차 + KL 규제(ELBO의 부호를 바꾼 값)        |
| 잠재 공간    | 학습 표본 주변만 의미 있음 | 원점 주변이 연속적으로 채워짐                     |
| 새 표본 생성 | 불가능에 가까움            | `z \sim \mathcal{N}(0, I){:math}`를 디코더에 입력 |

### 증거 하한(ELBO)

로그 가능도 `\log p_\theta(x){:math}`는 직접 계산할 수 없으므로, VAE는 그 하한인 ELBO(evidence lower bound)를 최대화한다.

```math
\log p_\theta(x) \ge \mathbb{E}_{q_\phi(z \mid x)}[\log p_\theta(x \mid z)] - D_{\mathrm{KL}}\big(q_\phi(z \mid x) \,\|\, p(z)\big)
```

첫째 항은 복원 오차(재구성 손실), 둘째 항은 인코더 분포가 사전 분포 `p(z) = \mathcal{N}(0, I){:math}`에서 멀어지지 않게 하는 규제 항이다. 잠재 차원이 J이면 KL 항은 닫힌 형태로 계산된다.

```math
D_{\mathrm{KL}} = -\frac{1}{2} \sum_{j=1}^{J} \left(1 + \log \sigma_j^2 - \mu_j^2 - \sigma_j^2\right)
```

<details>
<summary>ELBO의 유도</summary>

`p_\theta(x) = \int p_\theta(x \mid z)\, p(z)\, dz{:math}`는 모든 z에 대한 적분이라 계산할 수 없다. 대신 임의의 분포 `q_\phi(z \mid x){:math}`를 끼워 넣고 로그 가능도를 다음처럼 분해한다.

```math
\log p_\theta(x) = \underbrace{\mathbb{E}_{q_\phi}\!\left[\log \frac{p_\theta(x, z)}{q_\phi(z \mid x)}\right]}_{\text{ELBO}} + D_{\mathrm{KL}}\big(q_\phi(z \mid x) \,\|\, p_\theta(z \mid x)\big)
```

둘째 항은 KL 발산이므로 0 이상이고, 따라서 첫째 항은 로그 가능도의 하한이다. 첫째 항의 `p_\theta(x, z) = p_\theta(x \mid z)\, p(z){:math}`를 풀면 본문의 복원 항과 KL 규제 항이 나온다. ELBO를 최대화하면 가능도의 하한을 올리는 동시에 `q_\phi{:math}`가 계산할 수 없는 진짜 사후 분포 `p_\theta(z \mid x){:math}`에 가까워진다.

</details>

<details>
<summary>재매개변수화 기법</summary>

z를 `\mathcal{N}(\mu, \sigma^2){:math}`에서 직접 표본 추출하면 표본 추출 연산을 거쳐 μ, σ로 기울기가 전달되지 않는다. 원 논문은 무작위성을 별도 변수 `\epsilon \sim \mathcal{N}(0, I){:math}`로 분리했다.

```math
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon
```

이제 무작위성은 ε에만 있고 z는 μ, σ의 미분 가능한 함수이므로, 역전파로 인코더 매개변수 φ까지 학습할 수 있다.

</details>

### 흐릿한 출력과 이후의 변형

VAE는 학습이 안정적이고 잠재 공간이 연속적이지만, 생성 이미지가 흐릿한 경향이 있다. 디코더 분포를 가우시안 `p_\theta(x \mid z) = \mathcal{N}(\hat{x}, \sigma^2 I){:math}`로 두면 복원 항은 픽셀 단위 평균 제곱 오차가 되고, 한 z가 여러 그럴듯한 이미지에 대응하는 경우 제곱 오차를 가장 작게 만드는 출력은 그 이미지들의 평균이다. 털의 결이나 경계 위치처럼 조금씩 다른 세부가 평균되면서 흐려진다.

이후 연구는 잠재 변수를 이산화하는 방향으로 이어졌다. DALL·E(2021)는 이산 VAE(dVAE)로 256×256 이미지를 32×32 격자의 이미지 토큰(어휘 8,192개)으로 압축하고, 텍스트 토큰 뒤에 이미지 토큰을 자기회귀 트랜스포머로 이어 생성했다. VQGAN(Esser 등, 2020)은 코드북 양자화 오토인코더에 지각 손실과 패치 단위 판별자를 더해 압축률을 높여도 선명한 복원을 얻었다. 스테이블 디퓨전의 오토인코더는 이 VQGAN의 학습 방식을 이어받되, 양자화 대신 아주 작은 가중치의 KL 규제를 둔 연속 잠재 공간을 사용한다.

## 디퓨전 모델

### 확산 과정과 역확산 과정

디퓨전 모델(diffusion model, 확산 모델)은 Sohl-Dickstein 등(ICML 2015)이 제안하고 Ho 등의 DDPM(Denoising Diffusion Probabilistic Models, NeurIPS 2020)이 고품질 이미지 생성을 보이며 널리 쓰이게 되었다. ==데이터에 가우시안 잡음을 조금씩 더해 순수한 잡음으로 만드는 확산 과정(forward process)과, 잡음에서 조금씩 잡음을 제거해 데이터를 만드는 역확산 과정(reverse process)으로 이루어지며, 신경망은 역확산 과정만 학습한다.== 이름은 잉크 방울이 물에 퍼져 균일해지는 물리적 확산에서 왔다. 확산은 쉽게 일어나지만 되돌리기는 어렵고, 모델은 그 되돌리는 방향을 작은 단계로 나눠 배운다. 스테이블 디퓨전의 성공으로 최근 가장 주목받는 생성 모델이며, DALL·E 2, Imagen, 스테이블 디퓨전이 이 모델을 사용한다.

![원본 이미지 x0에서 x1, x2를 거쳐 순수한 잡음 z까지 실선 화살표로 잡음을 더하고, 점선 화살표로 잡음을 제거하며 되돌아오는 도식](./images/dl-image-generation-diffusion-steps.svg '디퓨전 모델은 가우시안 잡음을 점진적으로 더한 뒤 그 과정을 되돌린다')

![고양이 사진 x0에 잡음이 점점 많아져 완전한 잡음 xT가 되는 확산 과정과 그 반대 방향의 잡음 제거 과정](./images/dl-image-generation-13.jpg '위쪽 화살표가 순방향 확산 과정(Forward Diffusion Process), 아래쪽 화살표가 역방향 잡음 제거 과정(Reverse Denoising Process)이다. 확산 과정은 고정된 규칙이고, 역방향 잡음 제거를 신경망이 학습한다')

### 확산 과정의 수식

확산 과정은 학습할 매개변수가 없는 마르코프 연쇄다. 단계 t에서 분산 일정(variance schedule) `\beta_t{:math}`만큼 잡음을 더한다.

```math
q(x_t \mid x_{t-1}) = \mathcal{N}\big(x_t;\ \sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t I\big)
```

평균에 `\sqrt{1 - \beta_t}{:math}`를 곱해 신호를 조금 줄이는 이유는 분산을 1로 유지하기 위해서다. `x_{t-1}{:math}`의 분산이 1이면 `x_t{:math}`의 분산은 `(1 - \beta_t) + \beta_t = 1{:math}`이 되어, 단계를 거듭해도 값이 발산하지 않고 표준 정규분포로 수렴한다.

`\alpha_t = 1 - \beta_t{:math}`, `\bar\alpha_t = \prod_{s=1}^{t} \alpha_s{:math}`로 두면 가우시안의 합성 성질에 따라 임의의 t를 한 번에 추출할 수 있다.

```math
q(x_t \mid x_0) = \mathcal{N}\big(x_t;\ \sqrt{\bar\alpha_t}\, x_0,\ (1 - \bar\alpha_t) I\big), \qquad x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon
```

DDPM은 `T = 1000{:math}`, `\beta_1 = 10^{-4}{:math}`에서 `\beta_T = 0.02{:math}`까지 선형으로 늘어나는 일정을 사용했다. t가 T에 가까워지면 `\bar\alpha_t \approx 0{:math}`이 되어 `x_T{:math}`는 표준 정규분포를 따른다.

이 일정으로 `\bar\alpha_t{:math}`를 직접 계산하면 원본 신호의 계수 `\sqrt{\bar\alpha_t}{:math}`가 줄고 잡음의 계수 `\sqrt{1 - \bar\alpha_t}{:math}`가 1로 커지는 속도를 확인할 수 있다.

| t    | `\bar\alpha_t{:math}`       | `\sqrt{\bar\alpha_t}{:math}` (원본 계수) | `\sqrt{1 - \bar\alpha_t}{:math}` (잡음 계수) |
| ---- | --------------------------- | ---------------------------------------- | -------------------------------------------- |
| 100  | 0.897                       | 0.947                                    | 0.321                                        |
| 250  | 0.524                       | 0.724                                    | 0.690                                        |
| 500  | 0.079                       | 0.280                                    | 0.960                                        |
| 1000 | `4.0 \times 10^{-5}{:math}` | 0.006                                    | 1.000                                        |

t = 250 부근에서 원본과 잡음의 비중이 비슷해지고, t = 500이면 원본 계수가 0.28, 잡음 계수가 0.96으로 잡음이 신호의 대부분을 차지한다.

### 학습 목표: 잡음 예측

역확산 과정 `p_\theta(x_{t-1} \mid x_t){:math}`도 가우시안으로 두고 그 평균을 신경망으로 표현한다. 원래 목표는 VAE와 같은 ELBO이지만, DDPM은 평균 대신 `x_t{:math}`에 섞인 잡음 ε을 예측하도록 매개변수화하고 가중치를 없앤 단순 손실이 더 좋은 표본을 만든다는 것을 보였다.

```math
L_{\text{simple}} = \mathbb{E}_{t,\, x_0,\, \epsilon}\Big[\big\| \epsilon - \epsilon_\theta\big(\sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon,\ t\big) \big\|^2\Big]
```

<details>
<summary>ELBO에서 잡음 예측 손실까지</summary>

디퓨전 모델을 잠재 변수가 `x_1, \dots, x_T{:math}`인 VAE로 보면, 확산 과정 q가 인코더, 역확산 과정 `p_\theta{:math}`가 디코더 역할을 한다. 음의 ELBO는 단계별 KL 항의 합으로 분해된다.

```math
L = \underbrace{D_{\mathrm{KL}}\big(q(x_T \mid x_0) \,\|\, p(x_T)\big)}_{L_T} + \sum_{t > 1} \underbrace{D_{\mathrm{KL}}\big(q(x_{t-1} \mid x_t, x_0) \,\|\, p_\theta(x_{t-1} \mid x_t)\big)}_{L_{t-1}} \underbrace{-\, \log p_\theta(x_0 \mid x_1)}_{L_0}
```

`L_T{:math}`는 학습할 매개변수가 없는 상수다. `x_0{:math}`를 알면 한 단계 전의 분포 `q(x_{t-1} \mid x_t, x_0){:math}`는 베이즈 정리로 닫힌 형태의 가우시안이 된다.

```math
\tilde\mu_t(x_t, x_0) = \frac{\sqrt{\bar\alpha_{t-1}}\, \beta_t}{1 - \bar\alpha_t}\, x_0 + \frac{\sqrt{\alpha_t}\,(1 - \bar\alpha_{t-1})}{1 - \bar\alpha_t}\, x_t, \qquad \tilde\beta_t = \frac{1 - \bar\alpha_{t-1}}{1 - \bar\alpha_t}\, \beta_t
```

두 가우시안 사이의 KL은 평균의 제곱 거리에 비례하므로 `L_{t-1}{:math}`는 신경망 평균 `\mu_\theta{:math}`가 `\tilde\mu_t{:math}`를 맞히는 회귀 문제가 된다. 여기에 `x_0 = (x_t - \sqrt{1 - \bar\alpha_t}\, \epsilon) / \sqrt{\bar\alpha_t}{:math}`를 대입하면 `\tilde\mu_t{:math}`는 `x_t{:math}`와 ε만으로 표현되고, 평균을 다음처럼 매개변수화하면 결국 ε을 맞히는 문제가 된다.

```math
\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{\beta_t}{\sqrt{1 - \bar\alpha_t}}\, \epsilon_\theta(x_t, t) \right), \qquad L_{t-1} = \frac{\beta_t^2}{2 \sigma_t^2\, \alpha_t\, (1 - \bar\alpha_t)} \big\| \epsilon - \epsilon_\theta(x_t, t) \big\|^2 + C
```

DDPM은 앞의 가중치를 1로 바꾼 `L_{\text{simple}}{:math}`가 표본 품질이 더 좋다는 것을 실험으로 보였다. 가중치를 없애면 잡음이 적은 작은 t의 비중이 줄고, 더 어려운 큰 t의 잡음 제거에 학습이 집중된다.

</details>

| 단계 | 학습(한 번의 갱신)                                                | 생성(표본 추출)                                          |
| ---- | ----------------------------------------------------------------- | -------------------------------------------------------- |
| 1    | 데이터에서 `x_0{:math}`, 균등분포에서 t, 표준 정규분포에서 ε 추출 | `x_T \sim \mathcal{N}(0, I){:math}`                      |
| 2    | 위 식으로 `x_t{:math}`를 한 번에 계산                             | t = T, …, 1 순서로 `\epsilon_\theta(x_t, t){:math}` 계산 |
| 3    | 예측 잡음과 실제 잡음의 제곱 오차로 경사 하강                     | 아래 식으로 `x_{t-1}{:math}` 계산                        |

```math
x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar\alpha_t}}\, \epsilon_\theta(x_t, t) \right) + \sigma_t z, \qquad z \sim \mathcal{N}(0, I)
```

`\sigma_t^2{:math}`는 DDPM에서 `\beta_t{:math}`로 두고, 마지막 단계(`t = 1{:math}`)에서는 `z = 0{:math}`으로 잡음을 더하지 않는다.

학습 단계는 t를 무작위로 하나 골라 한 번의 순전파와 역전파만 수행하므로, 1,000단계짜리 과정을 학습하면서도 매 갱신의 비용은 일반 회귀 모델과 같다. 반복 비용은 생성 단계에만 남는다.

> [!IMPORTANT] 디퓨전과 GAN·VAE의 차이
> 디퓨전 모델은 한 번에 이미지를 만들지 않고 잡음 제거를 수백에서 천 번 반복한다. 매 단계 문제는 "조금 덜 시끄러운 이미지 예측"이라는 쉬운 회귀 문제여서 학습이 안정적이고 모드 붕괴가 거의 없지만, 생성 시각에 같은 네트워크를 여러 번 실행해야 하므로 느리다. DDIM 같은 샘플러는 단계를 건너뛰어 수십 번으로 줄인다.

### DDIM: 단계를 건너뛰는 표본 추출

Song 등의 DDIM(Denoising Diffusion Implicit Models, ICLR 2021)은 학습은 DDPM과 똑같이 하고 표본 추출 식만 바꾼다. 매 단계에서 예측한 잡음으로 원본 `x_0{:math}`를 먼저 추정하고, 그 추정치를 원하는 이전 단계의 잡음 수준으로 다시 섞는다.

```math
\hat{x}_0 = \frac{x_t - \sqrt{1 - \bar\alpha_t}\, \epsilon_\theta(x_t, t)}{\sqrt{\bar\alpha_t}}, \qquad x_{t-1} = \sqrt{\bar\alpha_{t-1}}\, \hat{x}_0 + \sqrt{1 - \bar\alpha_{t-1} - \sigma_t^2}\; \epsilon_\theta(x_t, t) + \sigma_t z
```

`\sigma_t = 0{:math}`으로 두면 무작위성이 없는 결정적 과정이 되어, 같은 시작 잡음은 항상 같은 이미지로 바뀐다. 이 식은 인접한 단계가 아니어도 성립하므로 1,000단계 가운데 50개의 t만 골라 건너뛰며 계산할 수 있다.

잡음 예측 신경망으로는 [의미 분할의 성능 평가와 FCN·DeconvNet·U-Net](/memo/dl-segmentation)에서 다룬 U-Net을 사용한다. 입력과 출력의 크기가 같고, 스킵 연결로 세밀한 공간 정보를 보존하기 때문이다.

## 스테이블 디퓨전

### 공개 배경

스테이블 디퓨전은 2022년 8월 22일 Stability AI가 CompVis(LMU 뮌헨)와 Runway와 함께 오픈 소스로 공개한 텍스트-이미지 생성 모델로, 가장 널리 쓰이는 이미지 생성 모델 중 하나다. 기반 논문은 Rombach 등의 「High-Resolution Image Synthesis with Latent Diffusion Models」(CVPR 2022)다. 스테이블 디퓨전의 접근성은 세 가지로 요약된다.

| 접근성       | 내용                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 오픈 소스    | 코드와 학습된 가중치를 공개해 누구나 내려받아 수정·재배포할 수 있다    |
| 일반 PC 추론 | 잠재 공간에서 연산해 VRAM 10GB 미만의 소비자용 GPU에서도 생성한다      |
| 프롬프트     | 텍스트 입력만으로 이미지를 생성하고, 인페인팅·이미지 변환으로 확장된다 |

가중치 공개는 쓰임새도 넓혔다. 이미지 바깥을 이어 그리는 아웃페인팅(outpainting), 일부만 다시 그리는 인페인팅(inpainting), Segment Anything(SAM)으로 분할한 배경만 새로 생성하는 편집이 모두 같은 모델 위에서 구현되었다. 원리는 뒤의 응용 절에서 다룬다.

### 학습 데이터

다양한 프롬프트에 대응하려면 방대하고 다양한 이미지-텍스트 쌍이 필요하다. 웹 페이지 작성자가 접근성과 검색 엔진을 위해 이미지에 붙인 대체 텍스트(alt 텍스트)를 캡션으로 쓰면 수억 장 규모의 데이터를 모을 수 있다. 예를 들어 뉴스 기사의 증권거래소 사진에는 `alt="Traders on the floor of the stock exchange."` 같은 설명이 붙어 있고, 허블 망원경 사진에는 "a picture of space taken by the Hubble telescope" 같은 설명이 붙는다. 엔지니어는 이렇게 웹에서 거대한 데이터셋을 얻는다.

![보라색 배경에 색 사각형 이미지와 그 아래 캡션 칸이 격자로 늘어서 있고, 한 칸에 허블 망원경 우주 사진과 캡션이 있는 도식](./images/dl-image-generation-23.jpg '웹에서 수집한 이미지-캡션 쌍의 격자. 칸마다 "위 이미지를 설명하는 캡션"이 붙고, 가운데 허블 사진의 캡션은 "허블 망원경으로 찍은 우주 사진"이다. 캡션은 웹 페이지의 alt 텍스트에서 온다')

스테이블 디퓨전 v1은 Common Crawl에서 이런 쌍 약 58억 5천만 개를 추출한 LAION-5B의 영어 부분집합(LAION-2B-en, 약 23억 쌍)과, 그중 미적 점수가 높은 부분집합(LAION-Aesthetics)으로 학습했다. LAION-5B는 웹 페이지에서 이미지와 alt 텍스트를 뽑은 뒤, CLIP으로 이미지와 텍스트의 임베딩 유사도를 계산해 영어 쌍은 코사인 유사도 0.28 미만을 버리는 방식으로 정제했다. 캡션이 이미지와 무관한 쌍(파일 이름, "image1.jpg", 광고 문구)을 걸러 내는 단계다. 사람이 쌍마다 검수하지 않으므로, 폭력적이거나 성적인 이미지, 저작권이 있는 작품, 개인 사진이 함께 들어간다는 문제가 이 단계에서 이미 생긴다.

학습은 256×256에서 시작해 512×512로 해상도를 올렸고, 공개판 v1-4는 LAION-Aesthetics v2 5+(미적 점수 5 이상)로 이어서 학습하면서 텍스트 조건의 10%를 비워 분류기 없는 가이던스에 대비했다.

### 잠재 공간

프롬프트에 "1960년대 사진 속, 스노우 글로브 안의 바나나"를 입력한 상황을 가정한다. 흔한 오해는 모델이 학습 데이터에서 바나나와 스노우 글로브 이미지를 찾아 픽셀 일부를 복사하고 조합해 결과를 만든다는 생각이다. 실제 모델은 이런 방식으로 동작하지 않는다.

![학습 데이터 격자 위에 바나나와 스노우 글로브 사진이 잘려 붙은 도식](./images/dl-image-generation-04.jpg '학습 이미지의 픽셀을 오려 붙인다는 오해. 두 캡션은 "빨간 받침의 빈 스노우 글로브"와 "탁자 위 나무 접시에 놓인 바나나"이다')

![A banana inside a snowglobe from 1960 프롬프트 아래 학습 데이터 격자와, 바나나를 스노우 글로브 안에 오려 붙인 출력이 나란히 놓인 도식](./images/dl-image-generation-24.jpg '오려 붙이기 가설대로라면 나올 출력. 프롬프트(PROMPT)는 "1960년의 스노우 글로브 속 바나나", 왼쪽은 학습 데이터(TRAINING DATA), 오른쪽은 출력(OUTPUT)이다. 두 사진을 합성한 콜라주이고, 1960년대 사진의 질감은 어디에도 없다')

오려 붙이기 가설에는 두 가지 문제가 있다. 첫째, 이 방식으로는 학습 데이터에 없는 질감이나 시대 분위기를 만들 수 없다. 둘째, 스테이블 디퓨전 v1의 가중치 파일은 약 4GB이고 학습 이미지는 20억 장이 넘으므로, 이미지 한 장당 평균 2바이트 정도밖에 저장할 수 없다. 모델은 개별 이미지를 보관하지 않고, 수많은 이미지에 공통된 규칙을 매개변수에 압축한다.

==새 이미지는 학습 데이터에서 직접 나오지 않고, 모델이 학습 과정에서 구축한 잠재 공간(latent space)에서 나온다.==

![학습 데이터와 출력 사이에 LATENT라고 적힌 오각형이 놓인 도식](./images/dl-image-generation-05.jpg '학습 데이터(TRAINING DATA)와 출력(OUTPUT) 사이에 잠재 공간(LATENT)이 있다. 위쪽 막대는 프롬프트(PROMPT) 입력 칸이다')

사람에게는 사진과 캡션을 짝짓는 일이 쉽지만, 이미지를 픽셀 값 배열로만 받으면 사람은 규칙을 찾을 수 없다. 컴퓨터는 픽셀 배열 자체를 입력으로 받으므로, 같은 학습을 반복해 어떤 배열이 바나나이고 어떤 배열이 풍선인지 구분하는 수학적 공간을 찾는다. 이것이 딥러닝이 하는 일이다.

![사진 세 장이 각각 숫자 격자로 바뀌고 아래에 캡션이 붙은 도식](./images/dl-image-generation-06.jpg '컴퓨터에게 이미지는 픽셀 값의 배열이다(숫자는 실제 픽셀 값이 아닌 예시). 캡션은 왼쪽부터 "크리스마스트리 아래 앉은 고양이 삭스", "1968년 4월 반전 시위에서 팻말을 든 시위대", "일리노이주 시카고의 공장 천장에 매달린 지구본"이다')

예를 들어 노란 정도(yellowness) 하나를 측정하면 바나나와 빨간 풍선은 1차원 축 위에서 잘 분리된다.

![노란 정도 축 위에 빨간 풍선은 왼쪽, 바나나는 오른쪽에 놓이고 가운데에 경계가 있는 1차원 공간](./images/dl-image-generation-07.svg '변수 하나(노란 정도)로 만든 1차원 공간')

학습 데이터에 노란 풍선이 들어오면 노란 풍선과 바나나가 비슷한 위치에 놓여, 이 1차원 공간은 더 이상 둘을 구분하는 좋은 방법이 아니다.

![노란 정도 축 위에 노란 풍선과 바나나가 거의 같은 위치에 놓인 1차원 공간](./images/dl-image-generation-08.svg '노란 풍선이 추가되면 변수 하나로는 분리되지 않는다')

둥근 정도(roundness)를 둘째 축으로 추가하면 2차원 공간에서 다시 분리된다. 풍선은 둥글어서 위쪽에, 길쭉한 바나나는 아래쪽에 놓이므로 수평선 하나가 경계가 된다.

![노란 정도와 둥근 정도의 2차원 평면에서 두 풍선은 위쪽, 바나나는 아래쪽에 놓여 수평 경계로 분리되는 그림](./images/dl-image-generation-09.svg '둥근 정도를 추가한 2차원 공간')

그러나 둥글고 노란 바나나 조각, 길쭉한 T자 모양 은색 풍선 같은 데이터가 추가되면 이 공간도 충분하지 않다. 바나나 조각은 노란 풍선 옆 위쪽에, T자 풍선은 바나나와 같은 아래쪽에 놓여 수평 경계가 두 범주를 모두 잘못 나눈다.

![노란 정도와 둥근 정도의 2차원 평면에 빨간 풍선, 노란 풍선, 바나나 조각, 바나나, T자 은색 풍선이 놓여 경계로 나눌 수 없는 그림](./images/dl-image-generation-25.jpg 'T자 풍선과 바나나 조각이 학습 데이터(TRAINING DATA)에 추가된 2차원 공간. 가로축은 노란 정도(YELLOWNESS), 세로축은 둥근 정도(ROUNDNESS)이다. 바나나 조각은 풍선 쪽에, T자 풍선은 바나나 쪽에 놓인다')

광택(shininess)을 셋째 축으로 추가하면 은색 T자 풍선은 광택 축 방향으로 떨어져 나가고, 3차원 공간에서 다시 범주가 나뉜다.

![광택, 노란 정도, 둥근 정도의 세 축 위에 풍선, 바나나, 바나나 조각, 금속 도구가 놓인 3차원 공간](./images/dl-image-generation-10.jpg '광택(SHININESS)을 추가한 3차원 공간(3-DIMENSIONAL SPACE). 나머지 두 축은 노란 정도(YELLOWNESS)와 둥근 정도(ROUNDNESS)이다')

새 이미지가 들어오면 세 변수를 측정해 바나나 영역인지 풍선 영역인지 판단할 수 있다. 문제는 바나나와 풍선뿐 아니라 세상의 모든 물체를 인식해야 한다는 점이고, 노란 정도, 둥근 정도, 광택만으로는 대부분의 물체 특징을 담지 못한다. 더 나은 변수와 더 많은 변수가 필요하고, 학습 데이터로 이 변수를 찾는 일이 딥러닝 알고리즘의 작업이다. 딥러닝 알고리즘은 작업 성능을 높이는 변수를 스스로 찾으며 이 과정에서 3차원을 훨씬 넘는 잠재 공간을 구축한다. 스테이블 디퓨전의 잠재 공간은 사람이 인지할 수 있는 3차원 공간을 넘어 수많은 차원으로 이루어진다.

잠재 공간의 축은 사람이 이름 붙일 수 없는 변수지만, 의미 있는 군집이 형성된다. 바나나다움을 포착하는 영역, 1960년대 사진의 질감과 색감을 나타내는 영역, 그리고 지구본(globe)과 눈(snow) 영역 사이 어딘가에 스노우 글로브 영역이 생긴다. 바나나 군집 주변에는 질경이 바나나(plantain), 사과, 파인애플 같은 다른 과일과 껍질, 아침 식사 같은 연관 개념이 놓이고, 1960년대 군집 주변에는 코닥크롬 필름, 필름 그레인, 사이키델릭, 팝 아트가 놓인다. 잠재 공간의 각 점은 수많은 차원 값의 조합이자 가능한 이미지 하나의 레시피이고, 프롬프트의 텍스트는 이 공간에서 생성할 지점을 가리킨다. "1960년대 사진 속, 스노우 글로브 안의 바나나"라는 프롬프트는 바나나 군집, 1960년대 사진 군집, 스노우 글로브 군집의 성질을 함께 지닌 지점으로 이동한다.

![어두운 공간에 banana, 1960s, snow, globes, snowglobes 군집과 주변 연관어가 흩어져 있는 그림](./images/dl-image-generation-11.jpg '잠재 공간 속 의미 군집. 바나나(banana) 둘레에는 껍질·아침 식사·딸기 같은 연관어가, 1960년대(1960s) 둘레에는 코다크롬·필름 그레인·팝 아트가 놓이고, 스노우 글로브(snowglobes)는 눈(snow)과 지구본(globes) 사이에 놓인다')

> [!NOTE]
> 이 절의 오려 붙이기 오해, 픽셀 배열, 2차원·3차원 공간, 의미 군집, 생성 흐름 그림은 Vox의 설명 영상 [「AI art, explained」](https://www.youtube.com/watch?v=SVcsDDABEkM)(2022년 6월) 장면이고, 1차원·2차원 축 도식은 같은 영상의 예시를 바탕으로 다시 그렸다. 실제 모델의 잠재 차원은 사람이 해석할 수 있는 축이 아니며, 스테이블 디퓨전의 잠재 텐서는 64×64×4 = 16,384차원이다.

이 직관은 실제 모델의 두 공간에 나눠 대응한다. 프롬프트의 의미가 놓이는 공간은 CLIP 텍스트 인코더의 임베딩 공간이고, 이미지가 놓이는 공간은 오토인코더의 64×64×4 잠재 공간이다. 디퓨전 U-Net은 텍스트 임베딩을 참고해 잡음에서 잠재 이미지를 만들어 두 공간을 잇는다. 다음 절부터 세 구성 요소를 차례로 살핀다.

### 잠재 디퓨전 모델의 구조

픽셀 공간의 디퓨전은 512×512×3 = 786,432차원 텐서에 U-Net을 수십 번 실행해야 해서 학습과 추론 비용이 크다. ==잠재 디퓨전 모델(LDM)은 오토인코더로 이미지를 작은 잠재 텐서로 압축한 뒤, 디퓨전을 그 잠재 공간에서 수행한다.== 지각적으로 중요하지 않은 고주파 세부 사항은 오토인코더가 담당하고, 디퓨전은 의미와 구도에 집중한다.

| 구성 요소                      | 역할                                                    | 스테이블 디퓨전 v1 설정                    |
| ------------------------------ | ------------------------------------------------------- | ------------------------------------------ |
| 오토인코더 E, D                | 이미지 ↔ 잠재 텐서 변환 (KL 규제를 둔 VAE)              | 다운샘플링 비율 f = 8, 512×512×3 ↔ 64×64×4 |
| U-Net `\epsilon_\theta{:math}` | 잠재 텐서의 잡음 예측, 교차 어텐션으로 텍스트 조건 주입 | 약 8억 6천만 매개변수                      |
| 텍스트 인코더 τ                | 프롬프트를 토큰 임베딩 시퀀스로 변환                    | 고정된 CLIP ViT-L/14, 77토큰 × 768차원     |

압축 비율을 확인하면 `512 / 8 = 64{:math}`이므로 잠재 텐서는 `64 \times 64 \times 4 = 16{,}384{:math}`차원이고, 픽셀 텐서 786,432차원의 1/48이다.

![잡음 z_T가 CLIP 텍스트 인코더 출력을 조건으로 받는 U-Net을 반복 통과해 z_0가 되고, VAE 디코더가 512×512 이미지로 복원하는 구조도](./images/dl-image-generation-18.svg '잠재 공간에서 잡음을 반복 제거한 뒤 디코더로 이미지를 복원한다')

LDM은 학습을 두 단계로 나눈다. 먼저 오토인코더를 한 번 학습해 고정하고, 그 위에서 디퓨전 모델을 학습한다. 오토인코더 학습에는 픽셀 복원 오차에 더해 사전 학습한 신경망의 특징 거리를 비교하는 지각 손실(perceptual loss)과, 복원 이미지의 작은 패치가 진짜처럼 보이도록 하는 패치 단위 적대적 손실을 함께 쓴다. VAE 절에서 본 흐릿한 복원 문제를 판별자로 보완한 것이다. KL 규제의 가중치는 `10^{-6}{:math}` 정도로 아주 작게 두어, 잠재 공간의 분산이 무한히 커지는 것만 막고 복원 품질은 거의 해치지 않게 한다.

다운샘플링 비율 f는 품질과 비용의 균형점이다. 논문은 f를 1에서 32까지 바꿔 비교했다.

| f    | 결과                           |
| ---- | ------------------------------ |
| 1    | 픽셀 공간. 학습이 느리다       |
| 4~16 | 효율과 품질의 균형이 가장 좋다 |
| 32   | 압축이 지나쳐 품질이 떨어진다  |

스테이블 디퓨전은 f = 8을 택했다. 같은 오토인코더를 모든 생성 작업에 재사용할 수 있다는 점도 장점이다. 오토인코더는 텍스트와 무관하게 이미지 압축만 학습하므로, 텍스트-이미지 생성, 초해상도, 인페인팅 같은 서로 다른 디퓨전 모델이 같은 잠재 공간을 공유한다.

LDM의 학습 목표는 DDPM의 잡음 예측 손실을 잠재 변수 `z = \mathcal{E}(x){:math}`와 조건 y에 대해 쓴 것이다.

```math
L_{\text{LDM}} = \mathbb{E}_{\mathcal{E}(x),\, y,\, \epsilon \sim \mathcal{N}(0, 1),\, t}\Big[\big\| \epsilon - \epsilon_\theta\big(z_t, t, \tau_\theta(y)\big) \big\|_2^2\Big]
```

텍스트 조건은 U-Net 중간 층의 교차 어텐션(cross-attention)으로 들어간다. 쿼리는 이미지 잠재 특징 `\varphi_i(z_t){:math}`에서, 키와 값은 텍스트 임베딩 `\tau_\theta(y){:math}`에서 만든다.

```math
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right) V, \quad Q = W_Q\, \varphi_i(z_t),\ K = W_K\, \tau_\theta(y),\ V = W_V\, \tau_\theta(y)
```

이 식은 [트랜스포머의 셀프 어텐션과 멀티 헤드 어텐션](/memo/dl-transformer)의 스케일드 내적 어텐션과 같다. 이미지의 각 위치가 프롬프트의 어떤 단어에 주목할지 계산해, "바나나" 토큰은 바나나가 놓일 영역에, "1960s" 토큰은 전체 색감에 영향을 준다.

64×64 해상도 층에 크기를 대입하면 다음과 같다.

| 행렬          | 크기       | 행 하나의 의미                           |
| ------------- | ---------- | ---------------------------------------- |
| Q             | 4,096 × d  | 이미지의 한 위치                         |
| K, V          | 77 × d     | 프롬프트 토큰 하나                       |
| 어텐션 가중치 | 4,096 × 77 | 이미지의 한 위치가 가진 토큰별 주목 비율 |

이 행렬을 토큰별로 잘라 이미지 크기로 펼치면 단어마다 영향을 준 영역을 시각화할 수 있다.

### CLIP 텍스트 인코더

텍스트 인코더 τ는 OpenAI의 CLIP(Contrastive Language-Image Pre-training, Radford 등, 2021)에서 텍스트 쪽 트랜스포머만 떼어 온 것이다. CLIP은 웹에서 모은 이미지-텍스트 쌍 4억 개로 이미지 인코더와 텍스트 인코더를 함께 학습해, 서로 짝인 이미지와 문장은 같은 임베딩 공간에서 가깝게, 짝이 아닌 것은 멀게 놓이도록 만든다.

학습은 배치 단위의 대조 학습(contrastive learning)이다. 배치에 N개의 쌍이 있으면 이미지 임베딩 `I_i{:math}`와 텍스트 임베딩 `T_j{:math}`를 L2 정규화한 뒤 N×N 코사인 유사도 행렬을 만들고, 대각선의 N개 쌍만 정답으로 두는 분류 문제를 행 방향과 열 방향으로 각각 푼다.

```math
L_{\text{CLIP}} = \frac{1}{2N} \sum_{i=1}^{N} \left[ -\log \frac{\exp(s\, I_i \cdot T_i)}{\sum_{j} \exp(s\, I_i \cdot T_j)} - \log \frac{\exp(s\, I_i \cdot T_i)}{\sum_{j} \exp(s\, I_j \cdot T_i)} \right]
```

s는 학습 가능한 온도(temperature)의 역수로, 유사도 차이를 얼마나 날카롭게 확률로 바꿀지 정한다. CLIP은 배치 크기 32,768을 사용했으므로, 정답 쌍 하나마다 32,767개의 오답과 비교하며 학습한다. 이 학습을 마치면 "노란 바나나"라는 문장의 임베딩은 노란 바나나 사진의 임베딩과 가까운 위치에 놓인다. 텍스트 인코더가 이미지와 정렬된 의미 공간을 이미 알고 있으므로, 디퓨전 모델은 그 공간을 조건으로 받기만 하면 된다.

| 항목                 | CLIP ViT-L/14 텍스트 인코더 (스테이블 디퓨전 v1)                     |
| -------------------- | -------------------------------------------------------------------- |
| 토크나이저           | 바이트 단위 BPE, 어휘 49,408개                                       |
| 최대 길이            | 77토큰 (시작·끝 토큰 포함, 실제 프롬프트는 75토큰)                   |
| 구조                 | 12층 트랜스포머, 폭 768, 인과적 마스크                               |
| 디퓨전에 넘기는 출력 | 마지막 층의 토큰별 은닉 상태 77 × 768 (문장 하나의 요약 벡터가 아님) |
| 학습 여부            | 고정(동결). 디퓨전 학습 중 갱신하지 않는다                           |

디퓨전 모델은 CLIP의 문장 요약 벡터 하나가 아니라 토큰별 은닉 상태 77개를 받는다. 교차 어텐션이 이미지 위치마다 서로 다른 토큰에 주목하려면 단어 단위 정보가 남아 있어야 하기 때문이다. 75토큰을 넘는 프롬프트는 잘리므로 뒤쪽 단어는 결과에 반영되지 않고, 인과적 마스크 때문에 앞쪽 토큰의 표현은 뒤쪽 단어를 보지 못한다. 프롬프트 앞쪽에 둔 단어가 결과에 더 강하게 반영되는 경향은 이 구조와 관련이 있다.

### U-Net 잡음 예측기

U-Net `\epsilon_\theta(z_t, t, \tau_\theta(y)){:math}`는 세 입력을 받아 `z_t{:math}`와 같은 크기의 잡음 예측을 출력한다. 의미 분할의 U-Net과 같은 인코더-디코더 대칭 구조에 스킵 연결을 두지만, 디퓨전용으로 세 가지가 더해졌다.

| 구성                 | 역할                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| 잔차 블록(ResBlock)  | 합성곱 두 층과 잔차 연결. 시간 단계 임베딩을 더해 현재 잡음 수준을 알려 준다                             |
| 공간 트랜스포머 블록 | 셀프 어텐션(이미지 위치끼리) → 교차 어텐션(이미지 위치 → 텍스트 토큰) → 피드포워드                       |
| 시간 단계 임베딩     | t를 사인·코사인 위치 인코딩으로 바꾼 뒤 MLP를 거쳐 모든 잔차 블록에 더한다                               |
| 해상도 단계          | 64 → 32 → 16 → 8, 채널 320 → 640 → 1280 → 1280. 어텐션은 64, 32, 16 해상도와 가운데 8 해상도 블록에 둔다 |

시간 단계 t가 필요한 이유는 같은 U-Net이 1,000가지 잡음 수준을 모두 처리하기 때문이다. t가 크면 입력의 대부분이 잡음이므로 전체 구도를 잡는 것이 중요하고, t가 작으면 세부를 다듬는 것이 중요하다. 사인·코사인 임베딩은 트랜스포머의 위치 인코딩과 같은 형태로, 정수 t를 연속 벡터로 바꿔 네트워크가 인접한 t를 비슷하게 다루게 한다.

셀프 어텐션은 이미지의 먼 위치끼리 정보를 주고받게 해 전체 구도를 맞추고, 교차 어텐션은 각 위치가 프롬프트의 어떤 단어를 그려야 하는지 정한다. 셀프 어텐션의 연산량은 위치 수의 제곱에 비례하므로, 64×64 해상도에서는 어텐션 행렬이 4,096×4,096이 되어 메모리 사용이 가장 크다.

### 분류기 없는 가이던스

조건부 디퓨전 모델을 그대로 표본 추출하면 프롬프트와 느슨하게만 맞는 이미지가 나오는 경우가 많다. 가이던스(guidance)는 생성 시각에 조건 쪽으로 더 강하게 끌어당기는 기법이다.

Dhariwal과 Nichol(2021)의 분류기 가이던스(classifier guidance)는 잡음이 섞인 이미지 `x_t{:math}`에서도 동작하는 분류기 `p_\phi(y \mid x_t){:math}`를 따로 학습하고, 그 로그 확률의 기울기를 잡음 예측에 더했다. 성능은 좋았지만 잡음 수준마다 동작하는 분류기를 별도로 학습해야 하고, 텍스트처럼 범주가 정해지지 않은 조건에는 쓰기 어렵다.

Ho와 Salimans의 분류기 없는 가이던스(classifier-free guidance, 2021)는 별도 분류기 없이 같은 효과를 낸다. 학습 시각에 일정 비율(스테이블 디퓨전은 10%)로 텍스트 조건을 빈 문자열로 바꿔, 하나의 U-Net이 조건부 잡음 예측과 무조건 잡음 예측을 모두 학습하게 한다. 생성 시각에는 두 예측의 차이를 안내 척도 w(guidance scale)만큼 키운다.

```math
\tilde\epsilon_\theta(z_t, t, y) = \epsilon_\theta(z_t, t, \varnothing) + w \big(\epsilon_\theta(z_t, t, y) - \epsilon_\theta(z_t, t, \varnothing)\big)
```

<details>
<summary>가이던스 식의 유도</summary>

잡음 예측과 점수 함수(score function, 로그 밀도의 기울기)는 `\epsilon_\theta(x_t) \approx -\sqrt{1 - \bar\alpha_t}\, \nabla_{x_t} \log p(x_t){:math}`의 관계에 있다. 베이즈 정리로 조건부 로그 밀도를 분해하면 다음과 같다.

```math
\nabla_{x_t} \log p(x_t \mid y) = \nabla_{x_t} \log p(x_t) + \nabla_{x_t} \log p(y \mid x_t)
```

둘째 항이 분류기 가이던스가 별도 분류기로 계산하던 부분이다. 이 항을 w배로 키운 분포 `p(x_t)\, p(y \mid x_t)^w{:math}`에서 표본을 뽑고 싶다고 하자. 같은 베이즈 정리로 `\nabla \log p(y \mid x_t) = \nabla \log p(x_t \mid y) - \nabla \log p(x_t){:math}`이므로, 분류기 없이 조건부·무조건 모델의 차이로 이 항을 계산할 수 있다.

```math
\nabla \log p(x_t) + w\big(\nabla \log p(x_t \mid y) - \nabla \log p(x_t)\big)
```

이를 잡음 예측으로 바꾸면 본문의 식이 된다. 원 논문은 `\tilde\epsilon = (1 + w)\, \epsilon_\theta(z_t, y) - w\, \epsilon_\theta(z_t){:math}` 형태로 썼고, 본문의 w는 원 논문의 1 + w에 해당한다.

</details>

w가 클수록 프롬프트를 충실히 따르지만 다양성이 줄어든다.

| w       | 결과                                       |
| ------- | ------------------------------------------ |
| 1       | 일반 조건부 생성                           |
| 5~9     | 흔히 쓰는 범위. 스테이블 디퓨전 기본값 7.5 |
| 15 초과 | 채도와 대비가 과해지고 구도가 단조로워진다 |

매 단계 U-Net을 조건부와 무조건으로 두 번 실행해야 하므로 연산량은 두 배가 되며, 구현에서는 두 입력을 배치로 묶어 한 번에 계산한다. 무조건 예측 자리에 빈 문자열 대신 다른 문장을 넣으면, 그 문장에서 멀어지는 방향으로 이미지를 이끄는 부정 프롬프트(negative prompt)가 된다. "흐릿한, 저해상도" 같은 부정 프롬프트가 품질을 높이는 원리가 이것이다.

### 생성 과정

잠재 공간의 점을 실제 이미지로 바꾸는 단계가 앞에서 설명한 확산의 역과정이다. 순수한 잡음에서 시작해 잡음 제거를 반복하며 사람이 알아볼 수 있는 구성으로 픽셀을 배열한다. 스테이블 디퓨전에서 한 장의 이미지가 만들어지는 과정을 단계로 나누면 다음과 같다.

| 단계 | 처리                                                                                      |
| ---- | ----------------------------------------------------------------------------------------- |
| 1    | CLIP 텍스트 인코더가 프롬프트를 77개 토큰 임베딩(각 768차원)으로 바꾼다                   |
| 2    | 난수 시드로 64×64×4 잠재 텐서 `z_T{:math}`를 표준 정규분포에서 뽑는다                     |
| 3    | U-Net이 교차 어텐션으로 텍스트 임베딩을 참고해 잡음을 예측하고, 샘플러가 잡음을 덜어 낸다 |
| 4    | 3단계를 샘플러 단계 수(보통 20~50회)만큼 반복해 `z_0{:math}`를 얻는다                     |
| 5    | VAE 디코더가 `z_0{:math}`를 512×512×3 픽셀 이미지로 복원한다                              |

![학습 데이터, 딥러닝 삼각형, 잠재 공간 오각형, DIFFUSION 원, 스노우 글로브 속 바나나 출력이 차례로 이어진 도식](./images/dl-image-generation-14.jpg '학습 데이터(TRAINING DATA) → 딥러닝(DEEP LEARNING) → 잠재 공간(LATENT SPACE) → 디퓨전 생성(GENERATION) → 출력(OUTPUT). 프롬프트는 "1960년의 스노우 글로브 속 바나나"이다')

시작 잡음 `z_T{:math}`를 난수로 뽑으므로 같은 프롬프트에도 매번 다른 이미지가 나오고, 난수 시드를 고정하면 같은 이미지를 재현할 수 있다. 다른 데이터로 학습한 다른 모델은 잠재 공간 자체가 다르므로 같은 프롬프트에도 다른 결과를 낸다.

3단계의 샘플러는 같은 U-Net의 예측으로 다음 잡음 수준의 잠재 텐서를 계산하는 수치 해법이다. 디퓨전 과정을 연속 시간의 미분 방정식으로 보면, 샘플러는 그 방정식을 몇 단계로 나눠 푸는지와 어떤 고차 공식을 쓰는지에서 차이가 난다.

| 샘플러         | 출처          | 성질                                                 | 흔히 쓰는 단계 수 |
| -------------- | ------------- | ---------------------------------------------------- | ----------------- |
| DDPM           | Ho 등, 2020   | 매 단계 잡음을 다시 더하는 확률적 과정               | 1,000             |
| DDIM           | Song 등, 2021 | `\sigma_t = 0{:math}`이면 결정적, 단계 건너뛰기 가능 | 50                |
| PLMS           | Liu 등, 2022  | 이전 단계들의 예측을 함께 쓰는 선형 다단계법         | 50                |
| DPM-Solver(++) | Lu 등, 2022   | 디퓨전 ODE의 구조를 이용한 고차 해법                 | 10~25             |

스테이블 디퓨전 v1 공개 저장소의 사용 예는 PLMS 샘플러 50단계와 안내 척도 7.5를 사용했다. 단계 수를 줄이면 U-Net 실행 횟수가 그만큼 줄어 생성이 빨라지지만, 너무 적으면 세부가 뭉개지거나 잡음이 남는다.

### 응용: 이미지 변환, 인페인팅, 미세 조정

같은 모델로 텍스트-이미지 생성 이외의 작업을 하는 방법은 대부분 시작 잠재 텐서나 U-Net의 입력을 바꾸는 것이다.

| 작업                 | 방법                                                                                                                  |
| -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 이미지 변환          | 입력 이미지를 인코딩한 잠재 텐서에 강도(strength) × T 단계만큼 잡음을 더한 뒤, 그 단계부터 잡음을 제거한다(SDEdit)    |
| 인페인팅             | U-Net 입력에 마스크와 가린 이미지의 잠재 텐서를 추가 채널로 넣어(4 + 4 + 1 = 9채널), 가린 영역만 새로 그리게 학습한다 |
| 아웃페인팅·분할 편집 | 넓힌 캔버스의 바깥 영역이나 SAM이 분할한 영역을 마스크로 두고 인페인팅한다                                            |
| 구조 조건            | ControlNet이 윤곽선, 깊이 지도, 자세 골격을 받아 U-Net 인코더 사본으로 구조 정보를 더한다                             |
| 미세 조정            | 전체 미세 조정, DreamBooth(특정 대상 몇 장), LoRA(저랭크 가중치 차분만 학습)로 화풍이나 대상을 추가로 학습한다        |

이미지 변환의 강도는 원본을 얼마나 남길지 정한다. 강도 0.3이면 T의 30% 지점부터 시작하므로 원본의 구도와 색이 대부분 남고, 0.8이면 원본은 거의 잡음에 묻혀 대략의 배치만 남는다. 확산 과정의 계수 표에서 본 것처럼, 시작 단계가 클수록 원본 계수 `\sqrt{\bar\alpha_t}{:math}`가 작아지기 때문이다.

NovelAI Diffusion도 이런 미세 조정의 결과물이다. 가중치가 공개된 기반 모델 위에 특정 화풍의 이미지를 대량으로 추가 학습하면, 기반 모델이 이미 배운 형태와 조명 지식은 유지한 채 출력의 화풍만 바뀐다. 적은 비용으로 특정 화풍을 재현할 수 있다는 점이 뒤에서 다룰 저작권 논란의 기술적 배경이다.

## 한계와 전망

### 저작권

가장 큰 문제는 학습에 사용한 이미지다. 웹에서 수집한 학습 이미지와 생성 결과물의 저작권 문제는 아직 정리되지 않았다. 데이터에서 패턴을 추출하는 딥러닝의 성질상 특정 작가의 화풍을 학습해 재현할 수 있고, 이는 수많은 작가의 권리를 침해할 수 있다. 사용자들은 "James Gurney가 그린 자이언 국립공원"처럼 생존 작가의 이름을 프롬프트에 넣어 그 화풍의 그림을 만들었고, 잠재 공간에서 작가의 이름은 그 작가의 화풍 군집을 가리키는 좌표로 작동한다. 이렇게 만든 그림의 작가가 프롬프트를 쓴 사용자인지, 모델을 만든 회사인지, 화풍의 주인인지에 대한 합의는 아직 없다.

앞에서 다룬 NovelAI 논란처럼, 작가의 동의 없이 수집한 그림으로 학습한 모델이 그 작가의 화풍을 흉내 내는 결과물을 대량으로 만드는 일이 실제로 일어났다. 2023년 1월에는 미국의 작가들이 Stability AI, Midjourney, DeviantArt를 상대로 집단 소송을 제기했고, 같은 달 Getty Images도 자사 이미지를 무단으로 학습에 사용했다며 Stability AI를 상대로 소송을 제기했다. Getty Images의 워터마크가 일그러진 형태로 생성 결과에 나타난 사례가 학습 사용의 근거로 제시되었다.

잠재 공간 절에서 모델은 개별 이미지를 보관하지 않는다고 했지만, 예외가 있다. Carlini 등(2023)은 학습 데이터에 여러 번 중복된 이미지의 캡션을 프롬프트로 넣어 대량 생성한 뒤, 학습 이미지와 거의 같은 결과를 찾아 디퓨전 모델에서 학습 이미지 1,000장 이상을 추출했다. 추출된 이미지는 대부분 학습 데이터에 여러 번 중복된 것이었다. 학습 데이터의 중복 제거가 암기를 줄이는 기본 대책이고, Stability AI는 2022년 12월 이후 모델의 학습 데이터에서 작가의 학습 제외 요청(opt-out)을 반영하겠다고 밝혔다.

### 사회적 편향

> [!WARNING]
> 생성 모델은 학습 데이터의 편향을 그대로 재현한다. "CEO"를 입력하면 백인 남성 위주로, "간호사"를 입력하면 여성 위주로 생성된다는 분석이 보고되었고, 아시아 여성을 과도하게 성적으로 묘사한다는 보고도 있었다. 학습 데이터셋의 구성을 사용자가 확인하기 어렵고, 웹 데이터 자체가 서구·남성 중심으로 치우쳐 있기 때문이다.

OpenAI는 2022년 4월 DALL·E 2 미리 보기와 함께 공개한 위험·한계 문서에서 "ceo" 프롬프트의 결과가 정장 차림의 백인 남성 위주이고 "nurse" 프롬프트의 결과가 여성 위주라는 사례를 직접 제시했다. Bianchi 등(2022)은 스테이블 디퓨전에 "매력적인 사람", "테러리스트", "가난한 사람"처럼 인종이나 성별을 명시하지 않은 프롬프트를 넣어도 특정 인종과 성별의 고정관념이 강하게 나타나고, "백인이 아닌"처럼 명시적으로 반대 조건을 넣어도 편향이 잘 바뀌지 않는다는 결과를 보였다.

편향의 근원은 학습 데이터에서 확인된다. Birhane 등(2021)은 LAION-400M을 CLIP 기반 검색 도구로 조사해, "asian" 같은 민족 명칭이나 "latina" 같은 단어로 검색하면 성적인 이미지가 상위에 대량으로 나타난다는 것을 보였다. CLIP 유사도로 정제한 데이터는 웹에서 이미지와 문장이 함께 쓰인 빈도를 반영하므로, 웹의 편향이 필터를 통과해 그대로 모델에 들어간다.

대응은 세 위치에서 이루어진다. 학습 데이터에서는 분류기로 성적·폭력적 이미지를 제거하지만 분류기 자체의 편향이 남는다. 프롬프트 단계에서는 인구 통계를 명시하지 않은 프롬프트에 다양성 조건을 자동으로 덧붙이지만, 역사적 장면처럼 맥락에 맞지 않는 결과가 생긴다. 출력 단계의 안전 분류기는 가중치가 공개된 모델에서는 사용자가 제거할 수 있다.

이 문제는 이미지 생성 모델에만 해당하지 않고 웹 데이터로 학습한 AI 전반에 적용된다. 생성 모델은 학습 데이터를 통해 사회의 모습을 그대로 비추는 복잡한 거울이므로, 모델의 개발과 사용 모두에서 편향을 측정하고 완화하는 논의가 필요하다.

### 기대

![텍스트, 코드, 이미지, 비디오·3D·게임 분야별로 2020년 이전부터 2030년까지 생성형 AI의 발전 단계를 첫 시도, 거의 도달, 본격 활용의 세 색으로 예측한 표](./images/dl-image-generation-forecast.svg '분야별 생성형 AI 발전 예측. 이미지 분야는 2022년에 아트·로고·사진 수준에 도달했다')

Sequoia Capital이 2022년 9월 내놓은 이 예측표는 분야별 대형 모델의 성숙도를 첫 시도, 거의 도달, 본격 활용의 세 단계로 나눈다. 이미지 분야는 2020년까지 첫 시도 단계였고, 2022년에 아트, 로고, 사진 생성이 거의 도달 단계에 들어섰다. 2025년에는 제품 디자인·건축의 최종 시안, 2030년에는 전문가보다 나은 결과물을 예측했고, 텍스트와 코드는 이미지보다 한 단계 앞서 있다.

생성형 AI는 사람이 손으로 만드는 것보다 빠르고 저렴할 뿐 아니라, 일부 작업에서는 더 나은 결과를 내는 단계에 이르렀다. 게임, 광고, 건축, 코딩, 그래픽 디자인, 제품 디자인, 법률, 마케팅, 영업처럼 사람이 독창적인 결과물을 만들어야 하는 산업 전반이 재편될 수 있다. 일부 업무는 생성 모델로 완전히 대체되고, 일부는 사람이 초안을 요청하고 모델의 결과를 다듬어 다시 요청하는 반복적인 창작 주기로 바뀔 가능성이 높다.

생성형 AI가 막대한 노동 생산성과 경제적 가치를 창출한다는 데에는 이미 넓은 합의가 이루어졌다. 생성형 AI는 여러 산업에서 혁신을 이끌고 사회와 경제의 변화를 앞당기는 동시에, 저작권과 편향 같은 새로운 문제를 제기한다. 기술의 발전을 꾸준히 추적하면서 이 문제를 다루는 제도와 연구를 함께 마련해 사회에 조화롭게 통합하는 일이 중요하다.
