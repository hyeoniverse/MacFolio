딥러닝 및 응용 연재의 여섯 번째 글로, 중간 발표 주제였던 이미지 생성 AI를 다룬다. 앞 글 [단어 임베딩과 seq2seq, 어텐션](/memo/dl-word-embedding-attention)까지는 입력을 분류하거나 다른 표현으로 바꾸는 판별 모델을 살폈고, 이 글은 학습 데이터의 분포를 배워 새 표본을 만드는 생성 모델(generative model)을 정리한다. 발표에서는 대표 생성 모델 세 가지(GAN, VAE, 디퓨전)를 소개한 뒤 스테이블 디퓨전(Stable Diffusion)의 동작을 설명했다. 이 글은 발표 대본을 바탕으로 각 모델의 수식을 원 논문 기준으로 보충했다.

## 생성형 AI와 이미지 생성

### 생성형 AI의 범위

생성형 AI(generative AI)는 사용자의 입력(프롬프트)을 받아 텍스트, 코드, 이미지, 음성 같은 콘텐츠를 새로 만드는 인공지능을 통칭한다. 2022년 말 공개된 ChatGPT가 텍스트 분야의 대표 사례이고, 이미지 분야에는 DALL·E, Midjourney, 스테이블 디퓨전이 있다.

![생성형 AI 응용과 모델: 텍스트, 코드, 이미지, 음성, 비디오, 3D 분야별로 응용과 대표 모델을 나눈 표](./images/dl-image-generation-diagrams-01.svg '분야별 생성형 AI 응용과 대표 모델(Sequoia Capital의 2022년 생성형 AI 지형도를 참고해 재구성). 이미지 분야 모델에 DALL·E 2와 Stable Diffusion이 있다')

### 캡션 생성에서 이미지 생성으로

2015년 무렵 이미지 캡셔닝(image captioning)이 크게 발전했다. 이미지 속 물체에 라벨을 붙이는 수준을 넘어, CNN으로 이미지 특징을 뽑고 RNN으로 문장을 생성해 "해변에서 공놀이를 하는 사람들" 같은 자연어 설명을 만들었다.

연구자들은 이 방향을 뒤집어 문장에서 이미지를 만드는 문제에 도전했다. 검색처럼 기존 이미지를 찾아오는 것이 아니라 학습 데이터에 없는 장면을 새로 그려야 하므로 캡셔닝보다 훨씬 어려운 문제다. Mansimov 등의 alignDRAW(2015년 arXiv 공개, ICLR 2016)는 "주차장에 서 있는 초록색 스쿨버스"처럼 학습 데이터에 드문 조합을 입력해 32×32 픽셀 이미지를 생성했다.

![이미지 캡셔닝은 이미지에서 CNN과 RNN을 거쳐 문장을 만들고, 텍스트-이미지 생성은 문장에서 생성 모델을 거쳐 새 이미지를 만드는 도식](./images/dl-image-generation-diagrams-02.svg '캡셔닝(이미지 → 문장)의 방향을 뒤집은 텍스트-이미지 생성')

![32×32 이미지와 512×512 이미지를 같은 축척으로 놓고, 32×32 이미지를 확대해 픽셀 격자로 보인 비교도](./images/dl-image-generation-diagrams-03.svg 'alignDRAW의 32×32 출력과 스테이블 디퓨전 v1의 512×512 출력의 크기 비교. 픽셀 수는 256배 차이다')

결과물의 품질은 낮았지만 텍스트 조건으로 새 이미지를 만들 수 있다는 가능성을 보였다. 7년 뒤인 2022년에는 Midjourney로 만든 작품 「Théâtre D'opéra Spatial」이 미국 콜로라도 주 박람회 미술전 디지털 아트 부문에서 1위를 차지해 AI가 예술 영역까지 들어왔다는 논쟁을 일으켰다.

## 생성 모델의 목표

판별 모델은 조건부 확률 `p(y \mid x){:math}`를 학습하고, 생성 모델은 데이터 자체의 분포 `p_{\text{data}}(x){:math}`를 근사하는 모델 분포 `p_\theta(x){:math}`를 학습한다. 학습을 마친 뒤 `p_\theta{:math}`에서 표본을 뽑으면 학습 데이터에 없던 새 이미지가 나온다. 이미지 한 장은 수십만 차원의 벡터이므로 분포를 직접 표현하기 어렵고, 세 모델은 저차원 잠재 변수(latent variable) `z{:math}`를 이미지로 바꾸는 방식을 서로 다르게 학습한다.

| 모델   | 학습 신호                       | 생성 방법                                         | 장점                        | 단점                    |
| ------ | ------------------------------- | ------------------------------------------------- | --------------------------- | ----------------------- |
| GAN    | 판별자와의 적대적 게임          | `G(z){:math}` 한 번의 순전파                      | 선명한 이미지, 빠른 생성    | 학습 불안정, 모드 붕괴  |
| VAE    | 증거 하한(ELBO) 최대화          | `z \sim \mathcal{N}(0, I){:math}`를 디코더에 입력 | 안정된 학습, 잠재 공간 구조 | 흐릿한 이미지           |
| 디퓨전 | 단계별 잡음 예측(ELBO의 단순화) | 잡음에서 T단계 반복 제거                          | 높은 품질과 다양성          | 반복 횟수만큼 느린 생성 |

## GAN

### 생성자와 판별자

GAN(Generative Adversarial Network, 적대적 생성 신경망)은 Goodfellow 등이 2014년 NeurIPS에 발표한 모델이다. ==생성자 G는 잡음 z에서 가짜 데이터를 만들고, 판별자 D는 입력이 진짜일 확률을 출력하며, 두 네트워크는 서로를 이기도록 번갈아 학습한다.== 발표에서는 위조지폐범(G)과 경찰(D)의 비유를 들었다. 위조지폐범은 경찰에게 들키지 않도록 위조 기술을 높이고, 경찰은 위조지폐를 찾아내도록 감별 능력을 높인다.

![잡음 z가 생성자 G를 거쳐 가짜 이미지가 되고, 가짜와 진짜 이미지가 판별자 D로 들어가 진짜 확률을 출력하는 구조도](./images/dl-image-generation-16.svg 'GAN 구조. 판별자의 기울기가 생성자로 역전파된다')

### 최소최대 목적 함수

원 논문의 목적 함수는 D는 최대화하고 G는 최소화하는 2인 게임이다.

```math
\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
```

G를 고정하면 최적 판별자는 `D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}{:math}`이고, 이를 대입하면 목적 함수는 두 분포의 젠슨-섀넌 발산(JSD)으로 바뀐다.

```math
V(D^*, G) = -\log 4 + 2 \cdot \mathrm{JSD}(p_{\text{data}} \,\|\, p_g)
```

따라서 전역 최적점은 `p_g = p_{\text{data}}{:math}`이고, 이 시각에 판별자는 모든 입력에 `D^*(x) = 1/2{:math}`을 출력한다.

> [!TIP] 비포화 손실
> 학습 초기에는 D가 가짜를 쉽게 구별해 `\log(1 - D(G(z))){:math}`의 기울기가 거의 0이 된다. 원 논문은 G가 `\log(1 - D(G(z))){:math}`를 최소화하는 대신 `\log D(G(z)){:math}`를 최대화하도록 바꿔 초기 기울기를 키웠고, 실제 구현은 대부분 이 비포화(non-saturating) 손실을 사용한다.

GAN은 한 번의 순전파로 선명한 이미지를 만들어 수년간 이미지 생성의 최고 성능(SOTA) 자리를 지켰고, 딥페이크도 GAN 계열 기술로 만든다. 그러나 두 네트워크의 균형이 깨지면 학습이 발산하고, 생성자가 판별자를 속이는 몇 가지 표본만 반복 생성하는 모드 붕괴(mode collapse)가 발생한다. 텍스트 조건 생성의 품질과 다양성에서 디퓨전 모델이 앞서면서 GAN은 상대적으로 주목을 덜 받게 되었다.

## VAE

### 오토인코더와 잠재 변수

VAE(Variational Autoencoder, 변분 오토인코더)는 Kingma와 Welling이 2013년 arXiv에 공개하고 ICLR 2014에 발표한 모델이다. 인코더가 입력 x를 저차원 잠재 변수 z로 압축하고 디코더가 z에서 x를 복원하는 오토인코더 구조를 따른다. 잠재 변수는 고양이 사진 한 장에 담긴 수많은 특징(털 색, 자세, 얼굴 방향 등)을 몇 개의 숫자로 압축한 표현이다.

일반 오토인코더는 입력마다 z를 한 점으로 대응시키므로 잠재 공간의 빈 곳에서 뽑은 z는 의미 있는 이미지로 복원되지 않는다. ==VAE는 인코더가 z의 분포 `q_\phi(z \mid x) = \mathcal{N}(\mu, \sigma^2 I){:math}`를 출력하고 그 분포를 표준 정규분포에 가깝게 규제해, 학습 후 `\mathcal{N}(0, I){:math}`에서 뽑은 z를 디코더에 넣어 새 데이터를 생성한다.== 발표에서 쓴 표현대로, 이렇게 만든 고양이는 원본을 복사한 것이 아니라 비슷하게 생긴 새 고양이다.

![입력 x가 인코더를 거쳐 평균과 표준편차를 출력하고, 잡음 ε과 결합해 z를 만든 뒤 디코더가 복원하는 구조도](./images/dl-image-generation-17.svg 'VAE 구조와 재매개변수화 z = μ + σ ⊙ ε')

### 증거 하한(ELBO)

로그 가능도 `\log p_\theta(x){:math}`는 직접 계산할 수 없으므로, VAE는 그 하한인 ELBO(evidence lower bound)를 최대화한다.

```math
\log p_\theta(x) \ge \mathbb{E}_{q_\phi(z \mid x)}[\log p_\theta(x \mid z)] - D_{\mathrm{KL}}\big(q_\phi(z \mid x) \,\|\, p(z)\big)
```

첫째 항은 복원 오차(재구성 손실), 둘째 항은 인코더 분포가 사전 분포 `p(z) = \mathcal{N}(0, I){:math}`에서 멀어지지 않게 하는 규제 항이다. 잠재 차원이 J일 때 KL 항은 닫힌 형태로 계산된다.

```math
D_{\mathrm{KL}} = -\frac{1}{2} \sum_{j=1}^{J} \left(1 + \log \sigma_j^2 - \mu_j^2 - \sigma_j^2\right)
```

<details>
<summary>재매개변수화 기법</summary>

z를 `\mathcal{N}(\mu, \sigma^2){:math}`에서 직접 표본 추출하면 표본 추출 연산을 거쳐 μ, σ로 기울기가 전달되지 않는다. 원 논문은 무작위성을 별도 변수 `\epsilon \sim \mathcal{N}(0, I){:math}`로 분리했다.

```math
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon
```

이제 무작위성은 ε에만 있고 z는 μ, σ의 미분 가능한 함수이므로, 역전파로 인코더 매개변수 φ까지 학습할 수 있다.

</details>

VAE는 학습이 안정적이고 잠재 공간이 연속적이지만, 픽셀 단위 복원 손실의 평균 효과 때문에 생성 이미지가 흐릿한 경향이 있다. DALL·E(2021)는 이산 VAE(dVAE)로 256×256 이미지를 32×32 격자의 이미지 토큰(어휘 8,192개)으로 압축하고, 텍스트 토큰 뒤에 이미지 토큰을 자기회귀 트랜스포머로 이어 생성했다. 스테이블 디퓨전도 이미지를 잠재 공간으로 압축하는 데 오토인코더를 사용한다.

## 디퓨전 모델

### 확산 과정과 역확산 과정

디퓨전 모델(diffusion model, 확산 모델)은 Sohl-Dickstein 등(ICML 2015)이 제안하고 Ho 등의 DDPM(Denoising Diffusion Probabilistic Models, NeurIPS 2020)이 고품질 이미지 생성을 보이며 널리 쓰이게 되었다. ==데이터에 가우시안 잡음을 조금씩 더해 순수한 잡음으로 만드는 확산 과정(forward process)과, 잡음에서 조금씩 잡음을 제거해 데이터를 만드는 역확산 과정(reverse process)으로 이루어지며, 신경망은 역확산 과정만 학습한다.== DALL·E 2와 스테이블 디퓨전이 이 모델을 사용한다.

![원과 사각형이 그려진 격자 x0에 잡음이 점점 많아져 완전한 잡음 xT가 되는 확산 과정과 그 반대 방향의 역확산 과정](./images/dl-image-generation-diagrams-13.svg '확산 과정은 고정된 규칙이고, 역방향 잡음 제거를 신경망이 학습한다')

### 확산 과정의 수식

확산 과정은 학습할 매개변수가 없는 마르코프 연쇄다. 단계 t에서 분산 일정(variance schedule) `\beta_t{:math}`만큼 잡음을 더한다.

```math
q(x_t \mid x_{t-1}) = \mathcal{N}\big(x_t;\ \sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t I\big)
```

`\alpha_t = 1 - \beta_t{:math}`, `\bar\alpha_t = \prod_{s=1}^{t} \alpha_s{:math}`로 두면 가우시안의 합성 성질에 따라 임의의 t를 한 번에 추출할 수 있다.

```math
q(x_t \mid x_0) = \mathcal{N}\big(x_t;\ \sqrt{\bar\alpha_t}\, x_0,\ (1 - \bar\alpha_t) I\big), \qquad x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon
```

DDPM은 `T = 1000{:math}`, `\beta_1 = 10^{-4}{:math}`에서 `\beta_T = 0.02{:math}`까지 선형으로 늘어나는 일정을 사용했다. t가 T에 가까워지면 `\bar\alpha_t \approx 0{:math}`이 되어 `x_T{:math}`는 표준 정규분포를 따른다.

### 학습 목표: 잡음 예측

역확산 과정 `p_\theta(x_{t-1} \mid x_t){:math}`도 가우시안으로 두고 그 평균을 신경망으로 표현한다. 원래 목표는 VAE와 같은 ELBO이지만, DDPM은 평균 대신 `x_t{:math}`에 섞인 잡음 ε을 예측하도록 매개변수화하고 가중치를 없앤 단순 손실이 더 좋은 표본을 만든다는 것을 보였다.

```math
L_{\text{simple}} = \mathbb{E}_{t,\, x_0,\, \epsilon}\Big[\big\| \epsilon - \epsilon_\theta\big(\sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon,\ t\big) \big\|^2\Big]
```

| 단계 | 학습(한 번의 갱신)                                                | 생성(표본 추출)                                          |
| ---- | ----------------------------------------------------------------- | -------------------------------------------------------- |
| 1    | 데이터에서 `x_0{:math}`, 균등분포에서 t, 표준 정규분포에서 ε 추출 | `x_T \sim \mathcal{N}(0, I){:math}`                      |
| 2    | 위 식으로 `x_t{:math}`를 한 번에 계산                             | t = T, …, 1 순서로 `\epsilon_\theta(x_t, t){:math}` 계산 |
| 3    | 예측 잡음과 실제 잡음의 제곱 오차로 경사 하강                     | 아래 식으로 `x_{t-1}{:math}` 계산                        |

```math
x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar\alpha_t}}\, \epsilon_\theta(x_t, t) \right) + \sigma_t z, \qquad z \sim \mathcal{N}(0, I)
```

> [!IMPORTANT] 디퓨전과 GAN·VAE의 차이
> 디퓨전 모델은 한 번에 이미지를 만들지 않고 잡음 제거를 수백에서 천 번 반복한다. 매 단계 문제는 "조금 덜 시끄러운 이미지 예측"이라는 쉬운 회귀 문제여서 학습이 안정적이고 모드 붕괴가 없지만, 생성 시각에 같은 네트워크를 여러 번 실행해야 하므로 느리다. DDIM 같은 샘플러는 단계를 건너뛰어 수십 번으로 줄인다.

잡음 예측 신경망으로는 [의미 분할 글](/memo/dl-segmentation)에서 다룬 U-Net을 사용한다. 입력과 출력의 크기가 같고, 스킵 연결로 세밀한 공간 정보를 보존하기 때문이다.

## 스테이블 디퓨전

### 공개 배경

스테이블 디퓨전은 2022년 8월 22일 Stability AI가 CompVis(LMU 뮌헨)와 Runway와 함께 공개한 텍스트-이미지 생성 모델이다. 기반 논문은 Rombach 등의 「High-Resolution Image Synthesis with Latent Diffusion Models」(CVPR 2022)다. 발표에서는 스테이블 디퓨전의 접근성을 세 가지로 요약했다.

| 접근성       | 내용                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 오픈 소스    | 코드와 학습된 가중치를 공개해 누구나 내려받아 수정·재배포할 수 있다    |
| 일반 PC 추론 | 잠재 공간에서 연산해 VRAM 10GB 미만의 소비자용 GPU에서도 생성한다      |
| 프롬프트     | 텍스트 입력만으로 이미지를 생성하고, 인페인팅·이미지 변환으로 확장된다 |

### 학습 데이터

다양한 프롬프트에 대응하려면 방대하고 다양한 이미지-텍스트 쌍이 필요하다. 웹 페이지 작성자가 접근성과 검색 엔진을 위해 이미지에 붙인 대체 텍스트(alt 텍스트)를 캡션으로 쓰면 수억 장 규모의 데이터를 모을 수 있다. 스테이블 디퓨전 v1은 Common Crawl에서 이런 쌍을 추출한 LAION-5B의 영어 부분집합(LAION-2B-en)과, 그중 미적 점수가 높은 부분집합(LAION-Aesthetics)으로 학습했다.

### 잠재 공간

프롬프트에 "1960년대 사진 속, 스노우 글로브 안의 바나나"를 입력한 상황을 가정한다. 흔한 오해는 모델이 학습 데이터에서 바나나와 스노우 글로브 이미지를 찾아 픽셀 일부를 복사해 붙인다는 생각이다.

![학습 데이터 카드에서 스노우 글로브와 바나나 영역을 오려 출력 이미지에 붙이는 도식](./images/dl-image-generation-diagrams-04.svg '학습 이미지의 픽셀을 오려 붙인다는 오해')

==새 이미지는 학습 데이터에서 직접 나오지 않고, 모델이 학습 과정에서 구축한 잠재 공간(latent space)에서 나온다.==

![학습 데이터가 학습을 거쳐 잠재 공간을 만들고, 프롬프트가 가리키는 지점에서 출력 이미지를 생성하는 도식](./images/dl-image-generation-diagrams-05.svg '학습 데이터와 출력 사이에 잠재 공간이 있다')

사람에게는 사진과 캡션을 짝짓는 일이 쉽지만, 이미지를 픽셀 값 배열로만 받으면 사람은 규칙을 찾을 수 없다. 컴퓨터는 픽셀 배열 자체를 입력으로 받으므로, 같은 학습을 반복해 어떤 배열이 바나나이고 어떤 배열이 풍선인지 구분하는 수학적 공간을 찾는다. 이것이 딥러닝이 하는 일이다.

![세 개의 숫자 배열 아래에 각각 바나나 한 송이, 빨간 풍선, 스노우 글로브 캡션이 붙은 도식](./images/dl-image-generation-diagrams-06.svg '컴퓨터에게 이미지는 픽셀 값의 배열이다')

예를 들어 노란 정도(yellowness) 하나를 측정하면 바나나와 빨간 풍선은 1차원 축 위에서 잘 분리된다.

![노란 정도 축 위에 빨간 풍선은 왼쪽, 바나나는 오른쪽에 놓이고 가운데에 경계가 있는 1차원 공간](./images/dl-image-generation-diagrams-07.svg '변수 하나(노란 정도)로 만든 1차원 공간')

학습 데이터에 노란 풍선이 들어오면 노란 풍선과 바나나가 같은 위치에 놓여 1차원 공간으로는 둘을 구분할 수 없다.

![노란 정도 축 위에 노란 풍선과 바나나가 거의 같은 위치에 놓인 1차원 공간](./images/dl-image-generation-diagrams-08.svg '노란 풍선이 추가되면 변수 하나로는 분리되지 않는다')

둥근 정도(roundness)를 둘째 축으로 추가하면 2차원 공간에서 다시 분리된다. 그러나 둥글고 노란 바나나 조각 같은 데이터가 추가되면 이 공간도 충분하지 않아, 광택(shininess)을 셋째 축으로 추가한다.

![노란 정도와 둥근 정도의 2차원 평면에서 두 풍선은 위쪽, 바나나는 아래쪽에 놓여 수평 경계로 분리되는 그림](./images/dl-image-generation-diagrams-09.svg '둥근 정도를 추가한 2차원 공간')

![광택, 노란 정도, 둥근 정도의 세 축 위에 빨간 풍선, 노란 풍선, 바나나 조각, 바나나, 금속 도구가 놓인 3차원 공간](./images/dl-image-generation-diagrams-10.svg '광택을 추가한 3차원 공간')

새 이미지가 들어오면 세 변수를 측정해 바나나 영역인지 풍선 영역인지 판단할 수 있다. 문제는 바나나와 풍선뿐 아니라 세상의 모든 물체를 인식해야 한다는 점이고, 노란 정도, 둥근 정도, 광택만으로는 대부분의 물체 특징을 담지 못한다. 딥러닝 알고리즘은 작업 성능을 높이는 변수를 스스로 찾으며 이 과정에서 3차원을 훨씬 넘는 잠재 공간을 구축한다.

잠재 공간의 축은 사람이 이름 붙일 수 없는 변수지만, 의미 있는 군집이 형성된다. 바나나다움을 포착하는 영역, 1960년대 사진의 질감과 색감을 나타내는 영역, 그리고 지구본(globe)과 눈(snow) 영역 사이 어딘가에 스노우 글로브 영역이 생긴다. 잠재 공간의 각 점은 가능한 이미지 하나의 레시피이고, 프롬프트는 이 공간에서 생성할 지점을 가리킨다.

![바나나, 1960년대, 눈, 지구본 군집과 연관어가 놓이고, 눈과 지구본 사이에 스노우 글로브 군집, 그 위에 프롬프트가 가리키는 지점이 있는 도식](./images/dl-image-generation-diagrams-11.svg '잠재 공간 속 의미 군집. 스노우 글로브는 눈과 지구본 사이에 놓인다')

> [!NOTE]
> 이 글의 잠재 공간 도식(노란 정도, 둥근 정도, 광택 축)과 오려 붙이기 오해, 생성 흐름 도식은 발표에서 인용한 Vox의 이미지 생성 AI 설명 영상의 예시를 참고해 다시 그렸다. 실제 모델의 잠재 차원은 사람이 해석할 수 있는 축이 아니며, 스테이블 디퓨전의 잠재 텐서는 64×64×4 = 16,384차원이다.

### 잠재 디퓨전 모델의 구조

픽셀 공간의 디퓨전은 512×512×3 = 786,432차원 텐서에 U-Net을 수십 번 실행해야 해서 학습과 추론 비용이 크다. ==잠재 디퓨전 모델(LDM)은 오토인코더로 이미지를 작은 잠재 텐서로 압축한 뒤, 디퓨전을 그 잠재 공간에서 수행한다.== 지각적으로 중요하지 않은 고주파 세부 사항은 오토인코더가 담당하고, 디퓨전은 의미와 구도에 집중한다.

| 구성 요소                      | 역할                                                    | 스테이블 디퓨전 v1 설정                    |
| ------------------------------ | ------------------------------------------------------- | ------------------------------------------ |
| 오토인코더 E, D                | 이미지 ↔ 잠재 텐서 변환 (KL 규제를 둔 VAE)              | 다운샘플링 비율 f = 8, 512×512×3 ↔ 64×64×4 |
| U-Net `\epsilon_\theta{:math}` | 잠재 텐서의 잡음 예측, 교차 어텐션으로 텍스트 조건 주입 | 약 8억 6천만 매개변수                      |
| 텍스트 인코더 τ                | 프롬프트를 토큰 임베딩 시퀀스로 변환                    | 고정된 CLIP ViT-L/14, 77토큰 × 768차원     |

압축 비율을 확인하면 `512 / 8 = 64{:math}`이므로 잠재 텐서는 `64 \times 64 \times 4 = 16{,}384{:math}`차원이고, 픽셀 텐서 786,432차원의 1/48이다.

![잡음 z_T가 CLIP 텍스트 인코더 출력을 조건으로 받는 U-Net을 반복 통과해 z_0가 되고, VAE 디코더가 512×512 이미지로 복원하는 구조도](./images/dl-image-generation-18.svg '잠재 공간에서 잡음을 반복 제거한 뒤 디코더로 이미지를 복원한다')

LDM의 학습 목표는 DDPM의 잡음 예측 손실을 잠재 변수 `z = \mathcal{E}(x){:math}`와 조건 y에 대해 쓴 것이다.

```math
L_{\text{LDM}} = \mathbb{E}_{\mathcal{E}(x),\, y,\, \epsilon \sim \mathcal{N}(0, 1),\, t}\Big[\big\| \epsilon - \epsilon_\theta\big(z_t, t, \tau_\theta(y)\big) \big\|_2^2\Big]
```

텍스트 조건은 U-Net 중간 층의 교차 어텐션(cross-attention)으로 들어간다. 쿼리는 이미지 잠재 특징 `\varphi_i(z_t){:math}`에서, 키와 값은 텍스트 임베딩 `\tau_\theta(y){:math}`에서 만든다.

```math
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right) V, \quad Q = W_Q\, \varphi_i(z_t),\ K = W_K\, \tau_\theta(y),\ V = W_V\, \tau_\theta(y)
```

이 식은 [트랜스포머 글](/memo/dl-transformer)의 스케일드 점곱 어텐션과 같다. 이미지의 각 위치가 프롬프트의 어떤 단어에 주목할지 계산해, "바나나" 토큰은 바나나가 놓일 영역에, "1960s" 토큰은 전체 색감에 영향을 준다.

<details>
<summary>분류기 없는 안내(classifier-free guidance)</summary>

스테이블 디퓨전은 학습 시각에 일정 비율로 텍스트 조건을 빈 문자열로 바꿔, 하나의 U-Net이 조건부 잡음 예측과 무조건 잡음 예측을 모두 학습하게 한다. 생성 시각에는 두 예측의 차이를 안내 척도 w(guidance scale)만큼 키운다.

```math
\tilde\epsilon_\theta(z_t, t, y) = \epsilon_\theta(z_t, t, \varnothing) + w \big(\epsilon_\theta(z_t, t, y) - \epsilon_\theta(z_t, t, \varnothing)\big)
```

w가 1이면 일반 조건부 생성이고, 클수록 프롬프트를 충실히 따르지만 다양성이 줄어든다. 스테이블 디퓨전의 기본값은 7.5 안팎이다. 이 방법은 Ho와 Salimans의 「Classifier-Free Diffusion Guidance」(2021)에서 제안되었다.

</details>

### 생성 과정

잠재 공간의 점을 실제 이미지로 바꾸는 단계가 앞에서 설명한 확산의 역과정이다. 순수한 잡음에서 시작해 잡음 제거를 반복하며 사람이 알아볼 수 있는 구성으로 픽셀을 배열한다.

![프롬프트가 텍스트 인코더를 거쳐 잠재 공간의 한 지점을 가리키고, 디퓨전이 잡음 제거를 반복해 이미지를 만드는 흐름도](./images/dl-image-generation-diagrams-14.svg '프롬프트 → 잠재 공간의 지점 → 디퓨전 생성 → 이미지')

시작 잡음 `z_T{:math}`를 난수로 뽑으므로 같은 프롬프트에도 매번 다른 이미지가 나오고, 난수 시드를 고정하면 같은 이미지를 재현할 수 있다. 다른 데이터로 학습한 다른 모델은 잠재 공간 자체가 다르므로 같은 프롬프트에도 다른 결과를 낸다.

## 한계와 전망

### 저작권

가장 큰 문제는 학습에 사용한 이미지다. 웹에서 수집한 학습 이미지와 생성 결과물의 저작권 문제는 아직 정리되지 않았다. 데이터에서 패턴을 추출하는 딥러닝의 성질상 특정 작가의 화풍을 학습해 재현할 수 있고, 이는 작가의 권리를 침해할 수 있다.

### 사회적 편향

> [!WARNING]
> 생성 모델은 학습 데이터의 편향을 그대로 재현한다. "CEO"를 입력하면 백인 남성 위주로, "간호사"를 입력하면 여성 위주로 생성된다는 분석이 보고되었고, 아시아 여성을 과도하게 성적으로 묘사한다는 보고도 있었다. 학습 데이터셋의 구성을 사용자가 확인하기 어렵고, 웹 데이터 자체가 서구·남성 중심으로 치우쳐 있기 때문이다.

### 기대

![텍스트, 코드, 이미지, 비디오·3D·게임 분야별로 2020년 이전부터 2030년까지 생성형 AI의 발전 단계를 예측한 표](./images/dl-image-generation-diagrams-15.svg '분야별 생성형 AI 발전 예측(Sequoia Capital의 2022년 전망표를 참고해 재구성). 이미지 분야는 2022년에 아트·로고·사진 수준에 도달했다')

생성형 AI는 일부 작업에서 사람이 직접 만드는 것보다 빠르고 저렴한 결과를 낸다. 게임, 광고, 건축, 그래픽 디자인, 제품 디자인, 마케팅처럼 독창적인 결과물이 필요한 산업에서 일부 업무는 대체되고, 일부는 사람과 모델이 반복적으로 주고받는 협업 방식으로 바뀔 것이다. 노동 생산성을 크게 높일 기술인 만큼 저작권과 편향 문제를 함께 다루는 제도와 연구가 필요하다.
