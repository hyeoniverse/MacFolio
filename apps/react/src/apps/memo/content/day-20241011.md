이 글은 2026년 10월에 git 기록을 다시 읽으며 쓴 회고다. 10월 11일과 12일은 커밋이 모두 합쳐 세 개라 한 편으로 묶고, 날짜가 아니라 주제별로 정리했다. 당시 화면은 캡처할 수 없어서 코드 구조를 도식으로 대신한다.

![2024년 10월 11~12일 작업 흐름](./images/day-20241011-timeline.svg '11일 아침에 하나, 12일 새벽과 아침에 하나씩')

## 빌드: Create React App과 TypeScript

11일 커밋은 [첫 커밋](/memo/day-20240827) 뒤 45일 만의 커밋이다. `index.html`·`script.js`·`style.css`를 삭제하고 `create-react-app`의 TypeScript 템플릿으로 옮겼다. 72개 파일이 바뀌었는데 그중 1만 9천 줄은 `package-lock.json`이다.

| 항목       | 값                                   |
| ---------- | ------------------------------------ |
| 빌드       | `react-scripts` 5.0.1 (CRA)          |
| React      | 18.3.1                               |
| TypeScript | 4.9.5                                |
| 그 밖      | react-toastify, Tailwind 3.4(개발용) |
| 시험       | CRA가 생성한 `App.test.tsx` 하나     |

## script.js를 컴포넌트로

같은 커밋에서 `script.js` 455줄을 Dock, DockItem, StatusBar, Safari, MusicPlayer 컴포넌트로 나눴다. 그림은 `public/imgs/`로 옮기고, 그림 주소는 `REACT_APP_IMAGE_URL` 환경 변수에서 읽게 했다. 공유 버튼의 동작(현재 주소를 클립보드에 복사하고 토스트 알림 표시)은 `clipboardHelpers.ts`로 분리했다.

| script.js의 역할     | 옮긴 컴포넌트         |
| -------------------- | --------------------- |
| Dock 칸과 실행 표시  | `Dock`, `DockItem`    |
| 상단 시계            | `StatusBar`           |
| 프로젝트 카드 창     | `Safari`              |
| jQuery 음악 플레이어 | `MusicPlayer`         |
| 주소 복사            | `clipboardHelpers.ts` |

## Dock 재작성

12일 새벽 3시 24분 커밋에서 Dock을 재작성했다(커밋 메시지의 "docker"는 Dock을 가리킨다). 앱 12칸의 목록을 배열로 정의하고, 화면 폭에 따라 Dock 폭을 95%·85%·70% 세 단계로 전환했다. 아이콘 라이브러리로 lucide-react를 도입했다.

## 음악 플레이어를 React로

12일 아침 7시 29분 커밋에서 음악 플레이어를 React로 옮겼다. jQuery 선택자 대신 `useRef`로 audio 요소·재생 막대·앨범 표지를 참조하고, 재생 여부·재생 위치·곡 번호를 `useState`로 관리했다. 컴포넌트 하나가 282줄이었다.

| jQuery 방식                                               | React 방식                                |
| --------------------------------------------------------- | ----------------------------------------- |
| `$("#player-track")` 등 선택자로 요소 조회, `new Audio()` | `useRef`로 audio·재생 막대·앨범 표지 참조 |
| `addClass("active")`로 재생 상태 표시                     | `useState`의 재생 여부로 렌더링           |
| 함수 범위 변수 `currIndex`의 곡 번호                      | `useState`의 곡 번호                      |
