이 글은 2026년 10월에 git 기록을 다시 읽으며 쓴 회고다. 23일 밤과 24일 아침에 커밋이 하나씩이라 한 편으로 묶었다. [12월 23일](/memo/day-20241222) 뒤 석 달 만의 커밋이고, 이 저장소에서 2025년에 남은 커밋은 이 둘뿐이다. 다음 커밋은 1년 반 뒤인 2026년 9월 28일이다.

![2025년 3월 23~24일 작업 흐름](./images/day-20250323-timeline.svg '23일 밤 11시 26분과 24일 아침 10시 8분')

## 23일: react-scripts를 걷고 Vite로

커밋 "chore: vite로 변경"은 1,190개 파일을 바꿨다. 대부분은 추적하던 `node_modules`가 빠진 것이다(1,478개 → 340개). 앱 코드에서 바뀐 것은 이렇다.

| 항목      | 전 (CRA)                  | 후 (Vite)                             |
| --------- | ------------------------- | ------------------------------------- |
| 빌드      | `react-scripts` 5.0.1     | `vite` 6.2.1 + `@vitejs/plugin-react` |
| 스크립트  | `start`, `build`, `eject` | `dev`, `build`, `preview`             |
| HTML      | `public/index.html`       | 루트의 `index.html`                   |
| 진입 파일 | `src/index.tsx`           | `src/main.tsx`                        |
| 환경 변수 | `process.env.REACT_APP_*` | `import.meta.env.VITE_APP_*` (11개)   |
| 설정 파일 | 없음 (CRA가 숨김)         | 없음 (`vite.config` 없이 기본값)      |

환경 변수 11개 중 8개가 Firebase 설정이고, 나머지 셋은 그림·음악·효과음 주소다. 접두사가 바뀌면 배포 환경의 변수 이름도 같이 바꿔야 한다. 이 커밋에서는 코드 쪽만 바꿨다.

같은 커밋에서 컴포넌트와 CSS 대부분이 조금씩 바뀌었다. 창(`Container.tsx`) 572줄, 음악(`MusicPlayer.tsx`) 431줄, `MusicContext` 387줄 등이다.

## 24일: Prettier

아침 10시 8분 커밋은 음악 플레이어·음악 Context·창·Dock CSS 여섯 파일을 Prettier로 정렬했다. 972줄을 더하고 887줄을 지웠지만, 공백 차이를 빼면 197줄과 112줄이다. 바뀐 것은 대부분 들여쓰기와 줄바꿈이다.

## 지금과 비교하면

- **Vite**: 지금도 Vite를 쓴다. 2026년 9월 28일에 같은 조건에서 CRA와 Vite를 다시 재 봤다. 개발 서버 시작이 5.05초에서 0.58초, 프로덕션 빌드가 6.33초에서 1.88초였다([CRA에서 Vite로 옮기기](/memo/cra-to-vite)).
- **남은 CRA 흔적**: 이 커밋 뒤에도 CRA가 남긴 것이 있었다. 2026년 9월 28일 0시 16분 커밋 "Vite 전환 후 빌드·배포 설정 수정 및 CRA 잔재 정리"가 그것을 치웠다([9월 28일 회고](/memo/day-0928)).
- **Prettier**: 이날은 손으로 한 번 돌렸다. 지금은 CI가 PR마다 형식을 검사한다([커밋 규칙과 CI](/memo/commit-conventions-ci)).

## 돌아보며

옮기기는 하룻밤 커밋 하나로 끝났다. React 앱은 빌드 도구에 크게 기대지 않아서, 바꿀 곳이 HTML 위치, 진입 파일, 환경 변수 접두사 정도였다. 그런데 바꾼 것을 확인할 시험이 없었다. `App.test.tsx` 파일은 남아 있었지만 `package.json`에 `test` 스크립트가 없었다. 1년 반 뒤 다시 손을 댈 때 가장 먼저 한 일이 시험을 붙이는 것이었고, 그때 [한 번도 동작한 적 없던 기능](/memo/bugs-found-by-tests)이 나왔다.
