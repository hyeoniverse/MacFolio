## DB를 Cloud SQL로, `.env`를 추적에서 제외

26일 8시 정각 커밋은 DB 연결 대상을 Google Cloud SQL로 변경했다. 코드 변경은 적다. 연결 설정에 포트(`DB_PORT`, 기본값 3306)를 추가하고 주석을 작성했을 뿐, 주소·사용자·비밀번호는 [닷새 전](/memo/day-20241021)과 같이 환경 변수에서 읽는다. 변경된 것은 환경 변수가 가리키는 DB 서버다.

이어서 1분 뒤 `.gitignore`에 `.env`를 추가하고, 4분 뒤 `server/.env`를 저장소에서 삭제했다. 마지막으로 `macbook.sql`(83줄)에 테이블 정의를 기록했다.

```sql
CREATE TABLE `memos` (
  `id` int NOT NULL AUTO_INCREMENT,
  `folder_id` int DEFAULT NULL,
  `title` varchar(300) DEFAULT NULL,
  `content` text,
  `password` varchar(60) NOT NULL DEFAULT '0000',
  ...
```

`password`의 기본값 `'0000'`은 bcrypt 해시가 아니다. `bcrypt.compare`는 해시 형식이 아닌 값과 비교하면 항상 불일치를 반환하므로, 비밀번호 없이 생성된 메모는 아무도 수정하거나 삭제할 수 없었을 것이다.

## node_modules 커밋

27일 아침 9시 커밋은 `.gitignore`에서 `node_modules` 한 줄을 삭제했다. 이어서 밤 11시까지 "CHORE: npm install"이라는 같은 메시지로 일곱 번 커밋했다.

네 번은 정확히 10,000개씩이다. 한 번에 push하지 못해 나눠 커밋한 것으로 보이지만, 커밋 메시지에는 이유가 없다. 마지막 커밋 시점에 git이 추적하는 `node_modules` 파일은 60,791개였다. 그중 44,322개가 `client/node_modules`(CRA와 그 의존성)다.

## 지금과 비교하면

- **node_modules**: 2024년 12월 서버 폴더를 지울 때 1,478개, 2025년 3월 Vite로 옮길 때 340개로 줄었고, 2026년 9월 28일 0시 15분 커밋에서 모두 추적에서 제외했다([9월 28일 회고](/memo/day-0928)). 지금은 pnpm 잠금 파일만 커밋한다.
- **.env**: 지금은 비밀 값을 저장소에 보관하지 않고, 한 번 커밋했다가 삭제한 값도 찾도록 git 기록 전체를 검사하는 CI가 있다([비밀 값 검사](/memo/secret-scanning)).
- **DB**: Cloud SQL의 MySQL은 두 달 뒤 Firebase로, 지금은 Oracle Cloud VM의 PostgreSQL이다([백엔드 설계](/memo/backend-design), [서버 배포](/memo/deploy-api-oracle-tunnel)).
- **스키마**: 수동으로 작성한 `.sql` 파일 대신, 지금은 API 서버의 Prisma 마이그레이션이 테이블을 생성한다.

## 돌아보며

`.env`를 삭제한 다음 날 `node_modules`를 커밋했다. 하나는 저장소에 있으면 안 되는 파일을 제외하는 작업이고, 하나는 없어도 되는 파일을 추가하는 작업이었다. 둘 다 "무엇을 저장소에 보관하는가"라는 같은 질문인데, 이틀 사이에 판단이 반대로 내려졌다.

이 6만 개는 2년 동안 저장소 기록에 남았다. 지금도 이 저장소를 처음부터 clone하면 그 파일들을 함께 내려받는다. 삭제한 파일도 git 기록에는 남는다는 점은 비밀 값에만 해당하는 문제가 아니다.

| 잘못 커밋한 것        | 기록에 남은 영향                       | 대응                         |
| --------------------- | -------------------------------------- | ---------------------------- |
| `.env` (비밀 값)      | 삭제 후에도 기록에서 값을 읽을 수 있음 | 추적 제외, 기록 전체 검사 CI |
| `node_modules` 6만 개 | clone 용량 증가                        | 추적 제외, 기록은 그대로     |
