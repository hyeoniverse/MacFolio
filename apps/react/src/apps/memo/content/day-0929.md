## 낮: Safari를 포트폴리오로

프로젝트 목록을 GitHub의 고정 저장소에 맞추고, Safari를 프로젝트마다 탭이 하나씩 열린 브라우저로 바꿨다. 탭은 macOS Safari 모양으로, 프로젝트 소개는 Apple 홈페이지처럼 짰고, 페이지 모양도 프로젝트마다 다르게 했다. 새싹 농장(SproutFarm)은 게임을 창 안에서 바로 하는 앱으로 넣었다.

![지금의 Safari](./images/day-0929-safari.jpg '프로젝트마다 탭이 열린 Safari의 지금 모습. 페이지 내용은 10월 4일에 거의 다시 짰다')

오후 1시 반에는 그동안 미뤄 둔 글 4편을 한 번에 올리고, 메모 앱에 정렬과 날짜별 묶음을 넣었다.

## 저녁: 처음으로 서버를 세우다

오후 4시 6분에 NestJS + Prisma + PostgreSQL로 API 뼈대를 만들었다. 40분 뒤 GitHub OAuth 로그인과 DB 세션, 관리자만 통과하는 AdminGuard가 붙었고, 루트에서 프론트엔드와 API를 함께 띄우는 `dev:all`도 만들었다.

로그인 화면은 macOS답게 넣었다. Apple 메뉴, 제어 센터의 관리자 타일, 암호 앱, 시스템 설정의 계정이 모두 로그인 입구다. 휴대폰 제어 센터는 화면 어디서나 쓸어 내려 열리게 했다.

그리고 저녁 7시 45분, 로그인을 고쳤다. **관리자를 GitHub 아이디(login)가 아니라 숫자 ID로 확인하게 했다.** 아이디는 바꿀 수 있고, 바꾸고 나면 옛 아이디를 다른 사람이 가져갈 수 있다. 그 사람이 옛 아이디로 로그인하면 관리자가 되어 버린다. 숫자 ID는 바뀌지 않는다. 로그인 요청에는 IP마다 횟수 제한도 걸었다.

| 한 일                                                  | 글                                  |
| ------------------------------------------------------ | ----------------------------------- |
| NestJS·Prisma API, GitHub OAuth, DB 세션, 숫자 ID 확인 | 정적 사이트에 관리자 로그인 붙이기  |
| 제어 센터를 어디서나 쓸어서                            | 화면 어디서나 쓸어서 제어 센터 열기 |

## 밤: 블로그를 서버에 잇다

밤 9시 반부터는 블로그를 서버와 이었다. 글에 이미지와 이전 글·다음 글을 넣고, 관리자가 정한 폴더 정리를 API에 저장하고, 댓글을 붙이고, 관리자 글쓰기·편집·삭제를 만들었다. 마지막 커밋(11시 29분)은 **편집 단추 없이 메모 앱처럼 바로 고치기**였다. 글을 열면 바로 고칠 수 있다.

필수 항목(제목·날짜·폴더·본문)은 세 곳에서 막았다. 화면에서 먼저 막고, API도 같은 규칙으로 400을 돌려주고, DB에는 CHECK 제약을 걸어 둘을 거치지 않은 쓰기까지 막는다.

| 관리자 글쓰기·편집·삭제, 바로 고치기 | Markdown 블로그에 글쓰기 붙이기    |
