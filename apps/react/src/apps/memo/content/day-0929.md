로그인을 처음 짠 지 세 시간 만에 다시 고쳤다. 관리자인지를 GitHub **아이디**로 보고 있었는데, 아이디는 바꿀 수 있다. 내가 아이디를 바꾸면 옛 아이디는 다른 사람이 가져갈 수 있고, 그 사람이 로그인하면 관리자가 된다. 바뀌지 않는 **숫자 ID**로 보게 고치고, 로그인 요청에는 IP마다 횟수 제한을 걸었다.

이날은 처음으로 서버가 생긴 날이다. 커밋은 24개로 전날의 3분의 1이지만, 화면 뒤에 저장하고 막는 쪽이 처음 생겼다.

![9월 29일 작업 흐름](./images/day-0929-timeline.svg '낮에는 Safari 포트폴리오, 저녁부터는 API와 로그인')

## 서버보다 먼저, Safari

서버에 앞서 Safari를 포트폴리오로 바꿨다. 프로젝트 목록을 GitHub 고정 저장소에 맞추고, 프로젝트마다 탭이 하나씩 열리게 하고, 소개는 Apple 홈페이지처럼 짰다. 새싹 농장은 게임을 창 안에서 바로 하는 앱으로 넣었다([Unity WebGL 게임을 창 안에 넣기](/memo/game-in-iframe)).

![지금의 Safari](./images/day-0929-safari.jpg '프로젝트마다 탭이 열린 Safari의 지금 모습. 페이지 내용은 10월 4일에 거의 다시 짰다')

전날 붙인 휴대폰 셸도 여기서 머지했고([#33](https://github.com/hyeoniverse/MacFolio/pull/33)), 그동안 미뤄 둔 글 네 편을 한 번에 올렸다.

## 서버 첫날에 붙인 것들

| 순서 | 붙인 것                                                      | 글                                                                   |
| ---- | ------------------------------------------------------------ | -------------------------------------------------------------------- |

| 2    | GitHub OAuth, DB 세션, 관리자만 통과하는 AdminGuard          | [정적 사이트에 관리자 로그인 붙이기](/memo/admin-login-github-oauth) |
| 3    | 로그인 입구: Apple 메뉴, 제어 센터, 암호 앱, 설정의 계정     | [화면 어디서나 쓸어서 제어 센터 열기](/memo/control-center-swipe)    |
| 4    | 관리자가 정한 폴더 정리를 API에                              | [글은 Markdown에 두고 정리만 서버에](/memo/memo-organization-api)    |
| 5    | 댓글                                                         | [댓글에 남기지 않은 것들](/memo/post-comments)                       |
| 6    | 관리자 글쓰기·편집·삭제, 편집 단추 없이 메모처럼 바로 고치기 | [Markdown 블로그에 글쓰기 붙이기](/memo/post-editor)                 |

필수 항목(제목·날짜·폴더·본문)은 세 곳에서 막았다. 화면이 먼저 막고, API도 같은 규칙으로 400을 돌려주고, DB는 CHECK 제약으로 둘을 거치지 않은 쓰기까지 막는다.

API e2e는 GitHub만 가짜로 바꾸고 실제 PostgreSQL에 붙여 돌린다. 관리자가 아닌 계정이 막히는지, 위조한 요청이 거절되는지까지 본다. 첫날부터 30개로 시작했다.
