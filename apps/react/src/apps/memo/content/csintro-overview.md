## 들어가기 전에

컴퓨터는 입력받은 데이터를 저장된 명령어에 따라 처리하고 결과를 내보내는 기계다. 정보보호는 이 기계가 다루는 데이터와 서비스를 허가되지 않은 열람, 변경, 중단으로부터 지키는 일이다. 두 분야는 따로 떨어져 있지 않다. 공격은 거의 항상 컴퓨터가 동작하는 방식의 특정 지점을 노린다. 메모리에 명령어와 데이터가 함께 저장된다는 사실은 버퍼 오버플로 공격의 전제가 되고, 문자가 바이트로 인코딩된다는 사실은 인코딩을 우회하는 웹 공격의 전제가 된다. 그래서 정보보호를 공부하려면 먼저 컴퓨터가 데이터를 어떻게 표현하고 처리하는지 알아야 한다.

## 계산 기계의 발전

### 기계식 계산기

사람은 오래전부터 계산을 돕는 도구를 만들었다. 주판은 구슬의 위치로 자릿값을 표현하는 도구이고, 17세기부터는 톱니바퀴로 자리올림을 자동으로 처리하는 기계식 계산기가 등장했다.

| 연도 | 기계                                | 만든 사람             | 특징                                                                |
| ---- | ----------------------------------- | --------------------- | ------------------------------------------------------------------- |
| 1642 | 파스칼린(Pascaline)                 | 블레즈 파스칼         | 톱니바퀴로 덧셈과 뺄셈을 수행                                       |
| 1673 | 단계 계산기(Stepped Reckoner)       | 고트프리트 라이프니츠 | 덧셈의 반복으로 곱셈, 뺄셈의 반복으로 나눗셈까지 수행               |
| 1822 | 차분기관(Difference Engine) 시제품  | 찰스 배비지           | 다항식의 값을 차분법으로 계산해 수표(數表)를 만드는 기계            |
| 1837 | 해석기관(Analytical Engine) 설계    | 찰스 배비지           | 연산부(mill), 기억부(store), 천공카드 제어, 출력부를 갖춘 범용 설계 |
| 1890 | 천공카드 집계기(Tabulating Machine) | 허먼 홀러리스         | 카드에 뚫린 구멍 위치로 인구 데이터를 전기적으로 집계               |

해석기관은 당시 기계 가공 기술과 자금 문제로 완성되지 못했지만, 오늘날 컴퓨터의 연산장치·기억장치·제어·입출력 구분을 이미 갖춘 설계였다. 에이다 러브레이스는 해석기관으로 베르누이 수를 계산하는 절차를 기록했고, 이것은 최초의 컴퓨터 프로그램으로 평가된다. 홀러리스의 천공카드 집계기는 1890년 미국 인구조사의 집계 기간을 크게 줄였고, 그가 세운 회사는 뒤에 IBM의 모태가 되었다.

### 튜링 기계

1936년 앨런 튜링은 논문 「On Computable Numbers」에서 튜링 기계(Turing machine)를 제안했다. 튜링 기계는 실제 장치가 아니라 계산이라는 행위를 수학적으로 정의하기 위한 모델이다. 구성은 단순하다.

- 칸으로 나뉜 무한히 긴 테이프: 각 칸에 기호 하나를 기록한다
- 헤드: 현재 칸의 기호를 읽고 쓰며 왼쪽이나 오른쪽으로 한 칸 이동한다
- 상태 레지스터와 규칙표: "현재 상태가 q이고 읽은 기호가 1이면, 0을 쓰고 오른쪽으로 이동한 뒤 상태 r로 바뀐다" 같은 규칙의 목록

이 단순한 모델로 계산할 수 있는 문제는 오늘날의 어떤 컴퓨터로도 계산할 수 있고, 그 반대도 성립한다고 받아들여진다(처치-튜링 논제). 또 튜링은 다른 튜링 기계의 규칙표를 테이프에 입력받아 그대로 흉내 내는 보편 튜링 기계(universal Turing machine)를 보였다. 기계의 동작을 하드웨어 배선이 아니라 입력된 데이터로 바꿀 수 있다는 이 생각은 뒤의 프로그램 내장 방식으로 이어진다.

### 전자식 컴퓨터와 프로그램 내장 방식

1930년대 후반부터 계산 장치는 톱니바퀴 대신 계전기(relay)와 진공관을 쓰기 시작했다.

![계산 기계에서 프로그램 내장식 컴퓨터까지의 연표: 1642 파스칼린, 1673 단계 계산기, 1837 해석기관 설계, 1890 천공카드, 1936 튜링 기계, 1942·1944 ABC와 Mark I, 1945 ENIAC, 1949·1951 EDSAC과 UNIVAC I](./images/csintro-overview-timeline.svg '색은 기계식, 이론, 초기 전자식, 프로그램 내장식을 구분한다')

| 연도      | 컴퓨터         | 개발                                     | 특징                                                                            |
| --------- | -------------- | ---------------------------------------- | ------------------------------------------------------------------------------- |
| 1942      | ABC            | 아이오와 주립대학 아타나소프·베리        | 진공관으로 2진 연산을 수행한 최초의 전자식 디지털 계산기. 연립방정식 전용       |
| 1944      | Harvard Mark I | 하버드대 에이컨, IBM 제작                | 계전기와 회전 축으로 동작하는 전기기계식 계산기. 천공 테이프로 명령어 입력      |
| 1945      | ENIAC          | 펜실베이니아대 모클리·에커트             | 진공관 약 17,500개, 무게 약 27톤. 프로그램을 바꾸려면 배선과 스위치를 다시 연결 |
| 1949      | EDSAC          | 케임브리지대 윌크스                      | 프로그램 내장 방식을 실용적으로 운용한 초기 컴퓨터                              |
| 1949~1951 | EDVAC          | 펜실베이니아대 무어 스쿨                 | 폰 노이만의 1945년 보고서가 설계 근거가 된 프로그램 내장식 컴퓨터               |
| 1951      | UNIVAC I       | 에커트-모클리 컴퓨터사(뒤에 레밍턴 랜드) | 미국 최초의 상업용 컴퓨터. 미국 인구조사국에 납품                               |

ENIAC은 기존 기계식 계산기보다 수천 배 빨랐지만, 계산할 문제를 바꿀 때마다 사람이 케이블과 스위치를 며칠에 걸쳐 다시 연결해야 했다. 프로그램이 하드웨어 배선 자체였기 때문이다.

존 폰 노이만은 1945년 EDVAC 설계 보고서(First Draft of a Report on the EDVAC)에서 명령어도 데이터와 똑같이 숫자로 부호화해 메모리에 저장하자고 정리했다. 이를 프로그램 내장 방식(stored-program concept)이라고 한다.

1. 프로그램(명령어와 데이터)을 주기억장치에 적재한다.
2. CPU는 프로그램 카운터(PC)가 가리키는 주소에서 명령어 하나를 인출(fetch)한다.
3. 명령어를 해독(decode)하고 실행(execute)한 뒤, PC를 다음 명령어로 옮긴다.
4. 2~3을 반복한다.

이렇게 하면 다른 계산을 하고 싶을 때 배선을 바꾸지 않고 메모리의 내용만 바꾸면 된다. 오늘날 노트북과 스마트폰도 이 구조를 따른다. 인출·해독·실행 사이클과 이 구조의 병목은 [컴퓨터 구조](/memo/csintro-computer-architecture) 글에서 자세히 다룬다.

> [!NOTE] 보안 관점에서 본 프로그램 내장 방식
> 명령어와 데이터가 같은 메모리에 같은 형태(비트열)로 저장되므로, 공격자가 데이터로 입력한 바이트열을 CPU가 명령어로 실행하게 만들 수 있다. 버퍼 오버플로를 이용한 코드 주입 공격이 이 원리를 이용하며, 운영체제는 데이터 영역을 실행 불가로 표시하는 NX 비트(DEP)로 대응한다.

### 컴퓨터의 종류

처리 성능과 용도에 따라 컴퓨터를 다음처럼 분류한다. 경계는 시대에 따라 움직인다. 1990년대 워크스테이션의 성능은 오늘날 스마트폰보다 낮다.

| 종류              | 용도와 특징                                                                               | 예                                |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------- |
| 슈퍼컴퓨터        | 수만~수백만 개의 CPU·GPU 코어를 병렬로 연결해 기상 예측, 핵융합·신약 시뮬레이션 등을 계산 | Frontier, Fugaku                  |
| 메인프레임(대형)  | 수많은 사용자의 거래를 동시에 안정적으로 처리. 은행 계정계, 항공 예약                     | IBM Z                             |
| 워크스테이션·서버 | 개인용보다 높은 성능과 신뢰성(ECC 메모리 등). 설계·영상 작업, 웹 서버 운영                | 랙 서버, 고성능 데스크톱          |
| 개인용 컴퓨터(PC) | 한 사람이 쓰는 데스크톱·노트북                                                            | 데스크톱, 노트북                  |
| 모바일·임베디드   | 배터리로 동작하는 휴대 기기, 가전·자동차에 내장된 제어용 컴퓨터                           | 스마트폰, 태블릿, 스마트워치, ECU |

슈퍼컴퓨터의 성능은 초당 부동소수점 연산 횟수(FLOPS)로 비교하며, TOP500 목록이 1년에 두 번 순위를 발표한다.

## 컴퓨터의 구성

컴퓨터 시스템은 물리적 장치인 하드웨어와, 하드웨어에게 할 일을 지시하는 명령어의 집합인 소프트웨어로 이루어진다.

### 하드웨어

![하드웨어 구성: 입력장치에서 CPU로, CPU에서 출력장치로 데이터가 흐르고, CPU와 기억장치는 명령어와 데이터를 주고받는다. CPU는 제어장치, 연산장치(ALU), 레지스터로 구성된다](./images/csintro-overview-hardware.svg 'CPU는 기억장치에서 명령어를 읽어 실행한다')

| 구성 요소         | 역할                                                     | 예                                         |
| ----------------- | -------------------------------------------------------- | ------------------------------------------ |
| 입력장치          | 문자, 소리, 이미지 같은 외부 데이터를 컴퓨터 안으로 전달 | 키보드, 마우스, 마이크, 카메라, 터치스크린 |
| 중앙처리장치(CPU) | 명령어를 해석하고 연산을 수행                            | Intel Core, AMD Ryzen, Apple M 시리즈      |
| 기억장치          | 프로그램과 데이터를 저장                                 | RAM, ROM, SSD, HDD                         |
| 출력장치          | 처리 결과를 사람이 인식할 수 있는 형태로 표현            | 모니터, 프린터, 스피커                     |

CPU는 다시 세 부분으로 나뉜다.

- 제어장치(Control Unit): 명령어를 해독하고, 그 결과에 따라 다른 장치에 제어 신호를 보내 명령어가 순서대로 실행되게 한다
- 연산장치(ALU, Arithmetic Logic Unit): 덧셈·뺄셈 같은 산술 연산과 AND·OR·NOT 같은 논리 연산을 수행한다
- 레지스터(register): CPU 내부의 소용량 고속 기억장치로, 연산에 쓰는 값과 다음 명령어 주소 등을 임시로 보관한다

기억장치는 주기억장치와 보조기억장치로 나뉜다. 주기억장치는 CPU가 직접 읽고 쓰는 메모리로, 전원이 꺼지면 내용이 사라지는 휘발성 RAM과 전원이 없어도 내용이 유지되는 비휘발성 ROM이 있다. 보조기억장치는 SSD, HDD, USB 플래시 메모리처럼 전원과 무관하게 데이터를 오래 보관하는 대용량 저장장치다. 예를 들어 문서 편집기로 파일을 열면 SSD에 저장된 파일 내용이 RAM으로 복사되고, CPU는 RAM에 있는 내용을 수정한다. 저장 버튼을 누르기 전에 전원이 꺼지면 RAM의 수정 내용은 사라진다.

### 소프트웨어

| 분류              | 역할                                                   | 예                                                       |
| ----------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| 시스템 소프트웨어 | 하드웨어를 관리하고 다른 프로그램이 실행될 환경을 제공 | 운영체제(Windows, macOS, Linux), 장치 드라이버, 컴파일러 |
| 응용 소프트웨어   | 사용자가 특정 업무를 처리하려고 사용하는 프로그램      | 웹 브라우저, 워드프로세서, 스프레드시트, 게임            |

응용 소프트웨어는 하드웨어를 직접 다루지 않고 운영체제가 제공하는 기능(시스템 호출)을 통해 파일을 읽거나 화면에 그린다. 그래서 같은 브라우저가 서로 다른 제조사의 SSD와 그래픽카드에서 동작한다.

프로그램은 사람이 읽기 쉬운 고급 언어(C, Python 등)로 작성한 뒤, 컴파일러나 인터프리터가 CPU가 실행하는 기계어로 변환한다. 다음 C 프로그램은 100에서 50을 뺀 결과를 출력한다.

```c
#include <stdio.h>

int main(void)
{
	int result = 100 - 50;
	printf("결과 = %d\n", result);
	return 0;
}
```

컴파일러는 이 코드를 "값 100을 레지스터에 넣는다, 50을 뺀다, 결과를 출력 함수에 넘긴다"에 해당하는 기계어 명령어 몇 개로 바꾼다.

### 컴퓨터의 활용 분야

컴퓨터는 거의 모든 산업에서 쓰인다. 몇 가지 예는 다음과 같다.

- 과학기술: 기상 예측 시뮬레이션, 우주 발사체의 궤도 계산과 자세 제어, 이동통신 기지국 소프트웨어 개발
- 산업: 공장 설비를 제어하는 PLC, 산업용 로봇, 스마트 가전
- 의료: 전자의무기록(EMR), CT·MRI 영상 재구성, 원격 조작 수술 로봇
- 금융: 인터넷 뱅킹, 카드 결제 승인, 증권 거래 시스템
- 교육: 온라인 강의 플랫폼, 학습 관리 시스템(LMS)
- 국방: 무기 체계 제어, 전장 시뮬레이션 훈련

이 분야들이 컴퓨터에 의존할수록 컴퓨터가 멈추거나 조작될 때의 피해도 커진다. 예를 들어 결제 승인 서버가 한 시간 멈추면 그 시간 동안의 모든 카드 결제가 실패한다. 정보보호가 필요한 이유가 여기에 있다.

## 해킹과 보안 사고의 역사

해킹(hacking)이라는 말은 본래 1960년대 MIT의 컴퓨터 동호인들이 시스템을 깊이 이해하고 설계자가 의도하지 않은 창의적인 방법으로 활용하는 일을 가리켰다. 오늘날 일상어에서는 허가 없이 다른 사람의 시스템에 침입하는 행위를 뜻하는 경우가 많다. 보안 분야에서는 허가받고 취약점을 찾는 사람을 화이트 해커 또는 윤리적 해커로, 불법 침입자를 크래커나 공격자로 구분해 부른다.

### 1950년대 이전: 암호 기계

에니그마(Enigma)는 독일의 아르투어 셰르비우스가 1918년 특허를 출원한 회전자(rotor) 방식 암호 기계다. 처음에는 기업 통신용으로 판매되었고, 이후 독일군이 개량해 제2차 세계대전 동안 군사 통신에 썼다. 키를 하나 누를 때마다 회전자가 회전해 같은 글자라도 매번 다른 글자로 암호화된다.

에니그마 해독은 1932년 폴란드 암호국의 마리안 레예프스키가 처음 성공했다. 전쟁이 시작되자 영국 블레츨리 파크에서 앨런 튜링 등이 이 성과를 이어받아 전기기계식 해독 장치 봄브(Bombe)를 만들었다. 같은 장소에서 1944년 토미 플라워스가 만든 콜로서스(Colossus)는 진공관 약 1,600~2,400개를 쓴 전자식 계산기로, 에니그마가 아니라 독일 최고사령부의 로렌츠(Lorenz) 암호를 해독하는 데 쓰였다.

### 1960~1980년대: 전화망 해킹에서 네트워크 침입으로

- 1960~1970년대 프리킹(phreaking): 당시 미국 장거리 전화망은 회선이 비어 있음을 2,600Hz 신호음으로 알렸다. 조 엔그레시아는 휘파람으로 이 음을 내 교환기를 조작할 수 있음을 알아냈고, 존 드레이퍼는 시리얼 캡앤크런치(Cap'n Crunch)의 경품 호루라기가 정확히 2,600Hz를 낸다는 사실로 유명해졌다. 제어 신호가 음성과 같은 회선으로 전달되는 대역 내 신호(in-band signaling) 설계의 약점이었다.
- 1983년: 밀워키의 10대들로 이루어진 414s가 메모리얼 슬론 케터링 암센터와 로스앨러모스 국립연구소 등의 시스템에 침입했다. 같은 해 해커를 다룬 영화 「WarGames」가 개봉했고, 미국 의회 청문회로 이어졌다.
- 1984년: 윌리엄 깁슨의 소설 『뉴로맨서』가 사이버스페이스라는 말을 대중화했다. 같은 해 해커 잡지 《2600》이, 1985년에는 《Phrack》이 창간되었다.
- 1988년: 코넬대 대학원생 로버트 모리스가 만든 모리스 웜이 당시 인터넷에 연결된 컴퓨터 약 6,000대(전체의 약 10%)를 감염시켰다. 이 사건으로 카네기멜런대에 컴퓨터 비상 대응팀(CERT/CC)이 설립되었고, 모리스는 미국 컴퓨터 사기 및 남용 방지법(CFAA)으로 처음 유죄 판결을 받은 사람이 되었다.

### 1990년대: 인터넷의 대중화

- 1991년: 리누스 토르발스가 리눅스 커널 0.01을 공개했다. 소스 코드가 공개된 운영체제가 보급되면서 보안 연구와 공격 도구 개발이 함께 활발해졌다.
- 1993년: 해킹 콘퍼런스 DEF CON이 라스베이거스에서 처음 열렸다.
- 1994년: 넷스케이프 내비게이터가 출시되며 웹이 대중화되었다.
- 1995년: 케빈 미트닉이 여러 기업의 네트워크에 침입한 혐의로 체포되었다. 그는 기술적 공격 못지않게 전화로 직원을 속여 정보를 얻는 사회공학(social engineering)을 많이 썼다.
- 1998년: 해킹 그룹 Cult of the Dead Cow가 DEF CON에서 Windows 원격 제어 트로이 목마 백 오리피스(Back Orifice)를 공개했다.

### 2000년대 이후: 대규모 감염과 개인정보 유출

- 2000년 2월: 야후, CNN, 아마존, eBay 등이 분산 서비스 거부(DDoS) 공격으로 몇 시간 동안 접속 불능이 되었다.
- 2000년 5월: 'ILOVEYOU' 제목의 이메일로 퍼진 러브 버그(Love Bug) 웜이 전 세계에서 수십억 달러 규모의 피해를 냈다.
- 2003년 1월 25일: Microsoft SQL Server 2000의 취약점을 노린 슬래머(Slammer) 웜이 10분 만에 취약한 서버 약 75,000대를 감염시켰다. 웜이 생성한 트래픽이 국내 인터넷망을 마비시킨 이 사건은 '1·25 인터넷 대란'으로 불린다.
- 2011년 4월: 농협 전산망의 서버 수백 대에서 데이터가 삭제되어 금융 서비스가 며칠 동안 중단되었다.
- 2010년대 이후: 스마트폰이 개인의 인증 수단(문자 인증, 앱 인증서)이 되면서 스마트폰 악성 앱과 스미싱이 주요 위협이 되었고, 데이터를 암호화하고 몸값을 요구하는 랜섬웨어가 기업과 병원을 노리고 있다.

이 흐름을 보면 공격 대상이 단일 기계에서 네트워크로, 다시 개인의 데이터와 사회 기반 시설로 넓어졌다. 피해의 종류도 데이터 유출, 데이터 변조, 서비스 중단으로 나눌 수 있는데, 이것이 다음 절의 3요소와 대응한다.

## 정보보호의 3요소

### 기밀성, 무결성, 가용성

정보보호의 목표는 흔히 세 단어의 머리글자를 따 CIA로 정리한다. 미국 연방법(44 U.S.C. § 3552)과 NIST SP 800-12는 정보 보안을 "허가되지 않은 접근, 사용, 공개, 방해, 수정, 파괴로부터 정보와 정보시스템을 보호해 기밀성, 무결성, 가용성을 제공하는 것"으로 정의한다.

![정보보호의 3요소: 기밀성은 허가된 주체만 읽는 성질로 스니핑과 유출이 침해하고 암호화·접근 통제로 대응한다. 무결성은 허가된 방법으로만 바뀌는 성질로 위변조와 랜섬웨어가 침해하고 해시·전자서명으로 대응한다. 가용성은 필요한 시각에 쓸 수 있는 성질로 DoS와 장애가 침해하고 이중화·백업으로 대응한다](./images/csintro-overview-cia.svg '세 요소는 각각 다른 공격과 대책에 대응한다')

| 요소                    | 뜻                                                           | 침해 예                                                                       | 대표 대책                                        |
| ----------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- | ------------------------------------------------ |
| 기밀성(Confidentiality) | 허가된 사용자만 정보를 열람할 수 있다                        | 공용 와이파이에서 평문 비밀번호 도청, 고객 DB 유출                            | 암호화, 접근 통제, 인증                          |
| 무결성(Integrity)       | 허가된 사용자가 허가된 방법으로만 정보를 변경할 수 있다      | 송금 계좌 번호 변조, 웹 페이지 변조, 소프트웨어 업데이트 파일에 악성코드 삽입 | 해시, 메시지 인증 코드(MAC), 전자서명, 변경 이력 |
| 가용성(Availability)    | 허가된 사용자가 필요한 시각에 정보와 서비스를 사용할 수 있다 | DDoS 공격으로 쇼핑몰 접속 불능, 랜섬웨어로 파일 사용 불가                     | 서버 이중화, 백업, 트래픽 필터링                 |

세 요소는 서로 다른 질문에 답한다. 은행 앱을 예로 들면 다음과 같다.

- 기밀성: 내 계좌 잔액을 다른 사람이 볼 수 없는가
- 무결성: 이체 요청의 받는 계좌와 금액이 전송 도중에 바뀌지 않았는가
- 가용성: 월급날 오전에 앱이 정상적으로 접속되는가

암호화는 기밀성을 지키지만 그것만으로 무결성을 보장하지는 않는다. 암호문의 일부 비트를 뒤집으면 복호화된 평문도 예측 가능한 방식으로 바뀌는 암호 방식이 있기 때문이다. 그래서 TLS 같은 실제 프로토콜은 암호화와 무결성 검증(인증 암호화)을 함께 적용한다. 또 세 요소는 서로 충돌하기도 한다. 비밀번호를 다섯 번 틀리면 계정을 잠그는 정책은 기밀성을 높이지만, 공격자가 일부러 틀린 비밀번호를 입력해 정상 사용자의 계정을 잠글 수 있으므로 가용성을 떨어뜨린다.

> [!TIP] 3요소를 보완하는 성질
> 실무에서는 CIA에 인증(authentication, 사용자가 주장하는 신원이 맞는지 확인), 부인 방지(non-repudiation, 행위자가 나중에 행위를 부인하지 못하게 하는 것), 책임 추적성(accountability, 누가 무엇을 했는지 로그로 추적)을 더해 설명하기도 한다. 전자서명은 무결성과 부인 방지를 함께 제공한다.

네트워크 위에서의 기밀성 침해(스니핑)는 [패킷 스니핑과 스푸핑](/memo/net-sniffing-spoofing)에서, 가용성을 노리는 SYN 플러딩 같은 공격은 [TCP 프로토콜을 겨냥한 공격과 방어](/memo/net-tcp-attacks)에서 다룬다.

### 보안 인력에게 필요한 요건

보안 업무는 공격 기법을 알아야 방어할 수 있다는 특성이 있다. 그래서 두 가지가 함께 요구된다.

- 윤리 의식: 같은 침투 기술이라도 시스템 소유자의 서면 허가와 합의된 범위 안에서 수행하면 모의 해킹(침투 테스트)이고, 허가 없이 수행하면 범죄다. 발견한 취약점은 공개 전에 제조사에 먼저 알리는 책임 있는 공개(coordinated disclosure) 절차를 따른다.
- 기술 전문성: 운영체제, 네트워크 프로토콜, 프로그래밍, 서버 운영, 암호, 보안 장비, 로그 모니터링, 보안 정책과 법규까지 넓은 범위의 지식이 필요하다. 예를 들어 웹 서버 침해 사고를 분석하려면 HTTP 요청 로그를 읽고(네트워크), 업로드된 악성 스크립트를 해석하고(프로그래밍), 공격자가 얻은 권한을 확인해야(운영체제) 한다.

### 정보보호 관련 법률

국내에서 정보보호와 관련된 주요 법률은 다음과 같다.

| 법률                                                         | 주요 내용                                                                                 |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 정보통신망 이용촉진 및 정보보호 등에 관한 법률(정보통신망법) | 정보통신망 침입, 악성 프로그램 유포, 서비스 거부 공격 금지와 처벌. 정보보호 관리체계 인증 |
| 개인정보 보호법                                              | 개인정보의 수집·이용·제공·파기 원칙, 유출 통지 의무. 2011년 시행                          |
| 정보통신기반 보호법                                          | 전력·금융·통신·교통 등 국가 주요 정보통신기반시설의 지정과 보호                           |
| 통신비밀보호법                                               | 우편물 검열과 전기통신 감청을 원칙적으로 금지. 1993년 제정                                |
| 저작권법                                                     | 소프트웨어를 포함한 저작물의 권리 보호와 공정한 이용                                      |

예를 들어 다른 사람의 서버에 허가 없이 접속해 취약점을 확인하기만 하고 아무것도 바꾸지 않았더라도, 정보통신망법의 정보통신망 침입 금지 조항을 위반한다. 취약점을 연습하려면 직접 구축한 실습 환경이나 공개된 CTF·워게임 서비스를 이용한다.

시스템 소프트웨어는 하드웨어를 관리하고 프로그램 실행 환경을 제공한다(운영체제, 장치 드라이버, 컴파일러). 응용 소프트웨어는 사용자의 특정 업무를 처리한다(스프레드시트, 워드프로세서, 웹 브라우저).

</details>

<details>
<summary>4. 프로그램 내장 방식을 설명하라</summary>

명령어와 데이터로 구성된 프로그램을 주기억장치에 적재하고, CPU가 프로그램 카운터가 가리키는 명령어를 하나씩 인출·해독·실행하는 사이클을 반복하는 방식이다. 프로그램을 바꾸려면 배선이 아니라 메모리 내용만 바꾸면 된다.

</details>

<details>
<summary>5. 정보보호의 3요소를 설명하라</summary>

- 기밀성: 허가된 사용자만 정보를 열람할 수 있다. 암호화는 기밀성을 지키는 대표적인 수단이다.
- 무결성: 허가된 사용자가 허가된 방법으로만 정보를 변경할 수 있다.
- 가용성: 허가된 사용자가 필요한 시각에 정보를 사용할 수 있다.

</details>

<details>
<summary>6. 제2차 세계대전에서 독일군이 쓴 회전자 방식 암호 기계와, 그 해독에 쓰인 장치는</summary>

에니그마다. 독일의 아르투어 셰르비우스가 1918년 특허를 출원했다. 해독은 폴란드 암호국이 1932년 처음 성공했고, 영국 블레츨리 파크에서는 전기기계식 장치 봄브로 해독했다. 같은 곳의 전자식 계산기 콜로서스는 에니그마가 아닌 로렌츠 암호 해독에 쓰였다.

</details>

## 정리

- 계산 기계는 톱니바퀴(파스칼린, 단계 계산기)에서 계전기(Mark I), 진공관(ABC, ENIAC)으로 발전했다. 해석기관은 연산·기억·제어·입출력의 구분을, 튜링 기계는 계산의 이론적 정의를 제공했다.
- 프로그램 내장 방식은 명령어를 데이터와 함께 메모리에 저장해, 배선을 바꾸지 않고 프로그램을 교체할 수 있게 했다.
- 하드웨어는 입력·처리(CPU)·기억·출력 장치로, 소프트웨어는 시스템 소프트웨어와 응용 소프트웨어로 나뉜다.
- 보안 사고는 전화망 조작에서 네트워크 웜, DDoS, 개인정보 유출, 랜섬웨어로 범위가 넓어졌다.
- 정보보호의 목표는 기밀성·무결성·가용성이며, 각 요소는 서로 다른 공격과 대책에 대응한다.
