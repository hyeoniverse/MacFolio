macOS의 Apple 메뉴 맨 위에는 늘 **이 Mac에 관하여**가 있다. 누르면 가운데에 작은 창이 뜨고, Mac 그림, 이름(MacBook Pro), 칩·메모리·일련 번호·macOS 버전, '추가 정보…' 단추가 보인다. 이 사이트의 Apple 메뉴에는 이 항목이 없었다. 포트폴리오에서 "이 Mac"은 결국 만든 사람이므로, 같은 창 모양에 프로필을 넣었다.

## 무엇이 보이나

| macOS               | 이 사이트                                   |
| ------------------- | ------------------------------------------- |
| Mac 그림            | GitHub 프로필 사진 (동그랗게)               |
| MacBook Pro         | 김정현, 아래에 Kim Jeong Hyeon              |
| 칩·메모리·일련 번호 | 직무·학교·위치·이메일·GitHub·주요 기술      |
| 추가 정보…          | 시스템 설정의 '정보'를 연다                 |
| 규제 인증서         | 개인정보 처리 방침                          |
| ™ & © Apple Inc.    | ™ & © 올해 Kim Jeong Hyeon. 모든 권리 보유. |

값은 모두 `shared/profile.ts`의 `PROFILE`과 `SKILLS`에서 읽는다. 프로필을 고치면 이 창도 따라 바뀐다.

링크는 두 가지다.

- **이메일:** `mailto:`로 기기의 메일 앱을 여는 대신, 이 사이트의 **메일 앱**에서 '새로운 메시지'를 바로 연다. 받는 사람이 늘 사이트 주인으로 정해져 있는 쓰기 화면이라, 방문자는 사이트를 떠나지 않고 메일을 보낸다. 휴대폰에서는 아래에서 올라오는 쓰기 시트가 열린다. 메일 앱이 이미 열려 있어도 바로 쓰기 화면으로 간다. 시스템 설정을 열 때처럼 작은 저장소에 "새로운 메시지를 열어 달라"고 적어 두면, 메일 앱이 읽고 비운다.
- **GitHub:** 바깥 링크라 새 탭으로 연다. 값 뒤에 ↗를 붙여, 누르면 사이트 밖으로 나간다는 것을 미리 보여 준다(나간 링크로 센다).

사진은 GitHub에서 받는데, 받지 못하면 이름 끝 두 글자를 회색 동그라미에 쓴다.

## 추가 정보…

macOS에서 '추가 정보…'는 시스템 설정의 **일반 › 정보**를 연다. 처음에는 Safari(자기소개가 있는 첫 화면)를 열게 했는데, 작은 창에서 한 단계 더 들어가는 느낌이 나지 않았다. 그래서 macOS처럼 시스템 설정에 **정보** 항목을 만들고 그쪽을 열게 했다.

정보에는 작은 창보다 자세한 내용이 묶음별로 있다.

- 프로필: 이름(한글·영문), 직무, 학교, 위치
- 연락처: 이메일, GitHub
- 기술: 프론트엔드·백엔드·인터랙션 전부
- 이 사이트(MacFolio): 만든 기술, 저장소

시스템 설정이 이미 열려 있어도 정보로 간다. 활동 상태 보기의 탭을 메뉴 막대에서 고를 때와 같은 방식이다. 작은 저장소에 "이 항목으로"를 적어 두면, 설정 앱이 그 값을 구독하고 있다가 읽고 비운다.

## 규제 인증서 자리에 개인정보 처리 방침

macOS의 이 창에는 저작권 줄 바로 위에 **규제 인증서** 링크가 있다. 이 사이트에서 그 자리에 맞는 문서는 개인정보 처리 방침이다(방문 분석, 방문자 쿠키, 메일을 다룬다). 그래서 같은 자리에 같은 모양의 링크를 두고, Apple 메뉴의 '개인정보 처리 방침'처럼 Finder에서 `docs/privacy.md`를 연다.

## 앱이 아니라 시스템 창

이 창을 앱으로 만들면 Dock 아이콘, Finder의 응용 프로그램, 터미널의 `open` 명령에 모두 자리가 생긴다. macOS에서도 이 창은 앱이 아니므로, 데스크톱이 직접 그리는 작은 창으로 만들었다.

- 열림 상태는 작은 저장소(`aboutStore`) 하나가 갖고, Apple 메뉴가 연다.
- macOS처럼 닫기 단추만 빨갛고, 최소화·확대는 회색으로 꺼져 있다.
- 창의 빈 곳을 잡아 옮긴다. 글자(값)와 단추, 링크 위에서는 옮기지 않아 글자를 고를 수 있다.
- 열리면 닫기 단추에 초점이 가고, Esc로도 닫힌다.
- 휴대폰에는 Apple 메뉴가 없으므로 이 창도 없다.

## 시험

- Apple 메뉴의 첫 항목이 '이 Mac에 관하여'
- 이름·영문 이름·사양 줄 여섯 개
- 이메일은 메일 앱의 새로운 메시지를 연다 (메일 앱이 열려 있어도, 시스템 설정의 정보에서도, 휴대폰에서도)
- GitHub은 ↗와 함께 새 탭으로 연다
- 열면 메뉴가 닫히고 닫기 단추에 초점, Esc와 닫기 단추로 닫힘
- 개인정보 처리 방침 링크는 창을 닫고 Finder에서 문서를 엶
- 빈 곳을 끌면 끈 만큼 옮겨짐, '추가 정보…'는 창을 닫고 시스템 설정의 정보를 엶 (이미 열려 있어도)
