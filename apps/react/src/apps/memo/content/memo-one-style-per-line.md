메모 편집기에서 목록 항목에 커서를 두고 서식 메뉴의 '머리말'을 누르면 아무 일도 일어나지 않았다. 머리말에서 '토글 목록'을 누르면 머리말은 그대로 두고 빈 토글이 아래에 하나 더 생겼다. 토글 제목에서 '제목'을 눌러도 그대로였다.

## 노션처럼, 아니면 macOS 메모처럼

노션은 목록 안에 제목을 넣을 수 있고, 제목 자체를 토글로 만들 수도 있다. macOS 메모는 줄마다 모양이 하나다. 제목·머리말·부머리말·본문·모노 스타일·목록 셋 가운데 하나를 고르면, 앞의 모양은 사라진다.

macOS 메모처럼 하기로 했다.

- 서식 메뉴가 처음부터 macOS 메모의 모양 목록을 그대로 따른다. 항목도 하나만 고르는 라디오 버튼(`menuitemradio`)다.
- 글은 Markdown으로 저장된다. 목록 안의 제목은 `- ## 제목`이 되는데, 읽기 화면에서는 목록 점 옆에 큰 제목이 붙어 어색하다.
- 토글 제목을 머리말로 만들려면 `<summary>` 안에 서식을 넣어야 한다. 읽기 화면은 본문의 HTML을 그리지 않고, 토글 제목도 안전하게 글자로만 넣는다.

## 고른 모양으로 그 줄을 바꾼다

정했으면 그대로 동작해야 한다. 아무 일도 없던 곳에서, 고른 모양으로 그 줄을 바꾼다.

| 지금 줄   | 고른 것               | 결과                                                       |
| --------- | --------------------- | ---------------------------------------------------------- |
| 목록 항목 | 제목·머리말·본문·모노 | 목록에서 꺼내 그 모양으로 (남은 항목은 목록 그대로)        |
| 목록 항목 | 토글 목록             | 목록에서 꺼내 그 글자를 제목으로 한 토글                   |
| 머리말    | 토글 목록             | 머리말 글자가 토글 제목 (빈 토글을 새로 만들지 않는다)     |
| 머리말    | 목록                  | 본문으로 바꿔 목록에 넣는다 (목록 항목의 첫 줄은 본문이다) |
| 토글 제목 | 제목·목록·인용        | 토글을 풀고 그 줄을 그 모양으로 (내용은 아래에 그대로)     |

편집기의 목록 항목은 첫 줄이 늘 문단이어야 한다(`paragraph block*`). 그래서 목록 항목 안에서 문단을 머리말로 바꾸는 명령은 아무 일도 하지 않고 실패했다. 이제 목록에서 먼저 꺼낸 다음 바꾼다.

```ts
case 'block': {
	// macOS 메모처럼 한 줄에 모양은 하나: 목록이나 토글 제목에서 고르면 그 줄을 꺼내 고른 모양으로 바꾼다
	const converted = current.summary || current.list !== null;
	if (current.summary) toggleDetails(view);
	else if (current.list) leaveList(ctx);
	// …
}
```

토글 제목에 커서가 있으면 서식 메뉴에서 '본문'이 아니라 '토글 목록'이 골라져 보이게 했다. 커서 자리의 서식에 `summary`(토글 제목 줄인지)를 더했다.

## 구분선

구분선(`---`)은 스타일이 없어서 브라우저 기본값으로 그려졌다. 회색 2px 입체 선이었고, 위 여백만 있고 아래 여백은 0이었다. 다크 모드에서는 밝고 굵은 선이 됐다.

테두리색 1px 선에, 위아래 1.8em 같은 여백으로 바꿨다. 편집기도 `.memo-markdown`이라 읽기 화면과 같은 규칙을 쓴다. 편집기에서 구분선을 고르면 강조색 테두리가 보인다.

편집기는 구분선을 `***`로 저장하고 있었다(remark-stringify 기본값). 지금 글들은 `---`를 쓰니, 목록 기호(`bullet: '-'`)처럼 `rule: '-'`을 줬다.
