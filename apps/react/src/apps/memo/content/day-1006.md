## 단축키: ⌘ 대신 ⌥

### 이유

macOS 앱은 ⌘N·⌘T·⌘W를 사용하지만, 브라우저 안의 웹 페이지는 이 키 입력을 받지 못한다. 브라우저가 먼저 새 창·새 탭·탭 닫기를 실행하고, 페이지에서 `preventDefault()`로 막을 수도 없다. 그래서 같은 글자에 ⌥를 조합했다([#112](https://github.com/hyeoniverse/MacFolio/pull/112)).

| 키               | 동작                                       |
| ---------------- | ------------------------------------------ |
| ⌥N               | 새로운 메모(관리자) · 새로운 Finder 윈도우 |
| ⌥T · ⌥W          | 새로운 탭 · 탭 닫기 (Safari)               |
| ⌥[ · ⌥] · ⌥↑     | 뒤로 · 앞으로 · 상위 폴더 (Finder)         |
| ⌥Space · ⌥← · ⌥→ | 재생/일시정지 · 이전 곡 · 다음 곡 (음악)   |
| ⌥W · ⌥M          | 윈도우 닫기 · 최소화 (공통)                |

### 중복된 ⌥W

도움말에 키보드 단축키 목록을 추가하고 화면에 표시해 보니, Safari에 '탭 닫기 ⌥W'와 '윈도우 닫기 ⌥W'가 함께 있었다. 같은 키가 두 항목에 지정되면 앞쪽 항목만 동작하므로, 윈도우 닫기는 메뉴에 단축키가 표시되지만 실제로는 동작하지 않았다.

| 상황                      | '윈도우 닫기' 단축키 |
| ------------------------- | -------------------- |
| 앱이 ⌥W를 사용하지 않음   | ⌥W                   |
| 앱이 ⌥W를 사용함 (Safari) | ⌥⇧W                  |

macOS Safari와 같은 규칙이다. 단축키 목록을 화면에 표시하지 않았다면 발견하지 못했을 문제다.

![현재의 키보드 단축키 목록](./images/day-1006-shortcuts.jpg '도움말 → 키보드 단축키의 현재 화면')

## 메뉴 구성: 맨 앞 앱의 메뉴만

밤에는 메뉴 구성을 정리했다. macOS에서 메뉴 막대는 맨 앞 앱의 메뉴만 표시한다. 이 원칙에 맞지 않는 항목을 정리했다([#114](https://github.com/hyeoniverse/MacFolio/pull/114)).

| 메뉴         | 변경 전           | 변경 후                           |
| ------------ | ----------------- | --------------------------------- |
| 윈도우       | 다른 앱 목록 포함 | 맨 앞 앱의 윈도우 항목만          |
| 보기         | 다크 모드 포함    | 다크 모드 제외 (앱의 보기 항목만) |
| 굵은 앱 이름 | 메뉴 없음         | 앱 메뉴 (가리기, 종료)            |
| Safari       | -                 | 책갈피 메뉴 추가                  |
| 메일         | -                 | 사서함 메뉴 추가                  |

자세한 내용은 [메뉴 막대 4 - 앱이 등록한 메뉴를 공통 메뉴와 병합하는 메뉴 막대 구조](/memo/menubar-menus)에 적었다.

## 돌아보며

**브라우저가 가로채는 키 대신 ⌥를 사용한 것은 올바른 결정이었다.** 화면에 표시되는 단축키와 실제로 동작하는 단축키가 항상 일치한다. 중복된 ⌥W는 단축키 목록을 화면에 표시해 발견했다.

**메뉴 막대 작업을 여섯 번에 나눠 진행했다.** 전날 저녁, 이날 오전, 이날 밤, 다음 날 새벽 두 번, 다음 날 밤이다. "맨 앞 앱의 메뉴만"이라는 원칙을 처음에 정했다면 정리용 커밋이 따로 필요하지 않았다. 다음 날 새벽에는 main에서만 실패하는 메뉴 시험까지 발생했다([10월 7일](/memo/day-1007)).
