하루 동안 커밋 12개가 main에 들어갔다. 열흘 중 가장 적다. 오전 9시 49분부터 12시 28분까지 세 시간 남짓 일하고, 밤 11시 37분에 하나를 더 했다. 새 글은 없고, 고친 내용은 모두 있던 글에 더했다.

![10월 6일 작업 흐름](./images/day-1006-timeline.svg '오전 세 시간 동안 메뉴 막대, 밤에 정리 하나')

## 오전: 앱마다 메뉴

전날 저녁 메뉴 막대의 파일·보기·윈도우·도움말이 실제로 열리게 했다. 이날은 그 메뉴에 앱마다 할 일을 채웠다.

먼저 작은 것 둘. 메모 글 안의 다른 글·프로젝트 링크는 새 탭이 아니라 사이트 안에서 열리게 하고, 메뉴 막대를 눌러도 지금 앱이 Finder로 바뀌지 않게 했다. 그다음 메모·Safari·Finder·음악이 자기 메뉴를 등록하고, 낮 12시 28분까지 메일·터미널·시스템 설정·iframe 앱(프로젝트 앱, API 문서)까지 붙였다.

![지금의 메뉴 막대 메뉴](./images/day-1006-menu.jpg '메모 앞에서 메뉴 막대의 메뉴를 연 지금 모습')

## 단축키는 ⌘ 대신 ⌥

macOS 앱은 ⌘N·⌘T·⌘W를 쓰지만, 브라우저 안의 페이지는 이 키를 받지 못한다. 브라우저가 먼저 새 창·새 탭·탭 닫기를 해 버린다. 그래서 같은 글자에 ⌥를 붙였다.

| 키               | 하는 일                                    |
| ---------------- | ------------------------------------------ |
| ⌥N               | 새로운 메모(관리자) · 새로운 Finder 윈도우 |
| ⌥T · ⌥W          | 새로운 탭 · 탭 닫기 (Safari)               |
| ⌥[ · ⌥] · ⌥↑     | 뒤로 · 앞으로 · 상위 폴더 (Finder)         |
| ⌥Space · ⌥← · ⌥→ | 재생/일시정지 · 이전 곡 · 다음 곡 (음악)   |
| ⌥W · ⌥M          | 윈도우 닫기 · 최소화 (공통)                |

도움말에는 키보드 단축키 목록을 넣었다. 목록을 띄워 보니 Safari에 '탭 닫기 ⌥W'와 '윈도우 닫기 ⌥W'가 함께 있었다. 같은 키는 앞쪽 항목만 들어서, 윈도우 닫기는 단축키가 있다고 보이는데 실제로는 되지 않았다. macOS Safari처럼 앱이 ⌥W를 쓰면 공통 '윈도우 닫기'는 ⌥⇧W로 바꿨다. 목록을 띄우지 않았으면 몰랐을 것이다.

![지금의 키보드 단축키 목록](./images/day-1006-shortcuts.jpg '도움말 → 키보드 단축키의 지금 모습')

## 밤: 그 앱의 것만

밤 11시 37분에는 메뉴를 정리했다. 윈도우 메뉴에 다른 앱 목록이, 보기 메뉴에 다크 모드가 있었다. macOS에서 메뉴 막대는 맨 앞 앱의 것이다. 이것들을 빼고, 굵은 앱 이름을 앱 메뉴(가리기, 종료)로 만들고, Safari에는 책갈피, 메일에는 사서함 메뉴를 넣었다.

| 한 일                                          | 글                                           |
| ---------------------------------------------- | -------------------------------------------- |
| 글 안의 링크는 사이트 안에서                   | 앱 안의 화면에 주소 붙이기                   |
| 메뉴 막대를 눌러도 앱이 그대로                 | 메뉴 막대의 앱 이름이 맨 앞 창을 따른다      |
| 앱마다 메뉴, 단축키, 단축키 목록, 그 앱의 것만 | 메뉴 막대의 파일·보기·윈도우가 실제로 열린다 |

## 돌아보며

- **잘한 것: 브라우저가 못 받는 키를 억지로 받으려 하지 않았다.** ⌘W는 사이트가 막을 수 없게 되어 있다. ⌥로 옮기고, 화면에 보이는 키와 실제로 듣는 키가 늘 같게 했다.
- **잘한 것: 목록을 만들어 겹침을 찾았다.** 단축키 목록을 화면에 띄우자 ⌥W 겹침이 바로 보였다.
- **아쉬운 것: 메뉴 막대를 여러 번에 나눠 했다.** 전날 저녁, 이날 오전, 이날 밤, 다음 날 새벽 두 번, 다음 날 밤. 무엇을 넣을지(그 앱의 것만)를 처음에 정했으면 정리하는 커밋이 따로 필요 없었다. 다음 날 새벽에는 main에서만 실패하는 메뉴 시험까지 나왔다.
