휴지통의 '내 브라우저 데이터'를 비우면 "이 사이트가 이 브라우저에 남긴 것이 없습니다"라는 한 줄만 남았다. 그런데 Dock의 휴지통 그림은 그대로 종이가 가득 담긴 휴지통이었다. macOS는 비어 있으면 빈 휴지통, 무언가 있으면 종이가 담긴 휴지통을 보여 준다. 처음 온 방문자도 늘 종이가 담긴 휴지통을 봤으니, "무언가 남아 있다"는 거짓 신호를 모두에게 주고 있었다.

고친 것은 PR [#184](https://github.com/hyeoniverse/MacFolio/pull/184)의 커밋 하나다([휴지통 앱](/memo/bin-app)을 만든 다음 날).

## 빈 휴지통 그림

빈 휴지통 그림은 원래 그림(`bin.png`)에서 만들었다. 같은 모양과 음영이어야 두 그림이 바뀔 때 어색하지 않다.

- 테 위로 솟은 종이는 지운다(투명하게).
- 테 안쪽에는 위가 조금 어둡고 앞으로 밝아지는 회색을 칠하고, 앞쪽 테 바로 안에 옅은 그늘을 넣는다.
- 몸통에 비치던 종이의 색은, 종이 그림자가 적은 아래쪽의 열마다 밝기를 원통 음영으로 삼아 덮는다.

![두 그림](./images/bin-empty-state-icons.jpg '둘 다 388×388. 빈 그림은 원래 그림에서 종이를 걷고 안쪽을 칠해 만들었다')

크기와 테두리 위치가 같아서 Dock에서 그림이 바뀌어도 아이콘이 움직이지 않는다. 파일 크기는 종이가 사라진 만큼 줄었다(77KB → 42KB).

## 언제 비었다고 보나

'내 브라우저 데이터'와 같은 기준이다. `readBrowserData()`가 돌려주는 항목이 하나도 없으면 비었다고 본다. 처음 온 브라우저는 아무것도 남기지 않았으므로 빈 휴지통으로 시작한다.

어려운 점은 **언제 다시 볼지**였다. 메모 검색어, 날씨 장소처럼 앱들이 `localStorage`에 직접 쓰는데, 같은 탭에서 쓴 것은 `storage` 이벤트로 알려 주지 않는다. 그래서 세 가지로 다시 본다.

- 휴지통에서 비우면 그 자리에서 (`refreshBin()`)
- 설정을 바꾸면 (설정 저장소를 구독)
- 그 밖에는 화면이 보이는 동안 2초마다. 키 몇 개만 읽으므로 가볍다.

![다시 보는 때](./images/bin-empty-state-recheck.svg '세 가지 때와 다른 탭의 storage 이벤트가 같은 함수를 부른다')

| 방법                                    | 좋은 점                 | 문제                                                       |
| --------------------------------------- | ----------------------- | ---------------------------------------------------------- |
| 앱마다 쓴 뒤에 `refreshBin()` 부르기    | 늦음이 없다             | 키를 쓰는 곳 모두가 휴지통을 알아야 한다. 하나 빠지면 그만 |
| `localStorage.setItem`을 감싸서 알리기  | 쓰는 곳을 고치지 않는다 | 전역 객체를 바꾼다. 다른 라이브러리까지 영향을 받는다      |
| 아는 때 + 2초마다 다시 읽기 (고른 방법) | 쓰는 곳은 모른다        | 길게는 2초 늦다                                            |

휴지통 그림이 2초 늦게 바뀌는 것은 아무도 알아채지 못한다. 반대로 휴지통에서 비울 때는 바로 바뀌어야 하니 그때만 직접 부른다. 탭이 숨어 있으면 읽지 않는다.

```ts
export function refreshBin() {
	const empty = readBrowserData().length === 0;
	if (binStore.getState().empty !== empty) binStore.setState({ empty });
}
```

값이 바뀔 때만 `setState`를 불러서, 2초마다 읽어도 Dock은 다시 그려지지 않는다.

## 휴지통 창

처음에는 가운데에 빈 휴지통 그림과 '휴지통이 비어 있음' 문구를 크게 두었는데, 실제 macOS Finder의 빈 휴지통은 그렇지 않다. 가운데는 그냥 비어 있고, 위쪽 줄 오른쪽에 꺼진 **비우기** 버튼, 아래 상태 막대에 '0개의 항목'만 있다. 빈 휴지통 그림도 Dock에서 이미 보이므로 창 안에는 두지 않는다. 그대로 맞췄다.

![빈 휴지통 창](./images/bin-empty-state-window.jpg '처음 온 브라우저에서 연 휴지통. 가운데는 비어 있고, 꺼진 비우기 버튼과 '0개의 항목'만 있다')

- 위쪽 줄: 오른쪽에 Finder처럼 작은 회색 **비우기** 버튼. 남은 것이 있으면 왼쪽에 '이 사이트가 이 브라우저에 남긴 것 n가지 · 크기', 비었으면 '내 브라우저 데이터'와 꺼진 비우기. 전에는 빨간 '휴지통 비우기' 버튼이었는데, 지우기 전에 한 번 더 묻는 창이 있으므로 버튼까지 빨갈 필요는 없다.
- 가운데: 비었으면 아무것도 없다. 화면 읽기 프로그램에는 숨은 글자로 '휴지통이 비어 있습니다'를 알린다.
- 아래 상태 막대: 'n개의 항목'.
- 방문자 이름 쿠키는 사이트가 지울 수 없어서, 남은 것이 있을 때는 다른 줄과 같은 모양의 줄로 두되 비우기 버튼 자리에 "브라우저 설정에서"라고 적고, 비었을 때는 아래 안내 글에 한 줄로 알린다.

## 시험

`e2e/bin.spec.ts`의 **내 브라우저 데이터: 이 사이트가 남긴 것을 보여 주고, 비우면 처음 설정으로 돌아간다**와 **처음 온 브라우저는 Dock의 휴지통이 비어 있고, 설정을 바꾸면 종이가 담긴다**가 확인한다.

- 남긴 것이 있으면 Dock에 `bin.png`, 휴지통을 비우면 목록이 사라지고 비우기 버튼이 꺼지고 '0개의 항목'이 보이며, Dock도 바로 `bin-empty.png`로 바뀐다.
- 처음 온 브라우저는 빈 휴지통이고, 시스템 설정에서 다크 모드를 고르면 종이가 담긴 휴지통으로 바뀐다.

## 그 뒤, 남은 것

- 10월 18일 Finder에 "휴지통으로 이동"이 생기면서, 비었는지의 기준에 Finder에서 버린 항목(`layout.trash`)도 더했다. 둘 다 비어야 빈 휴지통이다.
- 2초마다 읽는 것은 탭마다 따로 돈다. 탭을 여러 개 열어 두면 탭 수만큼 읽지만, 숨은 탭은 읽지 않으므로 실제로는 보이는 탭 하나뿐이다.
- 빈 상태를 "비었다는 문구를 크게"로 만들었다가 macOS를 다시 보고 걷어 냈다. 흉내 내는 대상이 있으면 짐작하지 말고 실제 화면을 먼저 본다.
