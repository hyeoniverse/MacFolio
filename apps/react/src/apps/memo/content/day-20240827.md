이 글은 2026년 10월에 git 기록을 다시 읽으며 쓴 회고다. 그날 남긴 메모는 없고, 근거는 그날의 커밋(`d5ece086c`, `7625dfa2c`, `2b6177967`)과 그 코드뿐이다. 화면은 캡처할 수 없어서 코드 구조를 그림으로 대신한다.

이날 커밋은 오후 2시 31분부터 34분 사이에 세 개다. 빈 저장소를 만들고, 파일 39개를 한 번에 커밋하고, `main.html`의 이름을 `index.html`로 변경했다. 그 뒤 45일 동안 커밋이 없다.

![2024년 8월 27일 작업 흐름](./images/day-20240827-timeline.svg '3분 동안의 커밋 세 개')

## 구성: 빌드 도구 없는 세 파일

빌드 도구도 패키지 관리자도 없었다. 브라우저가 `index.html`을 열면 CDN에서 jQuery 3.6과 Font Awesome 6 베타를 내려받고, `script.js`와 `style.css`를 불러오는 것이 전부다.

![첫 커밋의 구조](./images/day-20240827-structure.svg '코드는 세 파일, 나머지 61MB는 글꼴·그림·음악')

`script.js` 455줄 안에 현재 사이트의 기본 구조가 대부분 들어 있다.

- 창: 닫기, 최소화, 전체 화면, 제목 표시줄 드래그로 이동. 창은 Safari 하나뿐이었다.
- 상태 막대의 시계.
- Dock: 13칸. 클릭하면 아이콘 아래 실행 표시(`active-indicator`)가 활성화된다. GitHub·블로그·노션·메일은 외부 링크였다.
- 음악: jQuery로 작성한 플레이어(재생 위치 드래그, 이전·다음 곡)와, 첫 클릭에 배경 음악을 재생하는 코드.

Safari 창 안에는 프로젝트 카드 세 개(새싹 농장, 퍼펙데이, 챗벗)가 있었다.

## 자산: 저장소에 커밋된 61MB

코드는 1,032줄이고, 저장소 용량의 대부분은 자산이었다. 모두 압축이나 최적화 없이 저장소에 커밋되었다.

| 자산                     | 파일 수 |   크기 |
| ------------------------ | ------: | -----: |
| Apple SD Gothic Neo 글꼴 |       9 | 33.0MB |
| 그림 (배경 12.5MB 포함)  |      24 | 13.8MB |
| 음악                     |       3 | 14.6MB |

## 지금과 비교하면

| 당시 (script.js)                          | 지금                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 창 닫기·최소화·드래그를 DOM에서 직접 처리 | 창 위치·크기·겹침 계산은 React도 브라우저도 모르는 `desktop-core`에 ([창 관리를 core로](/memo/desktop-core-windows)) |
| jQuery 음악 플레이어                      | 재생 목록·셔플·반복은 core의 플레이어 store ([음악을 core로](/memo/desktop-core-music))                              |

| GitHub = 프로필로 가는 링크               | API가 받아 오는 GitHub 앱 ([GitHub 프로필을 실제 값으로](/memo/github-live-profile))                                 |
| Safari의 프로젝트 카드 3개를 HTML에 작성  | 시스템 설정에서 수정하는 프로젝트 페이지 ([프로젝트 관리](/memo/site-projects-editing))                              |

## 돌아보며

첫 커밋에 이미 "macOS 화면 안에 포트폴리오를 배치한다"는 설계가 담겨 있었다. 창, Dock, 상태 막대, 음악, Safari 안의 프로젝트다. 2년이 지난 지금도 화면의 큰 틀은 그대로이고, 바뀐 것은 그 구조를 구현하는 코드다. 455줄짜리 파일 하나가 하던 일이 지금은 패키지와 앱 수십 개로 나뉘었다.

자산을 저장소에 직접 커밋하는 방식은 이후에도 이어졌다. 두 달 뒤에는 `node_modules`까지 커밋했다([2024년 10월 26~27일 회고](/memo/day-20241026)).
