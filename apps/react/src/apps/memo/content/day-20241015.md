이 글은 2026년 10월에 git 기록을 다시 읽으며 쓴 회고다. 그날의 커밋 12개와 그 코드를 근거로 썼고, 화면 대신 그때의 메모 앱 구조를 그림으로 그렸다.

커밋은 세 덩어리다. 새벽 2시 43분~58분에 메모 앱과 창 손질, 아침 7시 27분~42분에 GitHub 앱과 음악, 오전 11시 37분~42분에 메모 앱 다듬기다.

![2024년 10월 15일 작업 흐름](./images/day-20241015-timeline.svg '새벽 2시, 아침 7시, 오전 11시에 커밋이 모였다')

## 메모 앱 첫판

2시 43분 커밋의 메시지는 "fix: app state"인데, 들어간 것은 메모 앱 첫판(`Memo.tsx` 133줄, `Memo.css` 161줄)이다. macOS 메모처럼 왼쪽에 폴더, 가운데에 메모 목록, 오른쪽에 본문을 둔다. `Button`, `Input`, `ScrollArea` 같은 작은 공통 컴포넌트도 이때 생겼다.

데이터는 모두 코드에 있었다. 폴더 다섯 개(모든 iCloud 메모, 메모, 공부, 아이디어, 스케치)와 메모 세 개(파스타 레시피, 책 읽기, 프로그래밍 공부)를 `useState`의 처음 값으로 넣었다. 새로고침하면 처음으로 돌아간다.

같은 커밋에서 서버에 `routes/memo.js`(24줄)를 더했다. `let memos = []`인 메모리 배열에 GET·POST를 붙인 것이고, 화면은 이 경로를 부르지 않았다. 반대로 이틀 전 만든 메일 경로 `routes/mail.js` 39줄은 이 커밋에서 지워졌다.

![10월 15일의 메모 앱 구조](./images/day-20241015-structure.svg '화면과 서버 모두 메모를 메모리에만 들고 있었다')

11시 42분에는 "모든 iCloud 메모" 폴더를 고르면 모든 메모를 보이게 했다. 폴더 id가 `'1'`이면 폴더 거르기를 건너뛰는 한 줄이다.

## GitHub 앱과 음악

7시 27분에 GitHub 앱을 더했다. 프로필 사진·이름·링크, GitHub README에 있던 배지와 통계 그림, 고정 저장소 목록을 JSX로 옮겨 적었다. 통계 그림은 바깥 서비스(github-readme-stats 등)의 그림 주소를 그대로 썼다.

7시 38분에는 배경 음악을 첫 클릭에 틀게 했다. 브라우저는 사용자가 페이지와 상호작용하기 전에는 소리 나는 자동 재생을 막는다. `window`에 클릭 리스너를 한 번 달아 두고, 처음 누르면 재생하고 리스너를 뗀다. 같은 시각에 볼륨 창은 음악 플레이어 쪽(`MusicPlayerVolume`)으로 옮겼다.

새벽의 짧은 커밋 셋은 창 손질이다. 제목 표시줄을 두 번 누르면 최대화하고(`onDoubleClick`), Blog 앱에 남아 있던 `bringAppToFront` 호출 하나를 지웠다.

## 돌아보며

메모 앱은 이날 "메모처럼 생긴 화면"으로 시작했다. 무엇을 담을지는 정하지 않았고, 그래서 내용은 파스타 레시피 같은 예시였다. 1주일 뒤에는 서버와 DB를 붙였고([2024년 10월 21~22일 회고](/memo/day-20241021)), 2년 뒤에는 이 앱이 사이트의 블로그가 되었다. 모양을 먼저 만든 앱이 나중에 가장 많은 일을 맡게 되었다.

커밋 메시지는 이날 가장 아쉬운 부분이다. 메모 앱 첫판이 "fix: app state", 메일 경로 삭제도 같은 커밋에 섞였다. 2년 뒤 이 회고를 쓸 때 가장 오래 걸린 것이 메시지와 내용을 맞추는 일이었다.
