GitHub 앱의 Pinned는 두 칸 그리드다. 그리드는 같은 줄의 카드끼리만 높이를 맞추기 때문에, 설명이 긴 저장소가 있는 줄은 높고 다른 줄은 낮았다. 설명이 없거나 짧은 카드는 언어·별·데모 줄이 설명 바로 밑에 붙어서 카드 아래쪽이 비어 보였다.

![Pinned 카드 전후](./images/github-pinned-card-size.jpg '위: 줄마다 높이가 다름 / 아래: 모든 카드가 같은 크기')

## 고친 것

- **모든 줄을 같은 높이로**: 그리드에 `grid-auto-rows: 1fr`을 줬다. 줄 높이가 모두 가장 높은 카드에 맞춰진다.
- **설명은 세 줄까지**: 설명 하나가 아주 길면 모든 카드가 함께 커진다. `-webkit-line-clamp: 3`으로 세 줄에서 자르고, 마우스를 올리면 `title`로 전체 설명을 보여 준다. GitHub의 Pinned도 설명을 자른다.
- **언어 줄은 카드 아래에**: 언어·별·데모 줄에 `margin-top: auto`를 줘서, 설명이 짧거나 없어도 카드 아래에 붙는다.

E2E 시험에서 Pinned 카드들의 높이가 모두 같은지, 카드 아래에서 언어 줄까지의 거리가 모두 같은지 확인한다.
