메뉴 막대의 Wi-Fi 자리에는 이미 서버(API)가 살아 있는지가 보인다. 그 옆 배터리는 3/4이 찬 그림일 뿐이었다. 서버 자원 감시를 만든 김에([무료 서버가 회수되기 전에](/memo/resource-monitor)) 이 배터리에 뜻을 붙였다. 관리자에게는 서버 자원을, 방문자에게는 방문 추이를 보여 준다. 사용률을 보려고 매번 '활동 상태 보기'를 여는 대신, 메뉴 막대를 한 번 보면 위험한지 알 수 있게 하고 싶었다.

같은 날 커밋 셋으로 했다(서버 자원 배터리, macOS 모양 SVG, 방문자용 방문 추이). 모두 PR [#162](https://github.com/hyeoniverse/MacFolio/pull/162)로 머지됐다. 메뉴는 `src/desktop/status-bar/BatteryMenu.tsx`(132줄), 값 계산은 `src/apps/activity/useServerResources.ts`(88줄)와 `useVisitTrend.ts`(75줄), 그림은 `src/shared/server/ServerBattery.tsx`다.

![배터리 단계](./images/battery-server-resources-levels.svg '왼쪽 관리자(유휴 회수 위험), 오른쪽 방문자(방문 추이). 같은 그림에 fill만 다르다')

## 관리자: 서버 자원

Always Free 서버라면 배터리는 **유휴 회수에서 얼마나 먼지**를 나타낸다. 사용률이 낮을수록 회수에 가까워지므로, 여유가 없을수록 배터리가 빈다.

| 회수 위험 (서버 탭과 같은 계산)  | 배터리          |
| -------------------------------- | --------------- |
| 안전                             | 가득            |
| 주의 (모든 기준이 30% 미만)      | 1/4, 주황       |
| 회수 위험 (모든 기준이 20% 미만) | 비어 있음, 빨강 |
| 아직 모름                        | 절반            |

종량제(`payg`)이거나 감시가 꺼져 있으면 회수 걱정이 없으니 평소 모양(3/4) 그대로 둔다.

## 방문자: 방문 추이

방문자에게 서버 자원은 보여 줄 수 없다(`/resources`는 관리자만 부를 수 있고, 방문자 화면에서는 묻지도 않는다). 대신 누구나 보는 '활동 상태 보기' 개요와 같은 `GET /analytics/summary`로 **최근 7일 방문이 앞 7일보다 얼마나 늘었는지**를 배터리로 보인다.

| 앞 7일과 비교 | 배터리       |
| ------------- | ------------ |
| +100% 이상    | 가득         |
| +50%          | 3/4          |
| 같음          | 절반         |
| -50%          | 1/4          |
| -100%         | 거의 빔 (5%) |

계산은 `50 + 늘어난 비율 / 2`를 5~100%로 자른 값이다.

```ts
const percent =
	trend.previous > 0 ? ((trend.visits - trend.previous) / trend.previous) * 100 : trend.visits > 0 ? 100 : 0;
const fill = Math.round(Math.min(100, Math.max(5, 50 + percent / 2)));
```

![방문 추이와 배터리](./images/battery-server-resources-curve.svg '같음이 절반, 두 배가 가득. 아래는 5%에서 멈춰 빈 배터리처럼 보이지 않게 했다')

아래를 0이 아니라 5%에서 멈춘 것은, 빈 배터리가 관리자 화면에서 "회수 위험"의 모양이기 때문이다. 방문이 줄었다고 같은 경고 모양을 보일 이유는 없었다. 앞 7일에 방문이 없었으면 비율을 낼 수 없어서, 이번에 방문이 있으면 가득, 없으면 절반으로 둔다. 방문이 준 것은 경고할 일이 아니어서 색은 칠하지 않는다.

서버는 방문자에게 이 값을 1분 동안 같은 값으로 주고, 메뉴 막대는 10분마다 다시 묻는다. 방문자가 아무리 많아도 집계는 1분에 한 번이다. 서버에 닿지 못하면 평소 모양으로 둔다.

누르면 이렇게 보인다.

- `1,284회 방문`
- `앞 7일(1,146회)보다 +12% ▲`
- `오늘 224회`
- **활동 상태 보기에서 자세히**: 개요 탭을 연다

관리자 메뉴에도 서버 자원 아래에 같은 방문 줄이 있다.

## 배터리 모양

처음에는 Font Awesome의 배터리 아이콘(`fa-battery-*`)을 썼다. 그런데 단계마다 그림이 따로라 찬 정도를 마음대로 정할 수 없고, 테두리와 안쪽이 같은 굵기의 검은 덩어리라 macOS 메뉴 막대의 배터리와 달라 보였다.

| 방법                                | 좋은 점                 | 문제                                                 |
| ----------------------------------- | ----------------------- | ---------------------------------------------------- |
| Font Awesome `fa-battery-*` 다섯 개 | 이미 쓰는 아이콘 묶음   | 0·25·50·75·100%만 있다. 테두리가 굵어 macOS와 다르다 |
| 그림 파일(PNG·SVG) 여러 장          | 모양을 마음대로         | 찬 정도마다 파일이 필요하다                          |
| 컴포넌트 하나의 SVG (고른 방법)     | `fill` 값 하나로 1~100% | 다크 모드 색을 직접 맞춰야 한다                      |

그래서 Wi-Fi 자리의 서버 신호처럼 SVG로 직접 그렸다(`ServerBattery`). 옅은 테두리, 오른쪽의 작은 꼭지, 그리고 `fill`(%)만큼 차는 진한 안쪽 막대로 되어 있다. 주의와 위험일 때는 안쪽 막대만 macOS의 주황(`#ff9f0a`)과 빨강(`#ff453a`)으로 칠한다. 방문 추이와 평소 배터리(75%)도 같은 그림이다. 메뉴 안의 '유휴 회수' 줄에는 같은 배터리를 아이콘 칸(14px)에 맞게 줄여 둔다.

## 관리자 메뉴

macOS 배터리 메뉴처럼 짧게 보인다.

- `CPU 3.2% · 메모리 41% · 네트워크 0.6%`: 가장 최근에 잰 값. 네트워크는 Mbps가 아니라 대역폭(기본 50Mbps)에 견준 비율이라 다른 두 값과 같은 눈금으로 읽힌다
- `Always Free · VM.Standard.E2.1.Micro · 3분 전 측정`
- `유휴 회수: 위험`, 7일치가 쌓이기 전이면 `2일치로 미리 본 값`
- 방문 (최근 7일): 방문자 메뉴와 같은 줄
- **활동 상태 보기에서 자세히**: 그래프와 기준 표가 있는 서버 탭을 바로 연다

메뉴 막대는 5분마다, 그리고 메뉴를 열 때 한 번 더 묻는다. 서버는 1분마다 재므로 메뉴를 열면 늘 거의 최신 값이다.

## 앱을 특정 탭으로 열기

'활동 상태 보기'는 열 때마다 개요 탭으로 시작한다. 메뉴에서 서버 탭으로 바로 가려면 앱에 "이 탭으로 열어 달라"는 말을 전해야 했다. 주소로 앱 항목을 여는 방법(`/memo/<글>`)은 메모와 Safari에만 있고, 탭 하나를 고르는 데 주소까지 바꿀 일은 아니어서 작은 저장소 하나(`requestedTab`)를 두었다. 메뉴가 탭을 적고 앱을 열면, 앱이 그것을 읽어 그 탭으로 바꾸고 비운다. 앱이 이미 열려 있어도 구독하고 있으므로 같은 방법으로 바뀐다.

## 휴대폰

휴대폰 상태 표시줄의 배터리도 같은 값으로 찬다. 관리자에게는 서버 자원(회수 위험이면 빨갛게 조금만), 방문자에게는 방문 추이다. 상태 표시줄은 누르면 제어 센터가 열리는 자리라 메뉴는 따로 두지 않았다.

## 시험

- 단위 `useServerResources.test.ts`(3개): **지금 사용률 한 줄: 네트워크는 대역폭에 견준 비율**, **Always Free면 유휴 회수에서 먼 만큼 차 있다**, **종량제·꺼짐·불러오는 중에는 평소 모양**
- 단위 `useVisitTrend.test.ts`(4개): 최근 7일·앞 7일·오늘 방문, **앞 7일과 같으면 절반, 두 배 이상이면 가득, 줄면 그만큼 빈다**, **앞 7일이 0이면 이번에 방문이 있을 때 가득, 없으면 절반**, 한 줄 요약에는 색을 칠하지 않는다
- E2E `e2e/server-status.spec.ts`: 방문자는 방문 추이(+12% → 56%)와 메뉴의 방문 수·개요 탭, 줄면 빔, 묻지 못하면 평소 모양, `/resources`를 부르지 않음, 회수 위험이면 빈 빨간 배터리와 메뉴 내용, 메뉴에서 서버 탭이 열림, 안전하면 가득, 서버에서 끄면 메뉴를 열 때 알림, 휴대폰 배터리

## 남은 것, 배운 것

- 방문자의 배터리는 "앞 7일 대비"라서, 방문이 꾸준하면 늘 절반이다. 많이 오든 적게 오든 같은 모양이다. 절대 수를 보이려면 메뉴를 열어야 한다.
- 관리자 배터리는 5분마다 묻는다. 그 사이 회수 기준을 넘어도 길게는 5분 늦게 바뀐다. 회수는 7일 단위로 판단되니 이 정도 늦음은 문제가 되지 않는다.
- 이미 있는 그림에 뜻을 붙이는 쪽이 새 아이콘을 더하는 것보다 메뉴 막대를 덜 어지럽혔다. 다만 같은 그림이 보는 사람에 따라 다른 뜻이라, 메뉴의 첫 줄에 무엇을 보이는지 꼭 적었다(서버 자원 / 방문).
