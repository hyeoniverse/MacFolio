이날 가장 중요한 변화는 화면에 보이지 않는다. 그전까지는 시험(`check`)이 깨져도 사이트에 올라갈 수 있었다. Cloudflare가 시험과 상관없이 같은 코드를 따로 빌드해서 배포했기 때문이다. 이날부터는 **시험을 통과한 커밋만 배포**된다.

그 밖에 한 일은 시스템 설정, GitHub 앱, Finder 세 가지다. 커밋 30개를 새벽, 오후, 밤 세 번에 나눠 했다.

![10월 3일 작업 흐름](./images/day-1003-timeline.svg '새벽에는 시스템 설정, 오후에는 배포와 아이콘, 밤에는 Finder')

## 시험을 통과해야 배포

계기는 Cloudflare 빌드 서버가 빌드 환경을 띄우지 못하고 시간 초과로 실패하는 일이었다. 배포를 GitHub Actions로 옮기면서, 배포 작업이 시험 작업 뒤에만 돌게 했다([프론트엔드 배포를 GitHub Actions로](/memo/deploy-github-actions), [#82](https://github.com/hyeoniverse/MacFolio/pull/82)). 같은 날 액션 버전도 Node 24로 올렸다([#83](https://github.com/hyeoniverse/MacFolio/pull/83)).

이틀 뒤 API 자동 배포도 같은 방식으로 만들었다. 백엔드 설계도 이날 한 장으로 정리했다([MacFolio 백엔드 한 장으로 보기](/memo/backend-design), [#84](https://github.com/hyeoniverse/MacFolio/pull/84)).

## 시스템 설정과 GitHub 앱

새벽에는 시스템 설정을 다듬었다. 배경화면 이름 바꾸기·추가·지우기, 화면마다 자기 배경화면만 보이기([관리자가 배경화면을 더하기](/memo/custom-wallpapers)), 계정 화면의 로그인 시각과 세션 만료 시각([언제 로그인했고 언제 끝나는지](/memo/settings-signed-in-at)), 좁은 창에서 제목이 신호등 단추에 가리던 것([좁은 창에서 신호등 단추 아래로](/memo/narrow-window-title)).

그다음 GitHub 앱이 서버가 받아 온 프로필과 README를 보여 주게 하고, 보일 저장소는 시스템 설정에서 고르게 했다([GitHub 앱을 진짜 GitHub로](/memo/github-live-profile)). 9월 29일에 열어 둔 이슈 [#34](https://github.com/hyeoniverse/MacFolio/issues/34)가 이것이다.

![지금의 GitHub 앱](./images/day-1003-github.jpg 'GitHub 앱의 지금 모습. 시험용 가짜 프로필(Test Name)로 찍었다')

저장소를 고르는 화면은 21분 동안 세 번 바뀌었다.

| 시각 | GitHub 저장소 고르기                           |
| ---- | ---------------------------------------------- |
| 5:02 | ≡ 손잡이로 끌어서 순서 바꾸기                  |
| 5:15 | 편집 모드에서만 바꾸고, 완료할 때 한 번에 저장 |
| 5:23 | macOS 설정의 묶음 목록 모양으로                |

오후에는 작은 문제들을 고쳤다. 시간이 바뀔 때 너비가 바뀌던 메뉴 막대 시계([글](/memo/menubar-clock-width)), 크기가 제각각이던 고정 저장소 카드([글](/memo/github-pinned-card-size)), 그리고 20분 동안 커밋이 네 개였던 새싹 농장 아이콘([새싹 농장 아이콘 - 32픽셀 캐릭터로](/memo/sproutfarm-icon)).

## Finder와 프로젝트 앱

밤에는 Finder를 만들었다. 문서·프로젝트·블로그·앱을 폴더와 파일처럼 둘러본다([Finder 앱](/memo/finder-app), [#86](https://github.com/hyeoniverse/MacFolio/pull/86)). 이슈 [#20](https://github.com/hyeoniverse/MacFolio/issues/20)(이력서·문서)의 첫 작업이다.

![지금의 Finder](./images/day-1003-finder.jpg 'Finder의 지금 모습')

배포한 프로젝트 사이트를 창 안에 띄우는 프로젝트 앱([프로젝트를 앱으로](/memo/project-apps), [#87](https://github.com/hyeoniverse/MacFolio/pull/87))과 MacFolio를 프로젝트로 더하는 일([프로젝트 목록은 한 곳에](/memo/projects-one-list), [#88](https://github.com/hyeoniverse/MacFolio/pull/88))도 이 밤에 시작했다. GitHub 앱의 스냅샷만 프로젝트 목록을 따로 적어 두고 있어서, 스냅샷도 Safari·Finder·터미널과 같은 `PROJECTS`에서 만들게 했다. 두 PR은 이틀 뒤에 머지되었다.

![10월 3일 영역별 변경](./images/day-1003-areas.svg 'Finder와 시스템 설정, GitHub가 가장 많이 바뀌었다. 서버의 GitHub 연동도 새로 생겼다')

![열흘 동안의 커밋과 E2E](./images/day-1003-days.svg '하루 끝 E2E 198개')

하루가 끝날 때 브라우저 E2E는 198개, 단위 시험은 277개, API 단위 시험은 63개, API e2e는 65개였다.

## 돌아보며

**잘한 점**

- 시험을 통과한 커밋만 배포되게 했다. 시험이 깨진 커밋은 이제 사이트에 올라가지 않는다.
- 프로젝트 목록을 한 곳으로 모았다. `PROJECTS` 하나를 고치면 모든 화면이 바뀌고, 둘이 어긋나면 시험이 깨진다.

**아쉬운 점**

- 화면을 정하지 않고 만들었다. 저장소 고르기는 21분에 세 번, 아이콘은 20분에 네 번 바뀌었다. 처음에 참고 화면(macOS 설정의 묶음 목록)을 정했으면 한두 번에 끝났다.
- 그 바뀐 화면들이 모두 새벽 5시 전후의 커밋이다.
