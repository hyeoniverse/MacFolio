## 새벽: 시스템 설정

전날 밤 관리자가 배경화면을 더할 수 있게 한 것을 이어서 다듬었다. 이름 바꾸기, macOS처럼 사진 추가 칸과 왼쪽 위 지우기 단추, 화면마다 자기 배경화면만 보이기, 더한 것과 기본을 묶음으로 나누기. 계정 화면에는 로그인한 시각과 세션이 끝나는 시각을 넣었다.

4시 54분에는 GitHub 앱이 서버가 받아 온 프로필과 README를 보여 주게 하고, 보일 저장소는 시스템 설정에서 고르게 했다.

| ------------------------------------------ | ------------------------------ |
| 배경화면 이름·추가·지우기, 화면별 묶음     | 관리자가 배경화면을 더하기     |
| 로그인·세션 만료 시각                      | 언제 로그인했고 언제 끝나는지  |

## 오후: 배포를 Actions로

오후에는 작은 것부터 고쳤다. 메뉴 막대의 시계 칸 너비를 고정해 시간이 바뀌어도 아이콘이 움직이지 않게 하고, 고정 저장소 카드 크기를 맞췄다.

그리고 프론트엔드 배포를 GitHub Actions로 옮겼다. 계기는 Cloudflare 빌드 서버가 빌드 환경을 띄우지 못하고 시간 초과로 실패하는 일이었지만, 구조도 아쉬웠다. 시험(`check`)과 상관없이 Cloudflare가 같은 코드를 따로 빌드해 배포해서, 시험이 깨진 커밋도 사이트에 올라갈 수 있었다. 이제 **시험을 통과한 커밋만 배포**된다. 백엔드 설계 문서도 이때 한 장으로 정리했다.

| 한 일                            | 글                                                |
| -------------------------------- | ------------------------------------------------- |
| 시계 칸 너비 고정                | 시간이 바뀔 때 움찔하던 메뉴 막대                 |
| 고정 저장소 카드 크기            | 들쭉날쭉하던 고정 저장소 카드                     |
| 프론트엔드 배포를 Actions로      | 프론트엔드 배포를 GitHub Actions로                |
| 백엔드 설계 문서                 | MacFolio 백엔드 한 장으로 보기                    |
| 새싹 농장 아이콘을 픽셀 캐릭터로 | 새싹 농장 아이콘 - 32픽셀 캐릭터로 다시 그린 풀밭 |

새싹 농장 아이콘은 5시 36분부터 56분까지 20분 동안 커밋이 네 개였다. 캐릭터로 바꾸고, 풀밭을 그리고, 덤불을 빼고 캐릭터를 아래 끝에 맞추고, 세로 그라데이션을 넣었다.

## 밤: 사이트를 파일처럼

밤에는 Finder를 만들었다. 문서·프로젝트·블로그·앱을 폴더와 파일처럼 둘러본다. 배포한 프로젝트 사이트(NewPick, WTD, QRU)를 창 안에 띄우는 프로젝트 앱도 만들었다. 마지막으로 MacFolio를 프로젝트로 더했다. 그러다 보니 GitHub 앱의 스냅샷만 프로젝트 목록을 따로 적어 두고 있어서, 스냅샷도 Safari·Finder·터미널과 같은 목록(`PROJECTS`)에서 만들게 했다.

## 돌아보며

- **잘한 것: 배포 앞에 시험을 세웠다.** Actions로 옮긴 덕에 시험이 깨진 커밋은 배포되지 않는다. 이틀 뒤 API 자동 배포도 같은 길로 만들었다.
- **잘한 것: 프로젝트 목록을 한 곳으로 모았다.** GitHub 스냅샷만 따로 적은 목록을 갖고 있었다. 이제 `PROJECTS` 하나를 고치면 모든 화면이 바뀌고, 둘이 어긋나면 시험이 깨진다.
- **아쉬운 것: 화면을 정하지 않고 만들었다.** GitHub 저장소 고르기는 21분에 세 번, 새싹 농장 아이콘은 20분에 네 번 바뀌었다. 커밋마다 다음 모양을 보고 정했다. 처음에 참고 화면(macOS 설정의 묶음 목록)을 정했으면 한두 번에 끝났다.
- **아쉬운 것: 새벽 5시까지 했다.** 그 시간의 커밋이 위의 세 번 바뀐 화면이다.
