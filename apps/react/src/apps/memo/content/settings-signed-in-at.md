관리자 로그인은 12시간 동안 이어진다. 그런데 시스템 설정의 계정 화면에는 "GitHub로 로그인됨"만 있어서, 언제 로그인했는지(그래서 언제쯤 다시 로그인해야 하는지) 알 수 없었다.

![계정 화면 전후](./images/settings-signed-in-at.jpg '로그인 줄 아래에 로그인 시각')

## 서버

세션 테이블(`AdminSession`)에는 처음부터 만든 때(`createdAt`)가 있었다. 관리자를 확인할 때 이 값을 함께 꺼내고, `/auth/me`가 `signedInAt`(ISO 8601)으로 돌려준다.

```json
{ "login": "hyeoniverse", "signedInAt": "2026-10-02T10:03:00.000Z" }
```

세션을 만들 때 `createdAt`도 로그인을 처리한 시각으로 직접 넣는다. 만료 시각(`expiresAt`)과 같은 기준이라, 시험에서 시각을 정해 두고 확인하기도 쉽다.

## 화면

받은 시각은 보는 사람의 시간대로 "2026년 10월 2일 오후 7:03"처럼 보여 준다. 처음에는 `Intl.DateTimeFormat('ko-KR')`을 썼는데, Node에서 돌린 단위 시험에서 "오후" 대신 "PM"이 나왔다. 한국어 출력은 ICU 버전마다 달라서, 메시지 앱처럼 숫자만 받아 문구는 직접 조립한다.

서버를 아직 새로 배포하지 않아 `signedInAt`이 없거나 값이 잘못되었으면 이 줄을 그리지 않는다. 로그인 상태는 그대로 보인다.
