하루 동안 커밋 83개를 썼다. 열흘 중 가장 많다. 그런데 이날 main에 들어간 PR은 하나도 없다. 83개가 모두 PR 하나(#88)에 쌓였고, 그 PR은 다음 날 새벽 3시 3분에 머지되었다.

![10월 4일 작업 흐름](./images/day-1004-timeline.svg '자정부터 아침 9시까지 쉬지 않고, 오후 3시부터 다시 자정까지')

## 밤새: 프로젝트마다 다른 페이지

0시 3분부터 아침 8시 52분까지 쉬지 않고 Safari의 프로젝트 페이지를 짰다. 전에는 색만 다르고 짜임은 같았는데, 이날 프로젝트마다 짜임과 읽는 순서를 따로 만들었다.

| 프로젝트    | 이날 생긴 것                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------- |
| 새싹 농장   | 게임 에셋으로 만든 페이지, 흙길 지도 위를 걷는 주인공, 아침에서 밤으로 바뀌는 하늘, 엔딩 크레딧 |
| DevCourse   | 터미널 화면만 두고, 명령을 쳐야 내용이 나온다 (`ls`·`cd`·`tree`·`cat`)                          |
| 큐알유      | 실제 앱 분위기, 스크롤에 맞춰 펼치는 묻고 답하기, 데이터베이스 구조                             |
| 뉴픽        | 신문 지면처럼 머리 사진 기사·사진 기사·단신                                                     |
| MacFolio    | 커지는 노트북, 화면 크기 시뮬레이터, 벤토 그리드                                                |
| HYEONIVERSE | 마스코트 몽이, 라이트·다크 밀대, 레이아웃 바꿔 보기                                             |

![지금의 새싹 농장 페이지](./images/day-1004-sproutfarm.jpg 'Safari의 새싹 농장 페이지 지금 모습. 개발 일지가 흙길 지도다')

움직이는 것은 여러 번 고쳤다. 새싹 농장의 소는 3시 55분, 4시 10분, 4시 16분에 걸음과 발끝을 고쳤고, 개발 일지의 주인공은 4시 26분(일정한 걸음), 4시 39분(걷는 방향의 앞·뒤·옆 모습), 7시 6분(멀어지면 뛰어서 따라오기)에 고쳤다.

새벽 7시 41분에는 HYEONIVERSE·뉴픽·WTD·큐알유 페이지의 숫자를 저장소를 근거로 바로잡았다. 9월 29일에 NewPick 팀 구성을 잘못 적었던 일과 같은 종류다.

## 오후부터: 직접 해 보는 데모

오후 3시부터는 HYEONIVERSE 페이지였다. 디자인 시스템 장은 프리셋을 골라 보는 테마 장으로, CMS 장은 발표 갤러리·음성·파형 편집·문서 변환·번역·요약을 직접 해 보는 데모로 바꿨다.

데모가 진짜로 돌게 API도 붙였다.

| 데모        | 공급자 (실패하면 다음) | 제한                             |
| ----------- | ---------------------- | -------------------------------- |
| 음성 만들기 | Fish → Google → Edge   | 80자, IP마다 하루 3번, 전체 50번 |
| 번역·요약   | 실제 공급자            | IP마다 하루 3번, 전체 50번       |
| AI 커버     | 실제 공급자            | IP마다 하루 3번, 전체 10번       |

밤에는 몽이가 장마다 자리를 옮기며 따라다니고, 데모 곁에서 해 보라고 권하고, 결과에 반응하게 했다.

![지금의 HYEONIVERSE 페이지](./images/day-1004-hyeoniverse.jpg 'Safari의 HYEONIVERSE 페이지 지금 모습. 페이지 짜임은 다음 날 새벽까지 더 바뀌었다')

그리고 밤 11시 31분과 48분에 커밋이 두 개 들어갔다. **Safari에서 멈춘 스크롤 장면**과 **Safari에서 사라지던 몽이**. 하루 종일 Chrome에서 만들고, 자정 무렵에야 Safari에서 열어 봤다.

## 돌아보며

- **잘한 것: 프로젝트마다 읽는 방법을 다르게 했다.** 게임은 걸으면서, 터미널 과정은 명령을 치면서, 신문 서비스는 지면처럼 읽는다. 색만 바꾼 페이지보다 프로젝트를 더 잘 보여 준다.
- **잘한 것: 데모에 제한부터 걸었다.** 실제 AI 공급자를 부르는 데모라, 공급자마다 대체 순서와 IP·전체 횟수 제한을 같이 넣었다.
- **아쉬운 것: PR 하나에 83개.** 첫 커밋부터 머지까지 27시간이 걸렸고, 그동안 main과 멀어졌다. 프로젝트 페이지마다 PR을 나눴으면 리뷰도 되돌리기도 쉬웠다.
- **아쉬운 것: Safari를 맨 마지막에 열었다.** Safari에서만 생기는 문제 둘을 자정에 찾았다. 스크롤 장면처럼 브라우저마다 다르게 도는 것은 만들 때마다 Safari에서도 열어 봐야 했다.
- **아쉬운 것: 밤을 새웠다.** 0시부터 9시까지 쉬지 않았다. 걸음 애니메이션을 여러 번 다시 고친 것도 이 시간이다.
