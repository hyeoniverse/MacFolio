폴더는 글 하나가 한 곳에만 들어간다. 'CSS'와 '리팩터링'에 모두 걸치는 글은 폴더로는 묶을 수 없다. macOS 메모는 이럴 때 태그를 쓴다. 본문 아무 데나 `#태그`를 쓰면 그것이 태그가 되고, 사이드바 아래에 태그 묶음이 생긴다.

![태그로 보기](./images/memo-tags.jpg '사이드바 아래의 태그 묶음. 누르면 그 태그의 글만, 본문의 태그도 누를 수 있다')

## 저장하지 않는다

태그 칸을 따로 두지 않았다. 본문이 곧 태그의 출처다. 그래서 DB도, API도, 저장소의 Markdown 형식도 그대로다. 글을 고쳐서 `#태그`를 지우면 태그도 사라진다. 따로 맞춰 둘 것이 없다.

```ts
/** #태그: 줄 처음이나 공백·여는 괄호 뒤의 #, 바로 뒤에 이름 (# 뒤에 공백이 있으면 제목이다) */
export const TAG_PATTERN = /(^|[\s(（[])#([\p{L}\p{N}_-]+)/gu;
```

`\p{L}`(모든 글자)이라 한글 태그도 된다. `#` 바로 뒤에 공백이 있으면 Markdown 제목(`# 제목`)이므로 태그가 아니다.

## 태그가 아닌 `#`

규칙의 대부분은 "태그가 아닌 #"을 거르는 일이었다. 이 블로그에는 CSS 글이 많아서 `#edbb4d` 같은 색이 자주 나온다. 커밋 이야기에는 `#14` 같은 이슈 번호도 나온다.

| 쓴 것                                | 태그?  | 이유                                 |
| ------------------------------------ | ------ | ------------------------------------ |
| `#리팩터링`, `(#CSS)`                | 예     |                                      |
| `# 제목`                             | 아니오 | `#` 뒤에 공백 (제목)                 |
| 코드 블록·`인라인 코드` 안의 `#코드` | 아니오 | 코드                                 |
| `[글](#section)`, `https://a.b/#x`   | 아니오 | 링크 주소                            |
| `#14`                                | 아니오 | 숫자만 (이슈 번호)                   |
| `#fff`, `#2b2100`, `#edbb4d`         | 아니오 | 색 (16진수 3·6·8자리)                |
| `C#언어`                             | 아니오 | 단어 가운데 (`#` 앞이 공백이 아니다) |

색을 거르는 규칙 때문에 `#cafe`나 `#face`처럼 16진수 글자로만 된 영어 태그는 쓸 수 없다. 블로그에 색이 나오는 일이 훨씬 많아서 그쪽을 골랐다.

이 규칙을 만든 뒤 지금까지 쓴 글 27편에 돌려 봤다. 태그로 읽힌 것은 하나도 없었다. 본문의 `#`은 모두 코드 블록 안의 색이었다.

## 세 곳에서 같은 규칙

태그는 세 곳에 보인다. 모두 같은 함수(`tagsInText`)로 찾는다.

- **사이드바의 태그 묶음**: 모든 글의 본문에서 태그를 모아, 글이 많은 태그부터 늘어놓는다. 누르면 그 태그의 글만 보고, 한 번 더 누르면 모든 글로 돌아간다
- **읽기 화면**: remark 플러그인이 Markdown 문법 나무의 글자 마디를 쪼개 `<span class="memo-tag">`로 감싼다. 코드·링크 마디는 들어가지 않는다. 누르면 그 태그의 글만 본다
- **편집기**: ProseMirror 꾸밈(decoration)으로 칠하기만 한다. 편집기에서 태그를 누르면 그 자리에 커서가 가야 하므로 다른 화면으로 넘어가지 않는다

태그로 보는 화면은 폴더로 보는 화면을 그대로 쓴다. 경로 자리에 `'\u0000tag:' + 이름`을 넣는다. 폴더 이름에 쓸 수 없는 글자로 시작해서 사용자가 만든 폴더와 겹치지 않는다. 제목 자리에는 `#이름`이 보인다.
