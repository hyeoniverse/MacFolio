새 팝업을 띄울 때마다 "이건 z-index를 얼마로 줘야 Dock 위에 뜨지?"를 물어야 했다. 답을 찾으려면 Dock.css, StatusBar.css, Menu.css, LoadingScreen.css를 차례로 열어 숫자를 비교하는 수밖에 없었다.

## z-index가 무엇인가

화면에서 요소가 겹칠 때 무엇을 위에 그릴지 정하는 CSS 속성이다. 값이 클수록 위에 그린다. 같은 부모 안의 작은 겹침(목록 위 버튼 등)은 1~10이면 충분하지만, Dock·메뉴 막대·펼친 메뉴처럼 화면 전체에서 서로 겹치는 요소는 서로의 값을 알아야 순서를 정할 수 있다.

## 흩어져 있던 숫자

앱 안의 작은 값을 빼고, 화면 전체에서 겹치는 값만 세어 보니 열세 개 파일에 스무 곳이었다.

| 값                        | 쓰는 곳                                                                   |
| ------------------------- | ------------------------------------------------------------------------- |
| 1000                      | Dock, 경고창(Modal) 기본값                                                |
| 1001                      | 메뉴 막대                                                                 |
| 1400 · 2000 · 2100 · 2200 | 휴대폰 앱 전환기 · 제어 센터 · 상태 막대 · 알림                           |
| 1500                      | 이 Mac에 관하여                                                           |
| 2000 · 3000               | Launchpad · 키보드 단축키 안내                                            |
| 9000 · 9999               | 알림 · 로딩 화면                                                          |
| 10000                     | 펼친 메뉴, 소리 조절, 메모의 서식 판·달력·라이트박스·끌어 놓기 표시 (6곳) |
| 15000 · 20000             | 앱 오류 화면 · 로그인                                                     |

메뉴 막대가 1001인 이유는 "Dock(1000)보다 위"라는 뜻이지만, 숫자만 보고는 그 의도를 알 수 없다. 10000은 여섯 곳에 같은 숫자로 적혀 있어서, 하나만 바꾸면 메뉴끼리 순서가 어긋난다.

## 이름 붙이기

`styles/theme.css`의 `:root`에 `--z-*` 변수로 모았다. 값은 하나도 바꾸지 않았다. 숫자가 그대로라 화면에서 겹치는 순서도 그대로다.

```css
:root {
	--z-dock: 1000;
	--z-menubar: 1001;
	--z-menu: 10000; /* 펼친 메뉴·팝오버·라이트박스: 어떤 창보다 위 */
	--z-login: 20000; /* 로그인: 가장 위 */
}

.dock {
	z-index: var(--z-dock);
}
```

공통 경고창(`Modal`)은 쓰는 쪽이 `--ui-modal-z`로 층을 정한다. Launchpad·키보드 단축키 안내·로그인이 이 값을 숫자로 적던 것도 `--ui-modal-z: var(--z-launchpad)`처럼 이름으로 바꿨다. 기본값도 `var(--ui-modal-z, var(--z-dialog))`이다.

## 남겨 둔 것

- **창 순서**: 창은 store가 1, 2, 3…으로 매기는 값이라 CSS 변수로 옮길 대상이 아니다.
- **앱 안의 작은 값(1~10)**: 같은 부모 안의 겹침이라 다른 화면과 비교할 일이 없다.
- **소리 조절 막대(100)**: 소리 조절 상자 안에서만 쓰는 값이다.

다음에 새 팝업을 만들 때는 `theme.css`의 표에서 위아래를 고르고, 그 사이에 이름 하나를 더하면 된다.
