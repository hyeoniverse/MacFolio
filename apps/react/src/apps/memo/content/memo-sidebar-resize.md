macOS 메모 앱은 사이드바와 목록 사이 경계를 끌어 사이드바 너비를 바꿀 수 있다. MacFolio의 메모 앱은 사이드바를 `13rem`(208px)으로 고정해 두어서, 3단계 폴더(`개발기 › MacFolio › 프론트엔드`)나 태그가 많을 때 줄이 잘리거나 여러 줄로 넘쳤다.

## 무엇이 바뀌었나

- 사이드바 오른쪽 경계에 마우스를 올리면 세로선이 보이고, 끌면 사이드바가 넓어지거나 좁아진다.
- 너비는 180px에서 360px 사이로 제한한다. 좁히면 폴더 이름이 읽히지 않고, 넓히면 목록과 본문이 너무 좁아진다.
- 손잡이를 두 번 누르면 기본 너비(208px)로 돌아간다.
- 키보드로도 조절한다. 손잡이에 포커스를 두고 ←·→로 8px씩, Shift를 함께 누르면 32px씩, Home·End로 가장 좁게·넓게 바꾼다.
- 조절한 너비는 브라우저에 남아, 메모 앱을 다시 열어도 유지된다.
- 사이드바를 가렸을 때와 한 칸씩 보는 화면(휴대폰, 700px 이하의 좁은 창)에서는 손잡이가 없다.

## 구조

![손잡이는 그리드 칸이 아니라 경계 위에 떠 있다](./images/memo-sidebar-resize-layout.svg '사이드바 너비는 CSS 변수 하나, 손잡이는 그 위치에 절대 위치로 놓는다')

메모 화면은 CSS 그리드 세 칸(사이드바 · 목록 · 본문)이다. 첫 칸의 너비를 고정값 대신 CSS 변수 `--memo-sidebar-width`로 바꾸고, React 상태의 너비를 `style`로 넣는다. 갤러리 보기(두 칸)도 같은 변수를 쓴다.

손잡이는 그리드의 자식이지만 `position: absolute`로 둔다. 절대 위치인 자식은 그리드 칸을 차지하지 않으므로, 기존 세 칸의 배치(사이드바·목록·본문 순서)를 건드리지 않고 경계 위에 띄울 수 있다. 위치도 같은 변수로 정한다(`left: calc(var(--memo-sidebar-width) - 4px)`). 너비 12px의 띠가 사이드바 패널과 목록 사이의 틈(8px)에 걸쳐 있어, 정확히 선 위를 겨누지 않아도 잡힌다.

## 끄는 동안의 처리

- **포인터 캡처**: 누를 때 `setPointerCapture`를 걸어, 빠르게 끌어 포인터가 손잡이 밖으로 나가도 계속 이벤트를 받는다. 마우스·터치펜·터치를 같은 코드로 다룬다.
- **애니메이션 끄기**: 사이드바를 여닫을 때 칸 너비가 부드럽게 바뀌도록 `transition: grid-template-columns`가 걸려 있다. 끄는 동안에도 이것이 걸리면 칸이 손보다 늦게 따라온다. 끄는 동안은 그리드에 `data-resizing`을 달아 transition을 끄고, 커서를 `col-resize`로 고정하고 글자 선택을 막는다.
- **저장 시점**: 끄는 동안에는 화면만 바꾸고, 손을 뗄 때 한 번 저장한다. 끌기가 취소되면(`pointercancel`) 처음 너비로 돌린다.

## 저장

너비는 `localStorage`의 `macfolio:memo:sidebar-width`에 숫자로 남긴다. 읽을 때 숫자가 아니면 기본값으로, 범위 밖이면 범위 안으로 맞춘다. 기본 너비로 돌아오면 값을 지워, 휴지통의 '내 브라우저 데이터'에 쓸데없이 남지 않게 했다. 이 키는 '메모 보기 설정' 항목에 함께 묶어, 거기서 지우면 정렬 기준과 함께 처음 상태로 돌아간다.

## 접근성

손잡이는 `role="separator"`와 `aria-orientation="vertical"`, 현재·최소·최대 너비(`aria-valuenow`·`aria-valuemin`·`aria-valuemax`)를 가진다. 포커스할 수 있는 separator는 화면 읽기 프로그램에서 "조절 가능한 분할선"으로 읽히고, 값이 바뀌면 새 너비를 알린다. 마우스를 쓰지 않아도 키보드만으로 같은 조절을 할 수 있다.
