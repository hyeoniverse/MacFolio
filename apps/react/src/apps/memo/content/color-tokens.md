z-index, 모서리 둥글기, 글자 크기, 그림자와 간격에 이어 마지막으로 색에 이름을 붙였다. 디자인 토큰 정리는 이것으로 마친다.

## 세어 보기

`src` 아래 CSS에서 주석을 빼고 hex 색(`#rgb`, `#rrggbb`, `#rrggbbaa`)을 세면 1,171곳이었다.

| 자리                                     | 곳  |
| ---------------------------------------- | --- |
| `styles/theme.css` (이미 변수의 값)      | 32  |
| Safari 프로젝트 소개 페이지 (`project/`) | 626 |
| 그 밖의 앱·데스크톱·공통 UI              | 513 |

![hex 수](./images/color-tokens-counts.svg '전체 1,171곳에서 대상 513곳, 그중 288곳을 바꿨다')

프로젝트 소개 페이지는 프로젝트마다 브랜드 색을 일부러 따로 쓴다. 공통 이름으로 묶으면 오히려 각 페이지의 색이 어디서 왔는지 흐려지므로 이번에는 손대지 않았다. 남은 513곳이 대상이다. `rgb()`·`rgba()`는 425곳인데, 대부분 그림자와 반투명 바탕이라 이번 범위에서 뺐다.

다크 모드는 `<html data-theme="dark">`로 켜고, CSS에서는 `:root[data-theme='dark'] …` 선택자로 값을 바꾼다. 그래서 hex 하나하나를 "라이트에서 쓰는지, 다크 선택자 안에서 쓰는지"로 나눠 셌다.

## 기준

바꿔도 계산된 색이 같아야 한다. 이 조건 때문에 이름을 두 종류로 나눴다.

1. **테마와 상관없는 값.** 라이트와 다크에서 똑같이 쓰는 색이다. 이름도 한 값만 갖고, 어느 자리에서 바꿔도 결과가 같다.
2. **라이트·다크 짝.** 앱마다 `[data-app='mail'] { --mail-text: #1d1d1f }`와 `:root[data-theme='dark'] [data-app='mail'] { --mail-text: #f5f5f7 }`처럼 같은 짝을 따로 적던 값이다. 이런 이름은 다크에서 값이 바뀌므로, **같은 선택자의 라이트 선언과 다크 선언이 정확히 그 짝일 때만** 두 곳을 함께 바꿨다. 라이트 값만 같고 다크 값이 다르면 바꾸지 않는다.

이미 있는 변수도 같은 기준으로 썼다. 예를 들어 `--color-text-secondary`는 라이트 `#6e6e73`, 다크 `#98989d`인데, 메일과 Safari의 흐린 글자가 바로 이 짝이라 그대로 가리키게 했다. 반면 터미널의 흐린 글자는 다크 값이 `#9a9aa0`이라 그대로 두었다.

## 테마와 상관없는 색

| 이름                      | 값        | 바꾼 곳 |
| ------------------------- | --------- | ------- |
| `--color-white`           | `#ffffff` | 95      |
| `--color-notes-yellow`    | `#edbb4d` | 32      |
| `--color-blue`            | `#0a84ff` | 13      |
| `--color-red`             | `#ff3b30` | 12      |
| `--color-danger`          | `#e5484d` | 11      |
| `--color-on-notes-yellow` | `#2b2100` | 8       |
| `--color-black`           | `#000000` | 7       |
| `--color-gray`            | `#8e8e93` | 7       |
| `--color-green`           | `#34c759` | 5       |
| `--color-gray-6`          | `#f2f2f7` | 4       |
| `--color-orange`          | `#ff9f0a` | 3       |

이름은 Apple 시스템 색(systemBlue, systemGray6 등)을 따랐다. `--color-blue`는 iOS 다크 모양의 systemBlue 값인데, 휴대폰 화면이 라이트에서도 이 값을 쓰고 있어서 값을 그대로 옮겼다. `--color-danger`는 Menu·Button·휴대폰 셸이 `var(--color-danger, #e5484d)`처럼 먼저 찾던 이름이다. 정의가 없어 늘 뒤의 값으로 떨어지던 것을 이번에 정의했다. 메모 앱의 노란색은 날짜 고르기도 같이 써서 앱 변수가 아니라 전역 이름으로 두었다.

## 라이트·다크 짝

| 이름                           | 라이트           | 다크               | 바꾼 곳 |
| ------------------------------ | ---------------- | ------------------ | ------- |
| `--color-label`                | `#1d1d1f`        | `#f5f5f7`          | 14      |
| `--color-code-number`          | `#0550ae`        | `#79c0ff`          | 12      |
| `--color-content-bg`           | `#ffffff`        | `#1c1c1e`          | 8       |
| `--color-card-bg`              | `#ffffff`        | `#2c2c2e`          | 7       |
| `--color-panel-bg`             | `#f6f6f6`        | `#2a2a2c`          | 4       |
| `--color-error`                | `#d70015`        | `#ff6961`          | 4       |
| `--color-link`                 | `#0071e3`        | `#2997ff`          | 4       |
| `--color-selected-content-bg`  | `#0063e1`        | `#0a84ff`          | 4       |
| `--color-code-keyword` 외 여섯 | GitHub 밝은 테마 | GitHub 어두운 테마 | 각 4    |

코드 강조 색은 메모와 Finder 미리보기가 같은 GitHub 팔레트를 각자 적고 있었다. 터미널의 경로·링크 색도 같은 숫자 색이다.

이미 있던 변수로 바꾼 곳은 10곳이다. 메모와 음악의 창 바탕(`--color-window-bg`) 4곳, 메일과 Safari의 흐린 글자(`--color-text-secondary`) 4곳, 음악의 사이드바(`--color-sidebar-bg`) 2곳이다.

모두 288곳을 바꿨다. 513곳의 56%다.

## 이름을 붙이지 않은 값

남은 225곳은 이렇다.

- **한 앱만 쓰는 변수 값 (103곳)**: 설정의 프로젝트 편집기, 날씨, 메시지 말풍선처럼 그 앱에만 있는 색이다. 이미 앱 변수로 이름이 있다.
- **되풀이되지만 짝이 맞지 않는 값 (39곳)**: `#3a3a3c`, `#6e6e73`처럼 여러 번 나오지만 다크 값이 자리마다 다르거나 다크 선택자에만 있는 값이다. 이름을 붙이면 어느 한쪽이 바뀐다.
- **한 곳에만 나오는 값 (36곳)**
- **GitHub 앱의 팔레트 (26곳)**: GitHub 화면을 흉내 내는 색이라 GitHub 값 그대로 둔다.
- **Safari 껍데기와 프로젝트 소개 공통 (19곳)**: apple.com 소개 페이지의 색이다.
- **SVG data URL 안의 색 (2곳)**: `url()` 안에는 `var()`를 쓸 수 없다.

TS·TSX 안의 hex 403곳도 그대로 두었다. 프로젝트 소개 데이터의 브랜드 색, 설정의 색 고르기 목록, 시험 코드, 캔버스에 그리는 값이라 CSS 이름으로 바꿀 대상이 아니다.

## 확인

바꾸기 전과 뒤의 빌드를 띄워, 데스크톱과 iPhone 크기, 라이트와 다크에서 Dock 앱, Launchpad 앱, 메모 글, Safari 프로젝트 페이지, 휴대폰 홈 화면의 앱 116개 화면을 열었다. 모든 요소와 가상 요소에서 색에 관한 계산된 스타일 41만여 개를 비교했다. 시계 글자 폭, 재생 막대, 배경 밝기에 따라 바뀌는 상태 막대와 홈 인디케이터처럼 같은 빌드를 두 번 띄워도 달라지는 값을 빼면 차이는 없었다.
