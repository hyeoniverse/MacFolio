PR [#116](https://github.com/hyeoniverse/MacFolio/pull/116)을 머지하자 CI는 통과했다. 그런데 서버는 여전히 옛 버전이었다. API 배포가 건너뛰어졌기 때문이다. 이 문제는 한 시간 전, 관련 코드를 바꾸지 않은 시험 하나가 main에서만 실패하면서 시작됐다.

이날 PR 14개가 머지되었다. 새벽에는 문제를 고쳤고, 오후부터는 새 기능을 만들었다.

![10월 7일 작업 흐름](./images/day-1007-timeline.svg '새벽에는 메뉴·서버 고치기, 오후에는 감시, 저녁에는 트래픽 분석과 메일')

이 과정은 세 편의 글에 나눠 적었다. [서버는 켜져 있는데 "서버에 연결할 수 없음"](/memo/server-status-blocked-origin), [메뉴 막대의 파일·보기·윈도우가 실제로 열린다](/memo/menubar-menus), [자동 배포를 실제 서버에 걸기](/memo/api-auto-deploy-setup).

같은 시간에 로컬 API의 환경 변수도 정리했다. 개발용은 `.env`, 배포 값은 `.env.production`. 로컬 프론트엔드 주소를 허용하지 않으면 서버가 뜰 때 경고한다([#117](https://github.com/hyeoniverse/MacFolio/pull/117)).

## 서버 감시

9월 30일에 서버를 띄웠는데, 내려가도 사이트에 들어와 보기 전에는 알 방법이 없었다. 이제 GitHub Actions가 10분마다 바깥에서 `/health`와 사이트를 불러 본다. 지워지지 않고 쌓이기만 하던 컨테이너 로그는 컨테이너마다 30MB까지만 남긴다([서버가 죽으면 알려 주기, 로그가 디스크를 채우지 않게](/memo/server-uptime-and-logs), [#119](https://github.com/hyeoniverse/MacFolio/pull/119)).

## 트래픽 분석은 PR 네 개로

트래픽 분석은 큰 기능이라 처음부터 네 단계로 나눴다. 단계마다 PR 하나, 글 하나. 10월 4일에 PR 하나에 커밋 83개를 넣었던 것과 반대로 했다.

1. **API** — 쿠키 없이 하루 해시로 순방문자를 센다. 원래 IP는 저장하지 않고, 90일 뒤엔 날마다 모은 숫자만 남긴다. [#120](https://github.com/hyeoniverse/MacFolio/pull/120) · [트래픽 분석 1](/memo/analytics-api)
2. **모으기** — 앱 열기·글 보기·바깥 링크·머문 시간을 5초마다 sendBeacon으로. [#121](https://github.com/hyeoniverse/MacFolio/pull/121) · [트래픽 분석 2](/memo/analytics-collect)
3. **관리자 화면** — '활동 상태 보기' 앱, 표와 SVG 그래프. [#122](https://github.com/hyeoniverse/MacFolio/pull/122) · [트래픽 분석 3](/memo/analytics-activity-monitor)
4. **공개** — 누구나 열되 공개 숫자만, 상세·실시간은 관리자. 글 조회수도. [#123](https://github.com/hyeoniverse/MacFolio/pull/123) · [트래픽 분석 4](/memo/analytics-public)

## 메일 앱에서 실제로 메일 보내기

마지막으로 메일 앱에서 실제로 메일을 보낼 수 있게 했다. 전에는 방문자의 메일 앱을 여는 `mailto:` 링크였다. 이제 서버가 Resend로 보내고, 보낸 사람 주소는 Reply-To로 넣어 바로 답장할 수 있다. 스팸은 Cloudflare Turnstile과 하루 상한으로 막고, 서버에 설정이 없으면 예전처럼 메일 앱을 연다([메일 앱에서 진짜로 메일 보내기](/memo/contact-mail), [#125](https://github.com/hyeoniverse/MacFolio/pull/125)).

작은 버그도 두 개 고쳤다. `#115의`처럼 조사가 붙은 이슈 번호를 메모 태그로 읽던 것([#124](https://github.com/hyeoniverse/MacFolio/pull/124)), 메뉴 막대의 Finder 이름이 1.5px 위에 있던 것([#126](https://github.com/hyeoniverse/MacFolio/pull/126)).

## 열흘째에 돌아보며

이날은 열흘의 마지막 날이라 열흘 전체를 함께 돌아본다.

실패한 시험의 원인을 찾다가 배포가 빠지는 문제까지 찾은 것이 이날 가장 잘한 일이다. 수동으로 다시 배포하고 끝낼 수도 있었다. 대신 배포 여부를 서버의 실제 버전으로 정하게 바꿔서, 실패한 실행이 몇 개 있어도, 다음에 성공한 실행이 서버를 최신 버전으로 맞춘다. main에서만 나던 시험은 "마우스가 움직이지 않은 채 제목만 밀려 오는" 경우를 시험으로 직접 만들어, 고치기 전 빌드에서 실패하는 것까지 확인했다. 타이밍에 따라 결과가 달라지는 시험은 다시 돌려서 통과시키지 말고, 그 타이밍을 재현하는 시험을 만들어야 한다.

트래픽 분석을 PR 네 개로 나눈 것은 10월 4일의 반성을 반영한 것이다. 단계마다 리뷰하고 머지해서, 한 단계에 문제가 생겨도 앞 단계에는 영향이 없었다.

가장 늦게 한 일은 서버 감시다. 서버를 띄우고 일주일이 지나서야 서버가 멈춘 것을 알 방법이 생겼다. 그 사이 서버가 멈췄다면 방문자가 먼저 알았을 것이다.
