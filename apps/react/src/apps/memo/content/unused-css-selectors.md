이슈에 "쓰지 않는 선택자 지우기 (Stylelint 도입 검토)"를 적어 두었다. 먼저 Stylelint로 할 수 있는 일인지 보았다.

## Stylelint로는 안 된다

Stylelint는 CSS 파일만 읽는다. 어떤 클래스를 HTML이나 컴포넌트가 쓰는지는 모르므로 "쓰지 않는 선택자" 규칙이 없다. 그 일을 하는 도구(PurgeCSS 등)는 소스에서 클래스 이름을 글자로 찾는데, 이 사이트는 클래스 이름을 조립하는 곳이 많아 그대로 쓰면 쓰는 규칙까지 지운다. 그래서 한 번 직접 세어 보았다.

## 1단계: 글자로 찾기

CSS의 모든 선택자에서 클래스 이름 2,761개를 뽑고, `.ts`·`.tsx`·`.md` 어디에도 그 글자가 없는 것을 골랐다. 150개가 나왔다.

## 2단계: 조립하는 이름 걸러 내기

150개 대부분은 코드가 이름을 조립해 붙이는 클래스였다.

| 종류                   | 예                                                          | 코드                               |
| ---------------------- | ----------------------------------------------------------- | ---------------------------------- |
| 앞부분 + 값            | `sky-rain`, `rank-1`, `view-gallery`                        | `` `weather sky-${weather.sky}` `` |
| 템플릿 접두사 + 뒷부분 | `mg-trouble`, `pp-member`                                   | `cx(prefix, 'trouble')`            |
| 라이브러리가 붙임      | `hljs-keyword`, `ProseMirror-selectednode`, `resize-cursor` | highlight.js, ProseMirror          |

`이름-${` 꼴과 `cx(prefix, '이름')` 꼴을 코드에서 모아 이것으로 만들 수 있는 클래스를 빼고, 라이브러리 클래스를 빼자 9개가 남았다. 9개는 하나씩 코드를 읽어 정말 쓰지 않는지 확인했다.

| 클래스                                    | 무엇이었나                                             |
| ----------------------------------------- | ------------------------------------------------------ |
| `sp-hero-main`, `sp-tiles`, `sp-timeline` | 프로젝트 페이지를 템플릿으로 바꾸기 전의 공통 레이아웃 |
| `minimized-container`, `dock-launchpad`   | 창 최소화 미리보기와 옛 Launchpad 단추                 |
| `cd-lock`, `cd-voice-script`              | 데모의 옛 잠금 표시와 음성 대본                        |
| `tm-jump`                                 | DevCourse 터미널의 옛 바로 가기                        |
| `memo-toolbar-title`                      | 메모 도구 막대의 옛 제목                               |

## 지우기

CSS 파서(postcss)로 이 클래스만 쓰는 규칙 24개를 지우고, 다른 선택자와 함께 묶인 곳(`.minimized-container i, .dock-item i`)은 그 선택자만 뺐다. `minimized-container`만 쓰던 배경 그림(`imgs/minimize.JPG`, 58KB)도 지웠다.

이제 쓰지 않는 규칙은 이름을 조립하는 곳 때문에 자동으로 찾기 어렵다. 새 클래스를 지울 때 이 순서(글자로 찾기 → 조립하는 이름 걸러 내기 → 하나씩 읽기)를 다시 쓰면 된다.
