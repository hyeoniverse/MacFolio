리팩터링 계획([#150](https://github.com/hyeoniverse/MacFolio/issues/150))의 5단계는 CSS였다. 값은 하나도 바꾸지 않고 이름을 붙이고, 나누고, 지웠다.

## 왜

CSS가 26,464줄이었다. 직접 쓴 hex 색 650곳, CSS 변수 309종, `border-radius`는 6·8·10·14·999px 등이 섞여 있었고, `z-index` 값은 23가지였다. `Memo.css` 하나가 4,166줄이었다.

모든 PR의 확인 방법은 "같은지 보기"였다. 토큰은 값을 그대로 둔 채 이름만 붙였고, `Memo.css`는 빌드한 CSS가 바이트까지 같은지, 중복 제거는 요소마다 계산된 스타일이 라이트·다크 × 데스크톱·휴대폰에서 같은지 비교했다.

## 전후

|                       | 전                       | 후                                                     |
| --------------------- | ------------------------ | ------------------------------------------------------ |
| `z-index`             | 13개 파일에 숫자         | 20곳이 `--z-*` 15개                                    |
| 모서리                | 576곳, 마흔 가지 넘는 값 | 239곳이 `--radius-xs`~`--radius-full`                  |
| 글자 크기             | 958곳                    | 645곳이 `--text-caption2`~`--text-title2` 여덟 이름    |
| 간격·그림자           | 직접 쓴 값               | 간격 1,543곳이 `--space-*`, 그림자 19곳이 `--shadow-*` |
| 앱 CSS의 hex 색       | 513곳                    | 288곳을 `--color-*`로, 225곳 남음                      |
| `Memo.css`            | 4,600줄 한 파일          | `memo/styles/` 열다섯 파일                             |
| `HyeoniversePage.css` | 1,444줄                  | 735줄                                                  |
| 쓰지 않는 클래스      | 9개                      | 0개 (규칙 24개와 그림 한 장 삭제)                      |

## 일부러 남긴 것

- 프로젝트 소개 페이지의 브랜드 색은 일부러 따로 쓰는 값이라 토큰으로 묶지 않았다. `rgb()`·`rgba()` 425곳도 범위에서 뺐다.
- 같은 뜻의 `z-index` 값을 합치면 그리는 순서가 바뀔 수 있어 보류했다.
- 메모의 `late.css`는 옮기면 적용 차례가 바뀌어 그대로 두었다.
- Stylelint는 CSS만 읽어 클래스를 쓰는지 알 수 없어 들이지 않았다.
