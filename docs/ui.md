# 공통 UI 부품 (`apps/react/src/shared/ui`)

앱 여럿이 같은 모양·동작으로 쓰는 부품이 여기 있다. 리팩터링 계획([#150](https://github.com/hyeoniverse/MacFolio/issues/150)) 4단계의 첫 항목으로, 지금 있는 것의 props와 쓰는 곳을 적고, 새로 뽑을 후보를 지금 코드의 수로 다시 쟀다. 수는 2026-10-11 `main` 기준이다.

## 원칙

- **쓰는 곳이 셋 이상이고 모양과 동작이 같을 때** 뽑는다. 한두 곳이거나 서로 다르면 그 차이를 받는 옵션이 생겨 오히려 무거워진다 ([글자 버튼 글](https://macfolio.hyeoniverse.com/memo/shared-text-button)의 '만들지 않은 것')
- **모양은 변수로, 뜻은 role로.** 부품의 CSS는 `components` 층에 있어 앱의 CSS가 늘 이긴다. 색·모서리·여백은 앱이 `--ui-*` 변수로 정한다. 모양이 같아도 스크린 리더에게 뜻이 다르면(눌린 버튼 둘 vs 탭 목록) 한 부품으로 합치지 않는다
- **body에 그리는 창에는 앱 변수가 닿지 않는다.** `Menu`·팝오버처럼 `createPortal`로 body에 그리는 것은 바깥 요소에 `--ui-*`를 다시 정한다
- 부품의 파일은 `shared/ui/<종류>/<이름>.tsx`와 같은 이름의 `.css`. 순수 계산(자리 잡기, 단축키 글자)은 `.ts`로 두고 시험을 옆에 붙인다

옮길 수 있는 약 93곳은 4단계 마지막 항목("앱마다 따로 만든 버튼·시트·목록을 공통 컴포넌트로")에서 PR 둘로 옮긴다. `IconButton` 45곳을 먼저 옮겼고, 다음으로 `Button` 30곳을 옮겼다. 처음에 셌던 설정의 취소·완료·편집 7곳에 프로젝트 항목의 같은 버튼 3곳이 더해졌고, 옮기지 못한 버튼은 없다. 날씨의 사이드바 여닫기는 이미 있는 `SidebarToggle`로 옮겼다(아이콘이 Font Awesome `table-columns`에서 메모·사진과 같은 사이드바 SVG로 바뀌었다). 떠 있지 않은 동그란 버튼 15곳은 `IconButton`에 더한 `variant="circle"`로 받는다. `circle`은 모양(동그라미, 안쪽 여백 0)만 정하고 크기·바탕·색은 앱의 CSS가 정한다. 옮긴 버튼은 앱의 `className`을 그대로 두고, 공통 CSS가 더하는 값 가운데 앱이 덮지 않던 것(최소 폭·높이·안쪽 여백·둥근 모서리·색)은 앱의 규칙에 적어 되돌렸다. E2E를 돌리면서 옮긴 버튼마다 공통 클래스(`ui-icon-button`·`tool`·`circle`·`float`)를 뗀 계산된 스타일과 붙인 계산된 스타일을 비교해, 크기·색·여백이 같은 것을 확인했다. `Button`으로 옮긴 30곳도 같은 방법을 썼다. 앱의 `className`을 그대로 두고, 공통 CSS가 더하는 값 가운데 앱이 덮지 않던 것(`inline-flex`·가운데 정렬·`gap`, 나타날 때의 `fade-in`, 둥근 모서리, 바탕, 글꼴, 비활성의 흐림)은 앱마다 점수가 0인 규칙 하나(`:where(앱의 클래스):where(.ui-button)`)로 되돌렸다. 공통 클래스(`ui-button`)를 뗀 계산된 스타일과 붙인 계산된 스타일은 데스크톱과 휴대폰 두 프로젝트에서, 기본·올림·비활성 상태 모두 같았다.

## 데스크톱·휴대폰 짝

같은 부품이 두 모양을 가져야 하는 곳은 `variant`로 고른다. 지금은 `IconButton`의 `tool`·`float`·`circle`과 `Menu`의 `className`(휴대폰에서 iOS처럼 크게)이 그 예다. 새로 뽑는 `Sheet`는 휴대폰 전용(데스크톱은 `Modal`), `SearchField`는 둘이 같은 모양이라 `variant`가 없다.

## 시험과 접근성 이름

- 순수 계산(`placement.ts`, `shortcut.ts`, `direction.ts`)은 옆에 `*.test.ts`가 있다
- 부품의 이름·역할은 `shared/ui/a11y.test.ts`가 부품을 HTML로 그려(`renderToStaticMarkup`) 확인한다. 누르기·Esc·초점 이동 같은 동작은 브라우저 E2E(`apps/react/e2e/`)가 맡는다. `Menu`는 body에 그려서(portal) 이 시험에서 빠지고 E2E가 본다

이름 규칙 (부품이 붙이는 것, 쓰는 쪽이 줄 것):

| 부품            | 이름                                                                                                   | 쓰는 쪽이 줄 것                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `IconButton`    | `label` → `aria-label`·`title`                                                                         | 아이콘만 있으면 `label`이 꼭 있어야 한다 (타입이 막는다). 없으면 보이는 글자를 `children`으로 |
| `Button`        | 글자(`children`)                                                                                       | 글자. 앞 아이콘은 `aria-hidden`                                                               |
| `SidebarToggle` | 지금 할 일 ('사이드바 가리기'·'사이드바 보기') + `aria-expanded`                                       | 없음                                                                                          |
| `SearchField`   | `label` → `aria-label` (placeholder 기본값)                                                            | `label`                                                                                       |
| `DatePicker`    | '게시일 고르기' / '게시일 2026. 10. 17., 바꾸기' + `aria-haspopup="dialog"`                            | `label`                                                                                       |
| `Modal`         | `role="dialog"`(경고창은 `alertdialog`)·`aria-modal`·`aria-label`                                      | `label`                                                                                       |
| `AlertDialog`   | 제목이 이름                                                                                            | `title`                                                                                       |
| `Sheet`         | `role="dialog"`·`aria-label`, 덮개 없는 `cover`는 `aria-modal` 없음                                    | `label`                                                                                       |
| `Menu`          | `role="menu"`·`aria-label`, 항목은 `menuitem`(체크는 `menuitemcheckbox`), 단축키는 `aria-keyshortcuts` | `label`                                                                                       |

- 장식 아이콘(Font Awesome `<i>`, 그린 SVG)은 `aria-hidden="true"`. 그린 SVG는 `focusable="false"`도
- 이름은 할 일을 말한다 ('지우기', '사이드바 보기'). 상태는 이름에 넣지 않고 `aria-pressed`·`aria-expanded`·`aria-checked`로 알린다
