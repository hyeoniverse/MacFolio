# 개인정보: 무엇을 모으고 얼마나 두나

MacFolio(macfolio.hyeoniverse.com)가 방문자에 대해 서버에 남기는 것을 모두 적는다. 코드가 바뀌면 이 문서도 같이 바꾼다.

## 트래픽 분석 (#102)

사이트를 열면 브라우저가 몇 가지 이벤트를 모아 API(`POST /analytics/events`)로 보낸다. 모은 숫자는 '활동 상태 보기' 앱에서 본다.

- **누구나 보는 것:** 날짜별 방문·순방문자, 앱 열기, 평균 머문 시간, 앱·글·바깥 링크별 수, 나라·기기·브라우저·OS·언어별 수, 들어온 곳의 묶음(검색·소셜·직접·링크), 블로그 글마다 조회수, Apple 메뉴의 "오늘 방문자 N명". 모두 사람을 가리지 않는 합계다
- **관리자만 보는 것:** 들어온 곳의 주소(호스트)와 검색엔진이 넘겨준 검색어, utm 값(출처·매체·캠페인과 그 조합, 검색어·내용. 어디에 낸 링크인지 드러날 수 있다), 실시간 방문 목록(방문 흐름, 가린 IP), Google Search Console의 검색어(아래)

### 모으는 것

| 값                                                                    | 어디서                                              | 예                                                                             |
| --------------------------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------ |
| 이벤트 종류와 받은 시각                                               | 브라우저, 서버                                      | 페이지 열기, 앱 열기, 글·프로젝트 보기, 바깥 링크 누르기, 머문 시간            |
| 연 앱, 본 글·프로젝트, 누른 링크 주소                                 | 브라우저                                            | `memo`, `memo/hello`, `github.com/hyeoniverse`                                 |
| 처음 연 주소                                                          | 브라우저                                            | `/memo/hello`                                                                  |
| 들어온 곳의 **호스트만**                                              | 브라우저 (`document.referrer`)                      | `github.com` (경로는 보내지 않고, 서버도 호스트 모양이 아니면 거절한다)        |
| 검색엔진이 들어온 주소에 실어 보낸 **검색어** (실어 보낼 때만)        | 브라우저 (`document.referrer`의 검색어 칸)          | `macfolio 포트폴리오` (네이버 등. 구글·빙은 보내지 않는다. 소문자로 100자까지) |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content` | 주소 (읽은 뒤 주소창에서 지운다)                    | `linkedin`, `social`, `resume-2026` (소문자로, 공백은 `-`로 바꿔 100자까지)    |
| 기기 종류 (화면 폭), 언어                                             | 브라우저                                            | `desktop`, `ko-KR`                                                             |
| 나라                                                                  | Cloudflare가 붙이는 `CF-IPCountry`                  | `KR`                                                                           |
| 브라우저·OS **종류**                                                  | 서버가 User-Agent를 줄인 값                         | `Chrome`, `macOS`                                                              |
| 하루 해시                                                             | 서버: `HMAC(날짜 + IP + User-Agent, 비밀 키)`       | 64자 16진수                                                                    |
| 마지막 자리를 가린 IP                                                 | 서버                                                | `203.0.113.x`, `2001:db8:1::`                                                  |
| 방문 id                                                               | 브라우저가 페이지를 열 때마다 새로 만드는 무작위 값 | 한 방문의 이벤트를 묶는다                                                      |

utm 값은 첫 페이지 주소에서 한 번 읽고 바로 주소창에서 지운다 (`history.replaceState`, 다른 쿼리는 그대로). 주소를 복사해 나누거나 새로 고쳐도 같은 캠페인 방문이 다시 세지지 않고, 다른 사람에게 링크를 낸 곳이 전해지지 않는다.

### 모으지 않는 것

- **원래 IP.** 하루 해시를 만들 때만 쓰고 저장하지 않는다. 화면에는 마지막 자리를 가린 IP만 보인다
- **User-Agent 원문.** 브라우저·OS 종류로 줄인 값만 둔다
- **쿠키, 기기 지문.** 분석에는 쿠키를 쓰지 않는다. 방명록·댓글용 방문자 쿠키(아래)도 분석에 쓰지 않는다
- **날을 넘긴 추적.** 하루 해시에 날짜가 들어가서, 날이 바뀌면 같은 사람도 다른 값이 된다. 그래서 순방문자는 하루 단위로만 센다
- 들어온 곳의 경로(검색엔진이 넘겨준 검색어만 남긴다), 입력한 글자, 마우스 움직임

### 세지 않는 것

- 관리자로 로그인한 브라우저
- 검색 로봇, 링크 미리보기, 자동 도구 (User-Agent로 거른다)
- 브라우저가 Global Privacy Control(`navigator.globalPrivacyControl`)을 켠 경우: 사이트가 보내지 않는다 (사이트의 수집 코드)
- 로컬 개발과 화면 테스트(E2E)

### 얼마나 두나

| 값                                                                           | 기간                               |
| ---------------------------------------------------------------------------- | ---------------------------------- |
| 가린 IP                                                                      | 7일 뒤 지운다                      |
| 이벤트 (위의 표)                                                             | 90일 뒤 지운다                     |
| 날마다 모은 숫자 (날짜별 방문 수, 들어온 곳·검색어·utm·앱·글·나라·기기별 수) | 계속 둔다. 사람을 가리는 값이 없다 |
| Search Console 검색어 (날짜·검색어·페이지별 합계, 아래)                      | 계속 둔다. 사람을 가리는 값이 없다 |

서버는 한 시간마다 지난 날을 모으고 기간이 지난 값을 지운다 (`apps/api/src/analytics/analytics-rollup.service.ts`의 `maintain`). DB 백업(`ops/backup.sh`)에도 들어간다. 백업은 서버에 7일, 서버 밖(R2)에 30일 두고 지운다 (기본값). 그래서 지운 값도 백업에는 그만큼 더 남는다.

### Google Search Console

구글은 검색어를 사이트에 넘기지 않는다. 그래서 서버가 6시간마다 Google Search Console에서 날짜·검색어·페이지별 노출·클릭 수와 평균 순위를 가져와 둔다 (`apps/api/src/analytics/search-keywords.service.ts`). 구글이 검색 결과를 세어 둔 합계라 방문 하나나 사람 하나와 이어지지 않고, 사람을 알아볼 수 있는 드문 검색어는 구글이 빼고 준다. 관리자만 본다.

## 방명록·댓글 (방문자 쿠키)

메시지나 댓글을 처음 쓰는 브라우저에 무작위 토큰 쿠키(`macfolio_visitor`, 1년)를 주고, 그 토큰으로 이름(예: 🦊 날쌘 여우)을 정한다. DB에는 토큰의 HMAC만 둔다. 도배를 막으려고 IP의 HMAC과 앞 두 자리(`211.234`)를 함께 둔다. 이 쿠키와 값은 분석에 쓰지 않는다.

## 연락 메일 (메일 앱)

메일 앱에서 보낸 메일(이름, 답장받을 주소, 제목, 내용)은 메일 서비스 Resend를 거쳐 사이트 주인의 메일함으로 가고, 서버에도 **1년** 저장된다. 답장받을 주소는 그 메일의 Reply-To가 된다.

- **누가 보나:** 보낸 브라우저(방문자 쿠키)의 보낸 편지함과, 관리자의 받은 편지함에서만 보인다. 서버가 방문자 쿠키의 HMAC으로 거르므로 다른 브라우저에서는 보이지 않는다. 쿠키를 지우면 그 브라우저에서도 더는 보이지 않는다
- **답장:** 관리자가 메일 앱에서 쓴 답장은 답장받을 주소로 메일로 가고, 보낸 사람의 보낸 편지함에서 그 메일 아래에도 보인다
- **기간:** 1년이 지난 메일과 답장은 지운다 (메일을 보내거나 관리자가 받은 편지함을 열 때)
- 하루에 보낼 수 있는 수를 세려고 IP의 HMAC을 서버 메모리에만 두고, 날이 바뀌거나 서버를 다시 띄우면 사라진다
- 사람 확인(Cloudflare Turnstile)을 켜 두면 Cloudflare가 브라우저를 확인한다

## 문서 파일 (Finder의 이력서·포트폴리오·자격증)

Finder에서 여는 이력서·포트폴리오·자격증 파일은 Cloudflare R2에 두고 사이트 주소(`/files/…`)로 내준다. 방문자에 대해 따로 남기는 것은 없다(로그인·쿠키 없이 파일만 준다). 올리기 전에 전화번호·주소·생년월일·신분 번호를 지운 공개용 파일만 둔다.

## 사람 확인 (Cloudflare Turnstile)

메일·댓글·메시지를 쓸 때 사람인지 확인할 수 있다. 어디에 켤지는 관리자가 시스템 설정의 **개인정보 보호 및 보안**에서 정한다 (처음에는 메일만). 누구나 같은 화면에서 지금 어디에 켜져 있는지 본다.

- 켜진 곳에 글을 쓰면 Cloudflare의 위젯이 브라우저를 확인하고 한 번 쓰는 토큰을 준다. 서버는 그 토큰을 Cloudflare에 물어 확인한다. 이때 Cloudflare는 IP와 브라우저 정보를 본다 ([Cloudflare 개인정보 처리 방침](https://www.cloudflare.com/privacypolicy/))
- 이 사이트는 토큰을 저장하지 않는다
- 관리자가 쓰는 글은 확인하지 않는다
